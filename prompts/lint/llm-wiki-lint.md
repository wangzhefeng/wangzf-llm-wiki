请对当前知识库执行快速结构巡检。

## 执行流程

### 第 1 步：运行自动化检查
```bash
uv run scripts/tools/wiki_lint.py --output summary
```

解读结果时注意三级严重度：
- **❌ 错误**：阻塞性问题，必须修复（断链、缺字段、目录不一致）
- **⚠️ 警告**：建议修复（孤儿页、无日期标记、附件缺失）
- **ℹ️ 信息**：可关注的提示（内容新鲜度）

### 第 2 步：按优先级修复
1. 先修 ❌ 错误（wikilinks 断链、raw frontmatter 缺失、raw naming）
2. 再收敛 ⚠️ 警告（孤儿页补索引入口、补齐日期标记）
3. ℹ️ 信息类问题记录到 `wiki/log_lint.md`，不阻塞本轮

### 第 3 步：覆盖更新 `wiki/log_lint.md`
将本轮结果写入主报告，格式：
- 检查日期、命令、结果摘要
- 已修复项清单
- 遗留 warning 边界说明
- 下一步优先级（3-5 条）

### 第 4 步：增量更新 `wiki/log.md`
追加 `## [YYYY-MM-DD] lint | 结构巡检` 条目。

## 注意事项
- `wiki/log.md` 已被排除在 wikilink 检查外
- `raw/repos/**` 嵌套仓库镜像不参与命名检查
- 目录导航页允许 `status: active`
- 不要修复与当前任务无关的问题
