原创 时序之心 *2025年12月15日 18:27*

时间序列数据广泛存在于医疗、经济等关键领域，其动态性、自相关性及趋势性等特性，对因果关系识别提出特殊需求。医疗场景中，患者生命体征、用药剂量等时序数据承载治疗干预与病情变化的关联信息，需明确“何种干预在何时起效”以优化诊疗方案；经济领域，GDP、就业率等指标的时序波动与政策干预直接相关，精准识别因果可提升政策制定科学性。

传统方法存在明显局限：单纯时间序列分析侧重预测，无法剥离混淆因素以揭示因果；经典因果推断方法难以适配时序数据的动态依赖性与滞后效应。这种“预测与因果脱节”的困境，导致实际决策缺乏可靠理论支撑。因此，融合时间序列分析与因果推断，突破动态场景下因果识别的技术瓶颈，兼具指导临床决策、优化政策制定的现实意义与完善因果推断理论体系的学术价值。

## 【论文2】Multi-Band Variable-Lag Granger Causality: A Unified Framework for Causal Time Series Inference across Frequencies（type:cs.AI）

### 关键词：时间序列，因果推断，Granger 因果，多频带，变时滞

### 1.研究方法

![A high-level overview of proposed framework.](data:image/svg+xml,%3C%3Fxml version='1.0' encoding='UTF-8'%3F%3E%3Csvg width='1px' height='1px' viewBox='0 0 1 1' version='1.1' xmlns='http://www.w3.org/2000/svg' xmlns:xlink='http://www.w3.org/1999/xlink'%3E%3Ctitle%3E%3C/title%3E%3Cg stroke='none' stroke-width='1' fill='none' fill-rule='evenodd' fill-opacity='0'%3E%3Cg transform='translate(-249.000000, -126.000000)' fill='%23FFFFFF'%3E%3Crect x='249' y='126' width='1' height='1'%3E%3C/rect%3E%3C/g%3E%3C/g%3E%3C/svg%3E)

A high-level overview of proposed framework.

本文提出了一种名为多频带变时滞 Granger 因果（MB-VLGC）的统一框架，用于跨频率的时间序列因果推断。该方法通过结合频谱分解和动态时间对齐，扩展了传统的变时滞 Granger 因果（VLGC）方法，能够显式建模频率依赖的因果延迟。研究通过三个主要步骤实现：（1）频率带分解，使用带通滤波器将时间序列分解为特定频率成分；（2）因果推断，独立对每个频带应用 VLGC 分析；（3）结果整合，系统地结合频带特定的结果统计量，生成总体因果决策和频率特定的见解。实验表明，该框架在合成数据和真实世界数据集上均优于现有方法，证明了其在不同类型时间序列数据中的广泛适用性。

![Performance Comparison Across Dataset Types](data:image/svg+xml,%3C%3Fxml version='1.0' encoding='UTF-8'%3F%3E%3Csvg width='1px' height='1px' viewBox='0 0 1 1' version='1.1' xmlns='http://www.w3.org/2000/svg' xmlns:xlink='http://www.w3.org/1999/xlink'%3E%3Ctitle%3E%3C/title%3E%3Cg stroke='none' stroke-width='1' fill='none' fill-rule='evenodd' fill-opacity='0'%3E%3Cg transform='translate(-249.000000, -126.000000)' fill='%23FFFFFF'%3E%3Crect x='249' y='126' width='1' height='1'%3E%3C/rect%3E%3C/g%3E%3C/g%3E%3C/svg%3E)

Performance Comparison Across Dataset Types

1. 提出了一种新的多频带变时滞 Granger 因果（MB-VLGC）框架，能够同时处理时间延迟和频率依赖的因果关系。
2. 将变时滞 Granger 因果（VLGC）方法扩展到多频带分析，填补了现有方法在频率特定因果推断方面的空白。
3. 提供了一种高效的因果推断流程，通过频带分解和动态时间对齐，能够检测不同频带中的因果关系及其特定的时间延迟。
4. 在多个领域的数据集（包括合成数据和真实世界数据）上验证了该方法的优越性能，证明了其在处理复杂时间序列因果关系中的有效性。
