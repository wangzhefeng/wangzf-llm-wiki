功能规划如下：

1\. 语音接收

2\. 语音转文字

3\. 文字接入GPT

4\. 接收GPT回复

5\. 文字转语音

先创建虚拟环境并进入：

```properties
conda create -n soulbot python=3.11conda activate soulbot
```

pip install以下库：

```js
baidu-aipchardetlangchainopenai
```

导入库：

```swift
import osfrom aip import AipSpeechimport openaifrom langchain.chat_models import ChatOpenAIfrom langchain.chains import ConversationChainfrom langchain.memory import ConversationBufferMemory, ConversationBufferWindowMemoryfrom playsound import playsoundimport warningswarnings.filterwarnings('ignore')
```

先通过arecord录制音频文件，缺点是占用内存，读写耗时，没法自动根据用户不说话而停止语音采集行为，有兴趣的伙伴可以考虑实时接收麦克风语音后，直接转文字。

```apache
# record speechos.system("arecord -f S16_LE -r 16000 -c 1 -d 8 -q ./output.wav")
```

语音转文字，我用的是百度语音识别API：https://ai.baidu.com/ai-doc/SPEECH/6k38lxp0r。

使用须知：

1\. 音频文件需要在60s 内；

2\. 音频格式支持：pcm（不压缩）、wav（不压缩，pcm编码）、amr（压缩格式）、m4a（压缩格式）；

3\. 采样率 ：16000 固定值。编码：16bit 位深的单声道；

4\. api 调用流程：鉴权认证 -> 确认请求方式 -> 填写参数。

调用百度的语言识别接口，将语言转文本：

```python
# ref: https://console.bce.baidu.com/ai/#/ai/speech/app/listAPP_ID = '3****'API_KEY = 'Zn****'SECRET_KEY = 'xiD****'
client = AipSpeech(APP_ID, API_KEY, SECRET_KEY)
# 读取文件def get_file_content(filePath):    with open(filePath, 'rb') as fp:        return fp.read()
# 识别本地文件，recog_result就是识别结果recog_result = client.asr(get_file_content('./output.wav'), 'wav', 16000, {    'dev_pid': 1536,})recog_result = recog_result['result'][0]print('I: {}'.format(recog_result))
```

找朋友借了他openAI的api key，使用LangChain，接入GPT：

```markdown
# text2gptfirst_flag = Falseif first_flag == False:    openai.api_key = 'sk-*******'    # https://blog.csdn.net/bjweimengshu/article/details/129760971    llm = ChatOpenAI(temperature=0.0, openai_api_key=openai.api_key, model_name="gpt-3.5-turbo")    memory = ConversationBufferWindowMemory(k=5)    conversation = ConversationChain(        llm=llm,         memory = memory,        verbose=False    )    first_flag = True
# 尝试升级python到3.11试试重装langchainconversation.predict(input=recog_result)
# 打印对话历史# print(memory.buffer)history = memory.load_memory_variables({})last_reply = history['history'].split('\n')[-1][3:]print("GPT: {}".format(last_reply))
```

需要注意一点，接GPT需要kexue上网，而百度接口调用不能走代理，解决方案是，先开启kexue上网，然后unset http\_proxy和unset https\_proxy，把百度接口（aip.baidubce.com）添加到rule的白名单内。在gpt的api请求代码（/root/anaconda3/envs/soulmate/lib/python3.11/site-packages/openai/api\_requestor.py）中把代理地址加上。详见https://blog.csdn.net/bjweimengshu/article/details/129760971。这样百度接口走直连，gpt走代理。

记忆有很多种方法：比如只保留top k个记忆，按token数保留最近记忆，对近期记忆做summary。本质上都是通过组织prompt来完成这个过程（Langchain其他功能也是如此，有些还会配合一些其他简易的操作，非常巧妙的做了套壳），所以记忆内容越多，后续单次提问的成本也会增加。

最后，用百度api将文本转音频，播放即可：

```python
result  = client.synthesis(last_reply, 'zh', 1, {        'vol': 3,  })
# 识别正确返回语音二进制 错误则返回dict 参照下面错误码if not isinstance(result, dict):    with open('auido.mp3', 'wb') as f:        f.write(result)
playsound('auido.mp3')
```
