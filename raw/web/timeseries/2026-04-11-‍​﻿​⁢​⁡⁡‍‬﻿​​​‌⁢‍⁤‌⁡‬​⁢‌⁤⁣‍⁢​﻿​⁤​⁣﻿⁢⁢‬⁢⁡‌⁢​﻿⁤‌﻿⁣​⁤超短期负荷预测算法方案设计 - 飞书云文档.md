一、传统统计方法

时间序列分析法：

◦

自回归模型：Autoregressive model，简称AR模型，是统计上一种处理时间序列的方法，用同一变数例如x的之前各期，亦即x1至xt-1来预测本期xt的表现，并假设它们为一线性关系。因为这是从回归分析中的线性回归发展而来，只是不用x预测y，而是用x预测 x自己，所以叫做自回归。

▪

当前时刻的值是过去 p 个时刻值的线性组合，再加上一个随机误差（白噪声）。

▪

公式：Y\_t = c + φ₁Y\_{t-1} + φ₂Y\_{t-2} +... + φ\_pY\_{t-p} + ε\_t

▪

Y\_t: 当前时刻的观测值

▪

c: 常数项

▪

φ₁, φ₂,..., φ\_p: 自回归系数 (需要估计)

▪

ε\_t: 当前时刻的白噪声误差

▪

模型捕捉了序列自身的“记忆”或“惯性”。

◦

移动平均模型： Moving Average Model，简称MA模型。基于过去的观测值的移动平均值来预测未来值。移动平均模型通常用于平滑时间序列数据，以消除短期波动，从而更好地理解数据的长期趋势。

▪

当前时刻的值是过去 q 个时刻的随机误差的线性组合，再加上当前时刻的随机误差。

▪

公式：Y\_t = μ + ε\_t + θ₁ε\_{t-1} + θ₂ε\_{t-2} +... + θ\_qε\_{t-q}

▪

μ: 序列的均值（常假设为0）

▪

θ₁, θ₂,..., θ\_q: 移动平均系数 (需要估计)

▪

ε\_t, ε\_{t-1},..., ε\_{t-q}: 当前和过去时刻的白噪声误差

▪

模型捕捉了序列受到的短期“冲击”或“波动”的影响。

◦

自回归移动平均模型：autoregressive moving average model; 简称ARMA模型。 结合AR和MA模型，由自回归模型（AR）和滑动平均模型（MA）混合构成。

式中符号： p和q是模型的自回归阶数和移动平均阶数；φ和θ是不为零的待定系数；εt独立的误差项；

Xt是平稳、正态、零均值的时间序列。

◦

自回归积分移动平均模型：ARIMA模型全称Autoregressive Integrated Moving Average，由统计学家George Box与Gwilym Jenkins于20世纪70年代系统提出。ARIMA 模型的核心思想是将一个非平稳的时间序列通过差分（Differencing）转化为平稳序列，然后对这个平稳序列建立一个ARMA（AutoRegressive Moving Average）模型。ARMA 模型本身是 AR（自回归）模型和 MA（移动平均）模型的组合。

▪

差分 (Differencing): 计算当前时刻值与前一时刻值的差：∇Y\_t = Y\_t - Y\_{t-1}。一次差分通常可以消除线性趋势。如果一次差分后序列还不平稳，可以进行二次差分：∇²Y\_t = ∇(∇Y\_t) = (Y\_t - Y\_{t-1}) - (Y\_{t-1} - Y\_{t-2}) = Y\_t - 2Y\_{t-1} + Y\_{t-2}，依此类推。

▪

阶数 d： 表示需要进行差分的次数 (d=0 表示序列本身平稳，直接用ARMA模型；d=1 表示做一次差分；d=2 表示做两次差分)。

ARIMA模型参数体系包含三个维度：

▪

自回归阶数（p）：模型中使用的过去观测值 (Y\_{t-1}, Y\_{t-2},..., Y\_{t-p}) 的数量。反映了序列自身历史值对当前值的影响长度。

▪

差分次数（d）：使原始序列变得平稳所需的最小差分次数。决定了如何去除趋势和非平稳性。

▪

移动平均阶数（q）：模型中使用的过去预测误差 (ε\_{t-1}, ε\_{t-2},..., ε\_{t-q}) 的数量。反映了历史冲击或噪声对当前值的影响长度。

◦

季节性自回归积分移动平均模型： SARIMA (Seasonal ARIMA)： 专门处理具有强季节性的负荷数据。在标准ARIMA(p,d,q)基础上，增加了季节性部分(P, D, Q, S)，表示为 ARIMA(p, d, q)(P, D, Q)\[S\]。其中 S 是季节周期长度（如日负荷S=24，周负荷S=168）。这是处理负荷季节性最常用的扩展。

◦

ARIMAX (ARIMA with eXogenous regressors)： 在ARIMA模型中加入外部解释变量（如温度、湿度、风速、光照强度、节假日虚拟变量、经济指标等），显著提高预测精度。公式变为：

W\_t = c + φ₁W\_{t-1} +... + φ\_pW\_{t-p} + β₁X\_{1t} +... + β\_kX\_{kt} + ε\_t + θ₁ε\_{t-1} +... + θ\_qε\_{t-q}
