01

特征工程

本赛题是典型的长期时间序列回归预测问题，因此主要考虑的解题方向就是复杂的特征工程+调参，下面着重介绍特征工程部分

A

时间特征

```javascript
df["年"] = df["时间"].dt.yeardf["季节"] = df["时间"].dt.quarterdf["月"] = df["时间"].dt.monthdf["日"] = df["时间"].dt.daydf["周"] = df["时间"].dt.weekdf["分"] = df["时间"].dt.minute // 15 + df["时间"].dt.hour * 4df["分"] = df["分"].astype("category")
```

气象特征

```javascript
df['100m风速（100m/s）'] = df['100m风速（100m/s）'] * np.sin(np.pi * df['100m风向（°)'] / 180)df['10米风速（10m/s）'] = df['10米风速（10m/s）'] * np.sin(np.pi * df['10米风向（°)'] / 180)df["光照/温度"] = df["辐照强度（J/m2）"] / df["温度（K）"]
```

C

分组聚合类特征

（1） 历史值特征。这部分特征思路来源于隔壁风电预测赛道的gap特征

```bash
dfs = []for site, df_site in df.groupby("光伏用户编号"):    df_site = df_site.sort_values("时间")    df_site["辐照强度（J/m2） - 1"] = df_site["辐照强度（J/m2）"].shift(1) - df_site["辐照强度（J/m2）"]    df_site["辐照强度（J/m2） - 8"] = df_site["辐照强度（J/m2）"].shift(8) - df_site["辐照强度（J/m2）"]    dfs.append(df_site)df = pd.concat(dfs, axis=0)
```

（2）光照与当天最强光照的比值。夏天与冬天光照强度不均衡，为了使不同季节出力受光照角度影响较小，使用比值特征可能更加合理

```makefile
df["日期"] = df["时间"].dt.dateday_max_values = df[["光伏用户编号", "日期", "辐照强度（J/m2）"]].groupby(by=["光伏用户编号", "日期"]).max()day_max_values = day_max_values.rename(columns={x: x + "_max" for x in day_max_values.columns}).reset_index()df = pd.merge(df, day_max_values, on=["光伏用户编号", "日期"], how="left").drop(columns=["日期"])df["辐照强度（J/m2）_max"] = df["辐照强度（J/m2）"] / df["辐照强度（J/m2）_max"]
```

（3）当天平均光照。原理同上，为了均衡不同天的光照强度的差异

```makefile
df["日期"] = df["时间"].dt.dateday_mean_values = df[["光伏用户编号", "日期", "是白天", "辐照强度（J/m2）"]].groupby(by=["光伏用户编号", "日期", "是白天"]).mean()day_mean_values = day_mean_values.rename(columns={x: x + "_mean" for x in day_mean_values.columns}).reset_index()df = pd.merge(df, day_mean_values, on=["光伏用户编号", "日期", "是白天"], how="left").drop(columns=["日期"])
```

（4）温度与当天最高最低温度的差值。该特征来自于DF“光伏电站人工智能运维大数据处理分析”top1方案思路，即光伏发电与温度差强相关

```makefile
df["日期"] = df["时间"].dt.dateday_max_values = df[["光伏用户编号", "日期", "温度（K）"]].groupby(by=["光伏用户编号", "日期"]).max()day_min_values = df[["光伏用户编号", "日期", "温度（K）"]].groupby(by=["光伏用户编号", "日期"]).min()day_max_values = day_max_values.rename(columns={x: x + "_max" for x in day_max_values.columns}).reset_index()day_min_values = day_min_values.rename(columns={x: x + "_min" for x in day_min_values.columns}).reset_index()df = pd.merge(df, day_max_values, on=["光伏用户编号", "日期"], how="left")df = pd.merge(df, day_min_values, on=["光伏用户编号", "日期"], how="left").drop(columns=["日期"])df["温度（K）_max"] = df["温度（K）_max"] - df["温度（K）"]df["温度（K）_min"] = df["温度（K）"] - df["温度（K）_min"]df = df.rename(columns={    "辐照强度（J/m2）_max": "光照/当天最强光照",    "温度（K）_max": "与当天最高温度之差",    "温度（K）_min": "与当天最低温度之差"})
```

02

外部数据

经过测试，使用外部数据后得分能至少提升2个百分点，根据猜测原因有二：1、可能比赛提供的是气象预报数据，而外部数据因为是真实历史气象数据因此更为准确；2、外部数据通常为小时级，相对于15分钟级气象数据可能起到一定的平滑作用。

外部数据下载地址：https://open-meteo.com/en/docs/historical-weather-api，该网站提供了小时级历史气象真实值以及按天的聚合。可以直接根据经纬度下载所需数据，可供参考。
