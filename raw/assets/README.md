# assets

`raw/assets/` 存放通用附件和非来源型素材，不用于代替 `raw/` 保存原始来源。

目录职责：

- `attachments/`：Obsidian 默认附件目录

适合放在这里的内容：

- 通用插图
- 封面图
- 引用素材
- 与单一来源不强绑定的附件

约束：

- 来源型 PDF、网页正文、原始截图优先进入 `raw/`
- 附件路径尽量保持稳定，避免后续引用失效
