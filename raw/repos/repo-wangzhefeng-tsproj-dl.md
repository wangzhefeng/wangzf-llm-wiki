# tsproj_dl 仓库入口笔记

## 仓库信息

- 仓库名：`tsproj_dl`
- 仓库地址：https://github.com/wangzhefeng/tsproj_dl
- README 入口：`README.md`
- 主要用途：实现基于神经网络模型的时间序列预测快速测试、训练、推理框架，提供统一的深度学习时间序列预测工程结构。

## 仓库要解决的问题

- 为深度学习时间序列预测提供标准化的代码框架和工程实践。
- 统一不同神经网络模型（RNNs、Transformers等）的数据处理、训练和评估流程。
- 提供可复现的实验环境和减少随机性的最佳实践。

## 关键入口

- 仓库总入口：`README.md`
- 主要目录结构：
  - `models/`：模型实现，按神经网络类型分类
  - `layers/`：基础神经网络层定义
  - `data_provider/`：数据处理流程，按模型类型分类（RNNs_type, TFs_type）
  - `exp/`：实验主流程脚本（长期预测、短期预测等）
  - `scripts/`：可执行脚本，按数据集分类
  - `dataset/`：公开数据集
  - `docs/`：研究文档
  - `utils/`：工具函数库（独立git仓库）

## 核心特点

1. **模块化设计**：将模型、数据、训练流程分离，便于扩展和维护。
2. **多模型支持**：支持RNNs、Transformers等多种神经网络架构。
3. **工程最佳实践**：包含命令行解析、随机性控制、实验日志管理等。
4. **可复现性**：提供随机种子设置和实验记录机制。

## 训练、测试、预测涉及的知识单元

- 训练前：
  - 数据预处理与标准化
  - 序列窗口构造
  - 数据集划分
- 训练阶段：
  - 模型初始化与配置
  - 损失函数定义
  - 优化器与学习率调度
  - 训练循环与验证
- 测试阶段：
  - 模型评估指标
  - 结果可视化
- 预测阶段：
  - 推理脚本
  - 结果保存与导出
