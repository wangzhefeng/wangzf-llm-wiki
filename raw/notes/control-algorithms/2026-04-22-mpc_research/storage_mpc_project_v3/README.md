# 储能 MPC 项目（工程版 V3）

这是一个进一步贴近实际业务约束的储能 / 虚拟电厂 MPC 工程项目。  
相比 V2，本版本新增：

- 充放电互斥二进制变量（MILP/MICP 风格）
- 需量惩罚（demand charge / peak penalty）近似建模
- 偏差考核成本（针对计划与实际偏差）
- 真实预测器接口模板（可直接替换成你自己的 TS 模型）
- 多资源聚合状态/控制骨架（为 VPP 扩展预留）
- 配置化开关：可在不改代码的情况下启用/禁用部分成本项

> 说明：为了保证可运行性，默认仍使用 `CVXPY` 建模。  
> 如果本地缺少支持混合整数的求解器，可以先将互斥约束开关关闭，或改装到 Gurobi / CBC / SCIP。

---

## 1. V3 的工程目标

V1 解决“能跑”；  
V2 解决“更像业务”；  
V3 解决“更像真实交易策略”。

这里的核心目标是把下列业务约束纳入统一优化框架：

- 储能不能同时充电和放电
- 对峰值购电进行惩罚
- 对计划偏差进行考核
- 接入真实预测模型
- 为多储能 / 风光储 / 柔性负荷聚合预留接口

## 2. 核心建模

### 2.1 状态变量

\[
x_k = SOC_k
\]

### 2.2 控制变量

\[
u_k = [P_k^{ch}, P_k^{dis}, P_k^{buy}, P_k^{sell}, z_k]
\]

其中：

- \(P_k^{ch} \ge 0\)：充电功率
- \(P_k^{dis} \ge 0\)：放电功率
- \(P_k^{buy} \ge 0\)：购电功率
- \(P_k^{sell} \ge 0\)：售电功率
- \(z_k \in \{0,1\}\)：充放电模式二进制变量

### 2.3 互斥约束

\[
P_k^{ch} \le z_k P_{max}^{ch}
\]

\[
P_k^{dis} \le (1-z_k) P_{max}^{dis}
\]

这使得同一时刻只能充电或放电，而不能同时进行。

### 2.4 需量惩罚

引入峰值变量 \(P^{peak}\)：

\[
P_k^{buy} \le P^{peak}, \quad \forall k
\]

并在目标中加入：

\[
\lambda_{peak} P^{peak}
\]

这是一种常见的需量电费 / 最大需量惩罚近似形式。

### 2.5 偏差考核

若存在日前 / 日内计划购电功率 \(P_k^{plan}\)，则引入偏差项：

\[
\lambda_{dev} (P_k^{buy} - P_k^{plan})^2
\]

## 3. 推荐扩展路径

### 3.1 真实预测接入

将 `src/storage_mpc/real_forecaster_template.py` 替换为你自己的模型封装，统一输出：

- 负荷预测
- 电价预测
- 光伏预测
- 计划购电序列（可选）

### 3.2 多资源扩展

当前预留了聚合器骨架，后续可以扩展为：

- 多储能单元
- 光伏 + 储能
- 柔性负荷
- 柴油机 / 燃机
- 需求响应资源

### 3.3 求解器建议

若启用互斥二进制变量，建议使用：

- Gurobi
- SCIP
- CBC（能力较弱）
- CPLEX

若仅做连续凸版本，继续用 OSQP / ECOS 即可。
