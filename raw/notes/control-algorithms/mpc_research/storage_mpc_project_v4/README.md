# 储能 / 虚拟电厂 MPC 项目（工程版 V4）

这是一个面向能源算法工程师的**三层调度架构**工程项目，目标是把储能调度从“单层滚动 MPC”升级为更贴近实际业务的：

- **日前（Day-Ahead）计划层**
- **日内（Intra-Day）滚动修正层**
- **实时（Real-Time）MPC 执行层**

该版本的重点不只是增加几个约束，而是把系统架构升级成一个更接近真实电力交易 / 虚拟电厂落地的框架。

---

## 1. 为什么需要三层架构

在真实业务中，单层 MPC 往往不够，因为不同时间尺度的问题不同：

### 1.1 日前层
关注：
- 次日计划
- 交易申报
- 粗粒度能量分配
- 日前购售电计划

特点：
- 时域长（24h 或更长）
- 步长较粗（15min / 30min / 1h）
- 目标偏经济性与全局性

---

### 1.2 日内层
关注：
- 基于更新预测修正日前计划
- 重新安排储能充放电节奏
- 压低偏差风险

特点：
- 时域中等（未来数小时）
- 更新频率较高（每 15min / 每小时）
- 兼顾经济性与计划跟踪

---

### 1.3 实时层
关注：
- 当前状态闭环反馈
- 最后一层约束执行
- 安全、稳定、快速修正

特点：
- 时域短
- 更新频率高
- 偏控制执行

---

## 2. 三层结构

```text
预测层
  ├─ 日前预测（负荷 / 电价 / 光伏）
  ├─ 日内预测更新
  └─ 实时状态反馈

优化与控制层
  ├─ DayAheadPlanner     -> 生成日前购电/储能计划
  ├─ IntraDayPlanner     -> 滚动修正日前计划
  └─ RealTimeMPCController -> 实时执行第一步控制

执行层
  ├─ 更新 SOC
  ├─ 记录成本与偏差
  └─ 进入下一时刻
```

---

## 3. 当前版本实现内容

本项目提供一套**可直接运行**的三层原型：

- `day_ahead_planner.py`
- `intra_day_planner.py`
- `real_time_mpc.py`
- `hierarchical_simulator.py`

为了保证可运行性：

- 日前层：采用简化滚动能量计划
- 日内层：采用中短时域修正
- 实时层：采用 MPC 闭环执行

这是一套工程骨架，不是严格市场规则的完整仿真器，但已经足够作为真实项目的起点。

## 4. V4 的关键价值

相比 V3，V4 最重要的变化是：

### 4.1 从“单问题优化”升级为“多时间尺度协调”
这更符合：

- 虚拟电厂调度
- 储能交易策略
- 实际电力市场组织方式

### 4.2 让预测误差有更自然的修正通道
- 日前预测误差：由日内层修正
- 日内预测误差：由实时层再修正

### 4.3 更适合接入你的真实模型
你已经具备：

- 时间序列预测能力
- 运筹优化能力

V4 的结构正好适合把你的真实预测模型和真实市场规则逐层接入。
