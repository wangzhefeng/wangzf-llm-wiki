> 本文为系统化整理版本：在原始内容基础上，强化结构、补充方法论、增加工程视角，适合直接作为学习笔记或项目参考。

# 1. 总览：整数规划的本质

整数规划（IP / MILP）的核心是：

> **在连续优化框架中，引入离散决策变量，从而表达现实中的“选择/启停/分配/组合”问题**

核心链路：

```
业务问题 → 数学抽象 → 决策变量 → 约束建模 → MILP → 求解器 → 工程结果
```

# 3. 求解原理（核心必须掌握）

## 3.1 LP Relaxation

去掉整数约束：

```
整数问题 → 连续问题
```

作用：

- 提供下界（min问题）
- 判断问题难度
- 判断模型质量

---

## 3.2 Branch and Bound（最重要）

核心逻辑：

```
解 LP → 非整数 → 分支 → 递归 → 剪枝
```

剪枝条件：

1. 不可行
2. 下界劣于当前解
3. 已是整数解

---

## 3.3 Cutting Plane

作用：

```
减少分数解
收紧LP
减少搜索树
```

---

## 3.4 Branch-and-Cut（工业标准）

```
Branch & Bound + Cutting Planes
```

---

# 4. 建模方法论（非常关键）

## 4.1 常见建模套路

### 1）启停逻辑

$$
x \le M y
$$

---

### 2）容量约束

$$
\sum x \le cap \cdot y
$$

---

### 3）分配约束

$$
\sum_i x_{ij} = d_j
$$

---

### 4）互斥约束

$$
y_1 + y_2 \le 1
$$

---

## 4.2 Big-M 原则

不要：

```
M = 1e9
```

要：

```
M = 业务上限
```

---

## 4.3 模型质量核心指标

| 指标 | 说明 |
|------|------|
| LP 松弛紧度 | 越紧越好 |
| 变量数量 | 越少越好 |
| 对称性 | 越低越好 |
| Big-M | 越小越好 |

## 6.1 变量

- y_i：是否开仓

---

## 6.2 模型

$$
\min \sum f_i y_i + \sum c_{ij} x_{ij}
$$

$$
\sum_i x_{ij} = d_j
$$

$$
\sum_j x_{ij} \le cap_i y_i
