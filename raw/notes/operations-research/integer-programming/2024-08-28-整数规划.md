## 整数规划简介

整数规划（Integer Programming, IP）的核心是：

> **在连续优化框架中，引入离散决策变量，从而表达现实中的"选择/启停/分配/组合"问题**

核心链路：

```
业务问题 → 数学抽象 → 决策变量 → 约束建模 → MILP → 求解器 → 工程结果
```

通常，决策变量的取值是大于或等于 0 的自然数，然而在许多实际问题中，
都要求决策变量的取值为正整数，如机器台数、商品数量、工人数量、装载货物的汽车数量等，
这类要求变量为整数的问题称为 <span style='border-bottom:1.5px dashed red;'>
整数规划(Integer Progamming, IP)</span> 问题。

### 分类

* 如果只要求一部分决策变量取整数，则称为 <span style='border-bottom:1.5px dashed red;'>
  混合整数规划(Mix Integer Programming, MIP)</span>；
* 如果决策变量的取值只能是 0 或 1，则称为 <span style='border-bottom:1.5px dashed red;'>
  0-1 整数规划(Binary Integer Programming, BIP)</span>；
* 如果模型是线性模型，则称为 <span style='border-bottom:1.5px dashed red;'>
  整数线性规划(Integer Linear Programming, ILP)</span>。

**整数线性规划（ILP）示例：**

$$\max Z = 3x_{1} + 2x_{2}$$

$$s.t.\begin{cases}
2x_{1} + 3x_{2} \leq 14 \\
4x_{1} + 2x_{2} \leq 18 \\
x_{1},x_{2} \geq 0 \text{且为整数}
\end{cases}$$

### 三类核心变量

| 类型 | 含义 | 典型场景 |
|------|------|----------|
| Binary（0-1）| 开关决策 | 是否启用设备、是否选址 |
| Integer（整数）| 数量决策 | 生产批次、车辆数量 |
| Continuous（连续）| 连续决策 | 功率、流量、比例 |

### 标准问题形式

$$\min \; c^T x$$

$$s.t.\begin{cases}
Ax \leq b \\
x_i \in \mathbb{Z} \quad \text{或} \quad x_i \in \{0, 1\}
\end{cases}$$

## 整数规划求解

求解整数规划的常用方法有 <span style='border-bottom:1.5px dashed red;'>分支定界法</span>
和 <span style='border-bottom:1.5px dashed red;'>割平面法</span>，
这两种方法的共同特点是：在线性规划的基础上，通过增加附加约束条件，
使整数最优解成为线性规划的一个极点（可行域的一个顶点），于是就可以用单纯形法等方法找到这个最优解。
它们的区别在于约束条件的选取规则和方式不同。

### LP 松弛

**LP 松弛（LP Relaxation）** 是求解整数规划的基础步骤：去掉整数约束，将整数问题转化为连续问题，
再用线性规划方法求解。

```
整数问题（IP）→ 去掉整数约束 → 连续线性规划（LP）→ 求解
```

LP 松弛的作用：

- 为最小化问题提供**下界**（或最大化问题的**上界**）
- 判断问题难度（松弛解与整数最优解的差距越大，问题越难）
- 评估模型质量（松弛越紧，求解越快）

### 分支定界法

分支定界法（Branch and Bound Algorithm, B&B），
其基本思想是对有整数约束条件问题的可行域进行系统搜索，
通常是把全部解空间反复地切割为越来越小的子集，称为**分支**，
然后在每个子集内计算出一个目标下界（或上界），称为**定界**。

#### 问题介绍

以最大化目标函数的整数规划（MP）问题 A 为例，最优解为 $Z^{*}_{A}$，如果去掉整数约束，
对应的松弛问题 B 为普通的线性规划问题（LP）。

假设 B 的最优解是 $Z_{B}$，假设某一符合整数约束的 A 问题解（不一定是最优解）为 $Z_{A}$，则有：

$$Z_{A} \leq Z_{B}$$

对松弛问题 B 一个或多个变量添加整数约束（分支），相当于对可行域进行切割，每个可行域空间对应一个线性松弛问题，
设为 $B_{i}$，这些松弛问题 $B_{i}$ 的解的最大值（设为 $Z'_{B}$）一定会小于 $Z_{B}$，
即 $Z'_{B} \leq Z_{B}$，因此 $Z'_{B}$ 是 A 问题的一个上界，即：

$$Z_{A} \leq Z'_{B} \leq Z_{B}$$

同理，这些松弛问题 $B_{i}$ 的解的最小值（设为 $Z''_{B}$）可能会小于 $Z_{A}$，
即 $Z_{A}$ 是 A 问题的一个下界：

$$Z''_{B} \leq Z_{A} \leq Z'_{B} \leq Z_{B}$$
$$Z_{A} \leq Z_{A}^{*}$$

如果这些松弛问题 $B_{i}$ 的某个解（设为 $\dot{Z}_{B}$）符合整数约束，
且 $\dot{Z}_{B} > Z_{A}$，则 $\dot{Z}_{B}$ 是 A 问题的一个新的下界。

$$Z_{A} < \dot{Z}_{B} \leq  Z_{A}^{*}$$

分支定界法就是将 B 的可行解空间分成子空间再求最大值的方法，逐步减小上界和下界，最终求得 $Z_{A}^{*}$。
当 LP 问题满足全部整数约束条件时，即为 MP 问题的解。

#### 求解步骤

对于上面的整数规划问题 A，求解步骤如下：

1. 去掉整数约束条件，得到原问题 A 的松弛问题 B，使用单纯形法或内点法等求解 B 得到 B 的最优解，即：

$$X^{(0)}=(x_{1}, x_{2})^{T}=(3.25, 2.5)^{T}$$
$$Z^{(0)}=14.75$$

2. 由于此时 $x_{1}$ 和 $x_{2}$ 都不是整数，因此需要选择一个分支变量，如选择 $x_{1}$ 作为分支变量，
   分成左支（$x_{1}\leq 3$）和右支（$x_{1}\geq 4$），对应的分支子问题如下：

    $LP_{1}$
    $$\max Z = 3x_{1} + 2x_{2}$$

    $$s.t.\begin{cases}
    2x_{1} + 3x_{2} \leq 14 \\
    4x_{1} + 2x_{2} \leq 18 \\
    x_{1} \leq 3 \\
    x_{1},x_{2} \geq 0
    \end{cases}$$

    $LP_{2}$
    $$\max Z = 3x_{1} + 2x_{2}$$

    $$s.t.\begin{cases}
    2x_{1} + 3x_{2} \leq 14 \\
    4x_{1} + 2x_{2} \leq 18 \\
    x_{1} \geq 4 \\
    x_{1},x_{2} \geq 0
    \end{cases}$$

    求解两个子问题的最优解（单纯形法、内点法）如下：

    $$X^{(1)}=(3.0, 2.66)^{T}, Z^{(1)}=14.33$$
    $$X^{(2)}=(4.0, 1.0)^{T}, Z^{(2)}=14.0$$

    此时原整数规划 A 的新的下界为 14.0，新的上界为 14.33，即 $14.0 \leq Z^{*} \leq 14.33$。

3. 此时 $LP_{2}$ 的最优解是 14.0，如果继续 $LP_{2}$ 分支，那么其分支后的最优解一定小于 14.0。
   因为分支代表更多的约束，使线性规划更逼近整数规划，其最优解小于没有分支的最优解 $Z^{(2)}=14.0$，
   所以没有必要对 $LP_{2}$ 这个分支继续搜索，从优化的角度，不可能从这个点以后的分支中找到比目前 14.0 更优的解，
   可以直接删除，只需要搜索 $LP_{1}$ 分支即可，这样就大大减少了搜索空间，提高求解的效率。

4. 对 $LP_{1}$ 选择 $x_{2}$ 作为分支变量，分成左支（$x_{2}\leq 2$）和右支（$x_{2} \geq 3$），
   对应的分支子问题如下：

    $LP_{3}$
    $$\max Z = 3x_{1} + 2x_{2}$$

    $$s.t.\begin{cases}
    2x_{1} + 3x_{2} \leq 14 \\
    4x_{1} + 2x_{2} \leq 18 \\
    x_{1} \leq 3 \\
    x_{2} \leq 2 \\
    x_{1},x_{2} \geq 0
    \end{cases}$$

    $LP_{4}$
    $$\max Z = 3x_{1} + 2x_{2}$$

    $$s.t.\begin{cases}
    2x_{1} + 3x_{2} \leq 14 \\
    4x_{1} + 2x_{2} \leq 18 \\
    x_{1} \leq 3 \\
    x_{2} \geq 3 \\
    x_{1},x_{2} \geq 0
    \end{cases}$$

    求解两个子问题的最优解（单纯形法、内点法）如下：

    $$X^{(3)}=(3.0, 2.0)^{T}, Z^{(3)}=13.0$$
    $$X^{(4)}=(2.5, 3.0)^{T}, Z^{(4)}=13.5$$

5. 此时可以看到，在第一次分支后的最优解为 $14.0 \leq Z^{*} \leq 14.33$，而在第二次分支后最优解反而小于 14.0，
   虽然可以继续在 $LP_{4}$ 分支下继续搜索，但是搜索结果肯定不会大于 $Z^{(2)}=14.0$，只会更差，
   而且 $LP_{2}$ 的解恰好满足变量为整数的约束条件，因此该整数规划问题 A 的最优解的 $LP_{2}$ 对应的解为：

    $$X^{*}=X^{(2)}=(4.0, 1.0)^{T}, Z^{*}=Z^{(2)}=14.0$$

#### 剪枝条件

搜索树在以下三种情况下可直接剪枝，无需继续分支：

1. **不可行**：子问题无可行解（约束矛盾）
2. **界劣于当前最优解**：子问题的松弛上界 ≤ 当前已知最优整数解（对最大化问题）
3. **已是整数解**：子问题的松弛最优解恰好满足所有整数约束，直接更新当前最优解

#### 总结

从分支定界的搜索过程来看，该方法非常简洁清晰，相当于增加约束条件后继续求解普通线性规划问题。
但是也要注意到，在变量很多的情况下，该搜索过程是很复杂的，如对于 0-1 整数规划问题，
每个变量的取值只可能是 0 或 1，分支也只是简单的左右两支，形成简单二叉树。
如果变量个数为 10，那么最小分支数是 1024；如果变量数为 20，那么最小分支数是 1048576，呈指数级增长。

因此，分支定界法一般不考虑直接求解该问题的精确解，而是求解近似解或局部最优解，如可以设定当上界和下界非常接近时（如 0.001），
分支定界结束或者使用相对差值，即分支定界法中的 GAP：

$$GAP = \frac{\bar{Z} - Z}{\bar{Z}}$$

当 $GAP \leq 0.001$ 时，可以认为当前的上界或下界是问题的最优解，分支定界法结束迭代。

### 割平面法

#### 问题介绍

分支定界法的思路是对原问题对应的松弛问题的可行域进行切割，切割方法是对非整数变量取相邻整数作为附加约束。
从几何的角度来说，这些约束相当于切割可行域的超平面，这些超平面与坐标轴平行。

分支定界法的缺点是子问题由于分支的增加呈指数增长，为克服该缺点，学者提出了割平面法（Cutting Planes Method），
割平面法也是通过增加切割超平面切割掉松弛问题的非整数解部分，但是并没有对问题进行分支。

割平面法通过增加切割超平面切割掉部分的解空间，该超平面应该满足两个条件：

1. 刚好切割掉松弛问题的非整数解部分
2. 保留所有整数解

#### 求解步骤

那如何找到这个切割超平面呢？

假设有如下整数规划问题及其对应的松弛问题：

$$IP: \max Z = c^{T}x$$
$$s.t.\begin{cases}
Ax = b \\
x \geq 0 \\
x \text{ 为整数}
\end{cases}$$

$$LP: \max Z = c^{T}x$$
$$s.t.\begin{cases}
Ax = b \\
x \geq 0
\end{cases}$$

假设 LP 的最优解不是整数解，否则 LP 的最优解就是问题 IP 的最优解。设 LP 的最优解为：

$$X^{(0)} = (b_{1}, \cdots, b_{i}, \cdots, b_{m}, 0, \cdots, 0)^{T}$$

其中，$b_{i}$ 是分数（不是整数），$X^{(0)}$ 表示 $x_{1}, \cdots, x_{i}, \cdots, x_{m}$ 是基变量，
$x_{m+1}, \cdots, x_{n}$ 是非基变量，在单纯形法中说过，在标准型线性规划方程中，非基变量为 0 时，
基变量的值等于常数项，所有基变量组成一个单位阵。

| 变量       | $x_{1}$ | $\cdots$ | $x_{i}$ | $\cdots$ | $x_{m}$ | $x_{m+1}$ | $\cdots$ | $x_{n}$ | $b$ |
|------------|-----------|------------|-----------|------------|-----------|-------------|------------|-----------|-------|
| $x_{1}$  | 1         |            |           |            |           |  |  |  |  |
| $\cdots$ |           | 1          |           |            |           |  |  |  |  |
| $x_{i}$  |           |            | 1         |            |           | $a_{im+1}$ | $\cdots$ | $a_{in}$ | $b_{i}$ |
| $\cdots$ |           |            |           | 1          |           |  |  |  |  |
| $x_{m}$  |           |            |           |            | 1         |  |  |  |  |

$b_{i}$ 所在行的方程是：

$$x_{i}+a_{im+1}x_{m+1}+\cdots+a_{im+j}x_{m+j}+\cdots+a_{in}x_{n}=b_{i}$$

$$\Rightarrow x_{i}+\sum_{j=1}^{n-m}a_{im+j}x_{m+j}=b_{i}$$

把 $a_{im+j}$ 和 $b_{i}$ 分解成整数 $N$ 和小数 $f$ 两部分（如 $2.3=2+0.3$），即：

$$a_{im+j}=N_{im+j}+f_{im+j}$$
$$b_{i}=N_{bi}+f_{bi}$$

因此，$b_{i}$ 所在的方程可以写成：

$$x_{i}+\sum_{j=1}^{n-m}(N_{im+j}+f_{im+j})x_{m+j}=N_{bi}+f_{bi}$$

$$x_{i}+\sum_{j=1}^{n-m}N_{im+j}x_{m+j}+\sum_{j=1}^{n-m}f_{im+j}x_{m+j}=N_{bi}+f_{bi}$$

$$x_{i}-N_{bi}+\sum_{j=1}^{n-m}N_{im+j}x_{m+j}=f_{bi}-\sum_{j=1}^{n-m}f_{im+j}x_{m+j}$$

因为 $-\sum_{j=1}^{n-m}f_{im+j}x_{m+j} \leq 0$，$f_{bi} < 1$，所以：

$$f_{bi}-\sum_{j=1}^{n-m}f_{im+j}x_{m+j} < 1$$

若要决策变量都取整数，则左边必须为整数，又因为小于 1，所以：

$$f_{bi}-\sum_{j=1}^{n-m}f_{im+j}x_{m+j}\leq 0$$

这样就得到第 $i$ 行对应的割平面法方程（Gomory 割）：

$$f_{bi}-\sum_{j=1}^{n-m}f_{im+j}x_{m+j}\leq 0$$

引入松弛变量 $y_{i}$，将割平面法方程标准化，即：

$$-\sum_{j=1}^{n-m}f_{im+j}x_{m+j}+y_{i}=-f_{bi}$$

将新的约束加入到原来的问题约束中，继续求解，直到求出整数最优解为顶点时才停止计算。

#### 求解步骤示例

$$\max Z = 7x_{1} + 9x_{2}$$

$$s.t.\begin{cases}
-\frac{1}{3}x_{1} + x_{2} \leq 2.0 \\
x_{1} + \frac{1}{7}x_{2} \leq 5.0 \\
x_{1},x_{2} \geq 0 \text{ 且为整数}
\end{cases}$$

对应的松弛问题为：

$$\max Z = 7x_{1} + 9x_{2}$$

$$s.t.\begin{cases}
-\frac{1}{3}x_{1} + x_{2} + x_{3} = 2.0 \\
x_{1} + \frac{1}{7}x_{2} + x_{4} = 5.0 \\
x_{1},x_{2}, x_{3}, x_{4} \geq 0
\end{cases}$$

使用单纯形法求解，最优单纯形表如下：

| 目标和基变量 | b               | $x_{1}$ | $x_{2}$ | $x_{3}$ | $x_{4}$ |
|-------------|-----------------|----|----|--------------------|--------------------|
| $Z$       | -63             | 0  | 0  | -$\frac{28}{11}$ | -$\frac{15}{11}$ |
| $x_{1}$   | $\frac{9}{2}$ | 1  |    | -$\frac{1}{22}$  | $\frac{3}{22}$   |
| $x_{2}$   | $\frac{7}{2}$ |    | 1  | $\frac{7}{22}$   | $\frac{1}{22}$   |

在选择行 $i$ 时，一般选择最大的 $f_{bi}$ 所在的行 $i$。
如果 $f_{bi}$ 相同，那么选择 $\sum_{j=1}^{n-m}f_{im+j}$ 小的所在行 $i$ 构造割平面，
因此选择 $x_{2}$ 所在行构造割平面，即：

$$\frac{1}{2} \leq \frac{7}{22}x_{3} + \frac{1}{22}x_{4}$$

加入松弛变量，并调整后得到：

$$-\frac{7}{22}x_{3}-\frac{1}{22}x_{4}+y_{1}=-\frac{1}{2}$$

将新的约束加入到前面得到的最优单纯形表的最后一行中，如下表：

| 目标和基变量 | b                | $x_{1}$ | $x_{2}$ | $x_{3}$ | $x_{4}$     | $y_{1}$ |
|-------------|------------------|----|----|--------------------|--------------------|-----------|
| $Z$       | -63              | 0  | 0  | -$\frac{28}{11}$ | -$\frac{15}{11}$ | 0         |
| $x_{1}$   | $\frac{9}{2}$  | 1  |    | -$\frac{1}{22}$  | $\frac{3}{22}$   | 0         |
| $x_{2}$   | $\frac{7}{2}$  |    | 1  | $\frac{7}{22}$   | $\frac{1}{22}$   | 0         |
| $y_{1}$   | -$\frac{1}{2}$ | 0  | 0  | -$\frac{7}{22}$  | -$\frac{1}{22}$  | 1         |

使用对偶单纯形法求解，得到最终的最优单纯形表，如下表：

| 目标和基变量 | b                | $x_{1}$ | $x_{2}$ | $x_{3}$ | $x_{4}$     | $y_{1}$ |
|-------------|------------------|----|----|--------------------|--------------------|-----------|
| $Z$       | -59              | 0  | 0  | 0  | -1              | -8                           |
| $x_{1}$   | $\frac{32}{7}$ | 1  | 0  | 0  | $\frac{1}{7}$ | -$\frac{1}{7}$             |
| $x_{2}$   | 3                | 0  | 1  | 0  | 0               | 1                            |
| $x_{3}$   | $\frac{11}{7}$ | 0  | 0  | 1  | $\frac{1}{7}$ | -$\frac{22}{7}$            |

选择 $x_{1}$ 所在的行构造割平面，得到割平面方程：

$$\frac{4}{7} \leq \frac{1}{7}x_{4}+\frac{6}{7}y_{1}$$

加入松弛变量，并调整后得到：

$$-\frac{1}{7}x_{4}-\frac{6}{7}y_{1}+y_{2}=-\frac{4}{7}$$

将新的割平面方程加入到上一步得到的最优单纯形表中，得到如下结果：

| 目标和基变量 | b                | $x_{1}$ | $x_{2}$ | $x_{3}$ | $x_{4}$        | $y_{1}$         | $y_{2}$ |
|-------------|------------------|-----------|-----------|-----------|------------------|-------------------|-----------|
| $Z$       | -59              | 0         | 0         | 0         | -1               | -8                | 0         |
| $x_{1}$   | $\frac{32}{7}$ | 1         | 0         | 0         | $\frac{1}{7}$  | -$\frac{1}{7}$  | 0         |
| $x_{2}$   | 3                | 0         | 1         | 0         | 0                | 1                 | 0         |
| $x_{3}$   | $\frac{11}{7}$ | 0         | 0         | 1         | $\frac{1}{7}$  | -$\frac{22}{7}$ | 0         |
| $y_{2}$   | -$\frac{4}{7}$ | 0         | 0         | 0         | -$\frac{1}{7}$ | -$\frac{6}{7}$  | 1         |

迭代求解得到满足整数规划的解，结果如下表：

| 目标和基变量 | b   | $x_{1}$ | $x_{2}$ | $x_{3}$ | $x_{4}$ | $y_{1}$ | $y_{2}$ |
|-------------|-----|-----------|-----------|-----------|-----------|-----------|-----------|
| $Z$       | -55 | 0         | 0         | 0         | 0         | -2        | -7        |
| $x_{1}$   | 4   | 1         | 0         | 0         | 0         | -1        | 1         |
| $x_{2}$   | 3   | 0         | 1         | 0         | 0         | 1         | 0         |
| $x_{3}$   | 1   | 0         | 0         | 1         | 0         | -4        | 1         |
| $x_{4}$   | 4   | 0         | 0         | 0         | 1         | 6         | -7        |

即得到满足整数规划的解为：

$$X^{*}=(x_{1}, x_{2}) = (4, 3), \quad Z^{*}=55$$

### Branch-and-Cut（工业标准）

现代商业求解器（Gurobi、CPLEX 等）采用的工业标准算法是 **Branch-and-Cut**，将分支定界与割平面法结合：

```
求解 LP 松弛
    ↓
生成割平面（Gomory 割、覆盖割等）收紧可行域
    ↓
仍有非整数解 → 分支
    ↓
递归搜索 + 剪枝
    ↓
直到满足 GAP 要求或找到整数最优解
```

**优点**：
- 割平面收紧松弛，减少需要分支的节点数
- 工业求解器在此基础上还引入启发式（Heuristic）加速找到初始整数解

## 建模方法论

建模能力是整数规划工程实践的核心，核心目标是：

> **把复杂业务，建模成"求解器喜欢"的数学结构**

### 常见建模套路

#### 1. 启停逻辑

用二元变量 $y \in \{0,1\}$ 控制连续变量 $x$ 是否激活：

$$x \leq M \cdot y$$

- $y=0$ 时强制 $x=0$（设备关闭）
- $y=1$ 时 $x$ 可取 $[0, M]$（设备开启）

#### 2. 容量约束

$$\sum_i x_i \leq cap \cdot y$$

表示只有开启（$y=1$）时才有容量 $cap$。

#### 3. 分配约束

$$\sum_i x_{ij} = d_j \quad \forall j$$

表示客户 $j$ 的需求 $d_j$ 必须被完全满足（各分配量之和等于需求量）。

#### 4. 互斥约束

$$y_1 + y_2 \leq 1$$

表示两个选项最多选其一（0-1 互斥）。可推广到 $k$ 选 $m$：

$$\sum_i y_i \leq m$$

### Big-M 原则

Big-M 方法是处理启停逻辑的核心技巧，M 的取值直接影响模型质量：

| 写法 | 效果 |
|------|------|
| `M = 1e9`（太大）| LP 松弛极松，分支定界树爆炸，数值不稳定 |
| `M = 业务上限`（推荐）| 松弛紧，求解快，数值稳定 |

**原则**：M 应取该变量在业务上的合理最大值，而非一个随意的大数。

### 模型质量核心指标

| 指标 | 说明 | 优化方向 |
|------|------|----------|
| LP 松弛紧度 | 松弛解与整数最优解的差距 | 越紧越好（减少搜索空间）|
| 变量数量 | 模型规模 | 越少越好 |
| 对称性 | 等价解的数量 | 越低越好（避免重复搜索）|
| Big-M 值 | 约束中的大常数 | 越小越好（提高松弛紧度）|

## 经典问题结构

### 背包问题

> 0-1 背包问题（Knapsack Problem）

**问题描述**：有 $n$ 个物品，物品 $i$ 的重量为 $w_i$，价值为 $v_i$，背包容量为 $W$，
选择哪些物品装入背包使得总价值最大且不超过容量？

**数学模型**：

$$\max \sum_{i=1}^{n} v_i x_i$$

$$s.t.\begin{cases}
\sum_{i=1}^{n} w_i x_i \leq W \\
x_i \in \{0, 1\}, \quad i = 1, \cdots, n
\end{cases}$$

**扩展变体**：
- **有界背包**：每种物品可取多件（$x_i \leq u_i$，$u_i$ 为上限）
- **多维背包**：多种资源约束（$\sum_i w_{ik} x_i \leq W_k$，$k$ 为资源维度）
- **分组背包**：物品分组，每组最多选一件

### 指派问题

> 指派问题（Assignment Problem）

**问题描述**：将 $n$ 个任务分配给 $n$ 个执行者，每人恰好完成一个任务，
执行者 $i$ 完成任务 $j$ 的成本为 $c_{ij}$，求使总成本最小的分配方案。

**数学模型**：

$$\min \sum_{i=1}^{n}\sum_{j=1}^{n} c_{ij} x_{ij}$$

$$s.t.\begin{cases}
\sum_{j=1}^{n} x_{ij} = 1, \quad \forall i \quad \text{（每人恰好完成一个任务）} \\
\sum_{i=1}^{n} x_{ij} = 1, \quad \forall j \quad \text{（每个任务恰好被一人完成）} \\
x_{ij} \in \{0, 1\}
\end{cases}$$

**注**：标准指派问题可用匈牙利算法 $O(n^3)$ 精确求解；但加入额外约束后退化为 MILP。

### 设施选址

> 有容量限制设施选址（Capacitated Facility Location, CFL）

**变量**：
- $y_i \in \{0,1\}$：是否在位置 $i$ 开设仓库/设施
- $x_{ij} \geq 0$：从设施 $i$ 向客户 $j$ 的发货量

**模型**：

$$\min \sum_i f_i y_i + \sum_i \sum_j c_{ij} x_{ij}$$

$$s.t.\begin{cases}
\sum_i x_{ij} = d_j, \quad \forall j \quad \text{（满足客户需求）} \\
\sum_j x_{ij} \leq cap_i \cdot y_i, \quad \forall i \quad \text{（容量约束）} \\
y_i \in \{0,1\},\; x_{ij} \geq 0
\end{cases}$$

**工程增强**：
- 最小启用量：$\sum_j x_{ij} \geq q_{min} \cdot y_i$（避免小量低效开仓）
- 多级容量：不同规模仓库对应不同固定成本
- 客户分配限制：每个客户只允许从固定数量的设施发货

### 调度问题

**典型场景**：$n$ 个作业在 $m$ 台机器上加工，每个作业有工艺路线、加工时间、截止时间，
目标是最小化最大完工时间（Makespan）或延误量。

**关键约束**：

1. **顺序约束**（工艺顺序）：

$$s_{jk} \geq s_{ij} + p_{ij}$$

（作业 $i$ 在机器 $j$ 上完成后才能在机器 $k$ 上开始）

2. **机器互斥约束**（同一时刻只有一个作业在机器上）：

$$s_{ij} + p_{ij} \leq s_{i'j} + M(1-\delta_{ii'j}), \quad \delta_{ii'j} \in \{0,1\}$$

3. **截止时间约束**：

$$s_{ij} + p_{ij} \leq d_i$$

**常见目标**：$\min C_{max}$（最小化最大完工时间）、$\min \sum w_i T_i$（最小化加权延误）。

### 储能调度 MILP

储能系统（电池）的优化调度是典型的 MILP 应用场景，也是能源领域的核心方向。

**变量**：

| 变量 | 含义 | 类型 |
|------|------|------|
| $p^{ch}_t$ | $t$ 时刻充电功率 | 连续 |
| $p^{dis}_t$ | $t$ 时刻放电功率 | 连续 |
| $SOC_t$ | $t$ 时刻荷电状态 | 连续 |
| $u^{ch}_t$ | $t$ 时刻是否充电 | 二元 |
| $u^{dis}_t$ | $t$ 时刻是否放电 | 二元 |

**关键约束**：

1. **充放电互斥**（防止同时充放电）：

$$u^{ch}_t + u^{dis}_t \leq 1, \quad \forall t$$

2. **SOC 动态方程**：

$$SOC_t = SOC_{t-1} + \eta^{ch} p^{ch}_t \Delta t - \frac{p^{dis}_t \Delta t}{\eta^{dis}}$$

3. **SOC 范围约束**：

$$SOC_{min} \leq SOC_t \leq SOC_{max}$$

4. **功率约束（Big-M 形式）**：

$$0 \leq p^{ch}_t \leq P^{ch}_{max} \cdot u^{ch}_t$$
$$0 \leq p^{dis}_t \leq P^{dis}_{max} \cdot u^{dis}_t$$

**目标**：最小化购电成本或最大化套利收益：

$$\min \sum_t \lambda_t (p^{load}_t + p^{ch}_t - p^{dis}_t) \Delta t$$

### Gurobi 代码示例

使用 Gurobi 求解以下整数规划模型：

$$\max Z = 3x_{1} + 2x_{2}$$

$$s.t.\begin{cases}
2x_{1} + 3x_{2} \leq 14 \\
4x_{1} + 2x_{2} \leq 18 \\
x_{1},x_{2} \geq 0 \text{ 且为整数}
\end{cases}$$

```python
import gurobipy as grb

# 定义模型
model = grb.Model()

# 定义整数变量
x1 = model.addVar(vtype=grb.GRB.INTEGER, name="x1")
x2 = model.addVar(vtype=grb.GRB.INTEGER, name="x2")

# 添加约束
model.addConstr(2 * x1 + 3 * x2 <= 14)
model.addConstr(4 * x1 + 2 * x2 <= 18)
model.addConstr(x1 >= 0)
model.addConstr(x2 >= 0)

# 定义目标函数
model.setObjective(3 * x1 + 2 * x2, sense=grb.GRB.MAXIMIZE)

# 模型求解
model.optimize()

# 模型结果打印
print(f"目标函数值：{model.objVal}")
for v in model.getVars():
    print(f"参数 {v.varName} = {v.x}")
```

```
# 目标函数值：14.0
# 参数 x1 = 4.0
# 参数 x2 = 1.0
```

与线性规划代码的主要区别：定义变量时通过 `vtype=grb.GRB.INTEGER` 指定变量类型为整数，
其余建模方式与 LP 完全一致。

## 求解日志解读

求解器（如 Gurobi）在运行过程中会输出关键指标，理解日志有助于判断求解状态和调参方向：

| 指标 | 含义 | 说明 |
|------|------|------|
| `incumbent` | 当前最优整数解 | 搜索过程中找到的最好整数可行解 |
| `bound` | 理论界（上界/下界）| 通过 LP 松弛和割平面得到的理论最优界 |
| `gap` | 收敛程度 | `(bound - incumbent) / bound`，越小越好 |
| `nodes` | 已探索节点数 | 分支定界树中已搜索的节点数 |
| `cuts` | 添加的割平面数量 | 越多说明 LP 松弛越紧 |

**常见状态**：
- `OPTIMAL`：找到精确最优解，gap = 0
- `INFEASIBLE`：问题无可行解，需检查约束
- `TIME_LIMIT`：超时，返回当前最优解（可能有 gap）
- `MEM_LIMIT`：内存溢出，需简化模型

## 常见坑

### 1. 模型不可行（Infeasible）

**症状**：求解器报 `INFEASIBLE`，无解返回。

**排查步骤**：
- 逐步注释约束，定位冲突的约束组合
- 检查等式约束是否过度约束（等式比不等式更容易冲突）
- 使用 Gurobi 的 `computeIIS()` 方法自动定位不可行子系统

### 2. Big-M 过大

**症状**：求解时间极长，LP 松弛值远好于实际整数最优。

**原因**：M 过大导致 LP 松弛极松，分支定界需要探索大量节点才能收敛。

**解决**：将 M 替换为业务上的合理上限，或使用等价的强化约束替代 Big-M。

### 3. 变量乱设整数

**症状**：模型可行但求解极慢。

**原因**：将实际上可以是连续的变量错误地设为整数，徒增问题难度。

**原则**：只对真正需要离散决策的变量设整数类型（如启停开关、数量选择）；
流量、比例、功率等物理量通常设为连续变量。

### 4. 数值尺度问题

**症状**：求解结果异常，gap 无法收敛，或解在约束边界上抖动。

**原因**：不同量纲的约束系数相差悬殊（如 $10^6$ 与 $10^{-3}$ 混用），导致数值精度问题。

**解决**：对变量和约束进行归一化/量纲统一；避免极大或极小的系数；
使用求解器参数 `NumericFocus` 提高数值精度。

## 工程最佳实践

### 建模流程

```
1. 业务理解   → 明确决策变量、目标、约束的业务含义
2. 数学建模   → 写出完整的数学模型（变量、目标、约束）
3. LP 验证    → 先去掉整数约束，验证 LP 松弛可行且解合理
4. 加整数     → 引入整数/二元变量，验证模型正确性
5. 调参优化   → 调整 Big-M、GAP 容忍度、时间限制等参数
```

```
project/
  ├── data.py       # 数据加载与预处理
```

## 进阶方向

### 1. 储能调度 + MILP

结合电池物理模型（SOC 动态、充放效率、循环寿命）与电价信号，
构建储能系统日前/实时调度优化模型，是能源领域 MILP 应用的核心场景。

### 2. 预测 + 优化（Forecast + Optimization）

将负荷预测、电价预测结果作为 MILP 的参数输入，
构建端到端的"预测-优化"pipeline，处理预测误差对优化结果的影响（鲁棒优化/随机规划）。

### 3. MPC + MILP

模型预测控制（Model Predictive Control）在每个控制周期滚动求解一个短时域的 MILP，
兼顾实时性与最优性，是储能、微电网控制的主流方案。

### 4. 分解算法（Benders / Lagrangian 松弛）

对于大规模 MILP（万级变量以上），直接求解不现实，
Benders 分解将主问题（整数）和子问题（连续）分开求解，
Lagrangian 松弛通过对偶化复杂约束降低问题规模，两者均是工业级大规模优化的核心工具。
