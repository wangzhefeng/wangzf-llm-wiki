# 时间序列预测框架比较与选择指南

## 概述

基于知识库中整理的 5 个时间序列预测框架仓库（tsproj_ml, tsproj_stat, tsproj_dl, tsproj_ltsfm, Time-Series-Library），本文档提供框架特点比较、适用场景分析和选择建议。

## 框架概览

| 框架 | 核心定位 | 方法类型 | 适用场景 |
|------|----------|----------|----------|
| **tsproj_ml** | 机器学习时间序列预测策略体系 | 传统机器学习 | 中小规模数据、需要可解释性、特征工程重要 |
| **tsproj_stat** | 统计时间序列预测框架 | 统计方法 | 小样本、结构清晰、需要快速baseline |
| **tsproj_dl** | 深度学习时间序列预测框架 | 深度学习方法 | 大规模、复杂模式、长序列、多变量 |
| **tsproj_ltsfm** | 时间序列基础模型评测框架 | 基础模型评估 | 时序基础模型（TimesFM/Chronos等）评测与比较 |
| **Time-Series-Library** | 深度学习时间序列模型库 | 深度学习模型集合 | 学术研究、模型复现、算法对比 |

## 详细对比

### 1. tsproj_ml（机器学习框架）

**核心特点**：
- 实现 7 种多步预测策略：USMDO, USMD, USMR, USMDR, MSMD, MSMR, MSMDR
- 强调特征工程与输入组织
- 完整的训练-测试-预测闭环

**优势**：
- 策略体系完整，覆盖单/多变量、直接/递归等组合
- 工程化程度高，适合生产环境
- 对特征工程支持深入

**限制**：
- 主要针对传统机器学习方法
- 对超长序列处理能力有限

**适用场景**：
- 工业预测项目，数据规模中等
- 需要可解释预测过程
- 多序列统一建模需求

### 2. tsproj_stat（统计框架）

**核心特点**：
- 经典统计方法实现
- 快速baseline生成
- 平稳性检验与预处理

**优势**：
- 计算效率高，资源需求低
- 模型可解释性强
- 小样本场景表现稳定

**限制**：
- 对复杂非线性模式捕捉有限
- 多变量联动建模相对简单

**适用场景**：
- 数据量有限（<1000样本）
- 需要快速验证业务可行性
- 作为深度学习方法的对比基线

### 3. tsproj_dl（深度学习框架）

**核心特点**：
- 支持 RNNs、Transformers 等多种架构
- 模块化设计：数据、模型、训练流程分离
- 工程最佳实践集成（随机性控制、实验日志等）

**优势**：
- 架构灵活，易于扩展新模型
- 处理复杂模式能力强
- 适合大规模、高维数据

**限制**：
- 训练资源需求较高
- 需要较多数据才能发挥优势
- 模型可解释性相对较差

**适用场景**：
- 大数据量（>10万样本）
- 复杂时序模式（多周期、非线性交互）
- 研究新型神经网络架构

### 4. tsproj_ltsfm（基础模型评测框架）

**核心特点**：
- 专注时序基础模型评估
- 统一评测协议与指标
- 零样本/少样本能力测试

**优势**：
- 前沿技术跟进及时
- 评测标准化，结果可比性强
- 连接学术研究与应用实践

**限制**：
- 主要面向评测而非生产部署
- 对传统方法覆盖有限

**适用场景**：
- 评估时序基础模型性能
- 研究零样本迁移能力
- 为模型选择提供实证依据

### 5. Time-Series-Library（模型库）

**核心特点**：
- 深度学习模型集合（Informer、Autoformer、FEDformer等）
- 学术论文代码复现
- 标准数据集与评测

**优势**：
- 模型种类全面
- 代码质量较高，复现可靠
- 学术研究价值大

**限制**：
- 工程化程度相对较低
- 主要面向研究而非生产

**适用场景**：
- 算法研究与对比
- 论文复现与验证
- 模型改进实验

## 选择决策树

```
开始
├── 数据规模小 (<1000样本) → tsproj_stat
├── 需要强可解释性 → tsproj_ml 或 tsproj_stat
├── 评估基础模型能力 → tsproj_ltsfm
├── 大数据/复杂模式 → tsproj_dl
├── 算法研究/论文复现 → Time-Series-Library
└── 生产项目/工程化需求 → tsproj_ml 或 tsproj_dl（根据方法偏好）
```

## 组合使用建议

1. **研究到生产流水线**：
   - 探索阶段：Time-Series-Library（算法筛选）
   - 验证阶段：tsproj_ltsfm（基础模型评估）或 tsproj_ml/tsproj_stat（传统方法对比）
   - 工程化阶段：tsproj_dl 或 tsproj_ml（根据最终方法选择）

2. **混合方法策略**：
   - 使用 tsproj_stat 建立统计基线
   - 用 tsproj_ml 尝试机器学习方法
   - 用 tsproj_dl 探索深度学习潜力
   - 通过 tsproj_ltsfm 评估最新基础模型

3. **风险对冲**：
   - 同时在 2-3 个框架上实现关键业务预测
   - 定期用 tsproj_ltsfm 评估新模型是否值得引入
