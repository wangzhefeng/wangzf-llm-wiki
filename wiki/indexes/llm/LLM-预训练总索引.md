# LLM-预训练总索引

## 总览

LLM 预训练是从原始文本数据中自动学习通用语言表示的过程。本主题系统讲解预训练的全流程：从海量数据的收集与清洗、分词与 token 化、缩放定律对模型大小和数据量的约束、分布式训练策略（DDP/FSDP）的工程实现、到模型检查点、评估指标等核心环节。缩放定律（Scaling Laws）是理解现代大模型的关键——它表明模型性能与参数数量、数据量、计算量之间的幂律关系，指导了 GPT-3、LLaMA、Claude 等大模型的训练投资决策。分布式训练则通过数据并行、张量并行、流水线并行等多种策略，使在数十万 GPU 上训练千亿参数模型成为可能。本主题还涵盖检查点管理、多阶段训练、混合精度训练等实践工程知识。
