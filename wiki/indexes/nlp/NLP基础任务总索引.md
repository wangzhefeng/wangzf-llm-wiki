# NLP 基础任务总索引

## 总览

自然语言处理（NLP）的基础任务形成了整个 NLP 系统的基石，这些任务将非结构化的文本序列逐步转化为可理解的语言结构。本索引涵盖 NLP 的五大基础任务：**分词**（词序列化）、**词性标注**（语法属性标注）、**命名实体识别**（专有名词提取）、**句法分析**（语法结构建模）和**文本分类**（语义分类）。

这些任务既可以独立完成，也通常以流水线方式组合使用，共同构成 NLP 应用系统的核心处理管道。掌握这五项任务是进阶到情感分析、知识图谱、机器翻译等应用任务的必要基础。

## 核心概念导航

| 任务 | 一句话定义 | 关键方法 | 代表工具 |
|-----|---------|--------|--------|
| [[分词]] | 将连贯文本序列切分成有意义的词汇单位 | 规则匹配、HMM、CRF、神经网络 | jieba、spaCy |
| [[词性标注]] | 为每个词分配其语法属性（名词、动词、形容词等） | HMM、CRF、BiLSTM、Transformer | jieba、spaCy、nltk |

| [[句法分析]] | 构建句子的语法结构树，揭示词汇间的依存或成分关系 | 依存分析、转移系统、图神经网络 | spaCy、StanfordNLP |
| [[文本分类]] | 将文本文档自动分配到预定义的类别集合中 | 朴素贝叶斯、SVM、逻辑回归、神经网络 | scikit-learn、PyTorch |

## 知识体系定位

这五大基础任务位于 NLP 知识体系的**最下层**，作为所有高级应用（知识图谱、情感分析、机器翻译）的前置处理步骤。其特点是：
- **输入高度非结构化**：原始文本字符序列
- **输出结构化程度不同**：从词序列到语法树
- **方法论完整**：包含规则、统计、神经三代方法
- **适用范围广**：中英文、多领域都有成熟实现

1. 理解为什么需要分词（中文与英文的差异）→ [[分词]]

4. 实践：使用 jieba 和 spaCy 完成这三项任务的自动化

### 中级路径：深入方法论
1. 对比规则、统计、神经方法在各任务中的优缺点
2. 学习序列标注框架（BIO/BIOES 标签体系）理解 NER 和词性标注的统一视角
3. 深入学习 HMM、CRF 模型在词标注中的应用 → [[命名实体识别]]（方法论）
4. 理解 Transformer 如何改进 NLP 基础任务

### 高级路径：系统设计与应用
1. [[句法分析]]：从依存到成分，理解深层语法结构
2. [[文本分类]]：作为 NLP 基础任务与应用任务的桥梁
3. 设计工业级 NLP 流水线：何时使用序列标注，何时使用分类
4. 跨越到高级应用：如何使用基础任务的输出完成 [[知识图谱]] 和 [[机器翻译]]
