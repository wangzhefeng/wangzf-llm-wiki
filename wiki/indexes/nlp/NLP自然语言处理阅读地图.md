## 学习路径推荐

### 路径 A：工程实践优先
工具实操（spaCy/fastHan）→ 基础任务实现 → 应用任务（分类/摘要/问答）→ 接入 LLM

### 路径 B：理论优先
NLP 全景 → 词向量原理 → 序列模型（CRF/LSTM）→ 注意力/Transformer → LLM

### 路径 C：特定场景
- 中文信息抽取：分词 → NER → 关系抽取 → 知识图谱
- 文本分析平台：分类 → 情感分析 → 关键词 → 搜索（Solr）
