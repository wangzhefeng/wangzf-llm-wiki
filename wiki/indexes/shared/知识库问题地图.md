# 知识库问题地图

> **定位说明**：本页是 [[知识库问答与研究工作流]] 的**输入选择器**，不作为独立工作流使用。
> 使用顺序：先在本页选定问题 → 再进入问答工作流执行。

这页回答：**当前库里哪些问题已经值得直接发起 query。**

## 怎么用这页

1. 先从下面选一个问题
2. 带着问题进入 [[知识库问答与研究工作流]]，按每个问题后面的”建议入口”指定上下文页
3. 问答完成后，把结果写进 `outputs/answers/` 或 `outputs/syntheses/`
4. 如果形成了新问题或新缺口，再回来更新这页
