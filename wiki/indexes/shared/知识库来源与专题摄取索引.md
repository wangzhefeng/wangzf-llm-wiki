# 知识库来源与专题摄取索引

## 定位说明

这页收口”如何把新资料和新专题纳入知识库”。它不讲知识库为什么这样设计，而只回答”现在该用哪个 intake 入口”。

> 整合说明：本页位于 `shared/` 根目录，作为 ingest 执行入口页；构建方法论与完整边界以 [[LLM-Wiki总索引]] 为准。

## 适合场景

- 新增一篇网页、一个仓库或一份本地材料
- 想把一个新专题批量纳入当前知识库
- 已经知道资料范围，但不确定应该先补 sources 还是先做 indexes

## 关键资源

### 单份来源摄取

- `prompts/intake/source-summary`
- `prompts/intake/web-source-intake`
- `prompts/intake/repo-source-intake`
- `prompts/intake/paper-source-intake`
- `prompts/intake/dataset-source-intake`
- `prompts/intake/image-source-intake`
- `prompts/intake/local-note-source-intake`

### 整体专题摄取

- `prompts/topic-intake/topic-intake-plan`
- `prompts/topic-intake/topic-intake-execute`

### 方法论入口

- [[LLM-Wiki总索引]]

## 执行步骤

1. 单份资料：先确认来源类型（网页 / 仓库 / 论文 / 本地笔记），选对应 prompt 执行
2. 大专题：先用 `topic-intake-plan` 做计划，再用 `topic-intake-execute` 执行
3. 摄取完成后在 `wiki/sources/` 落来源卡，更新对应主题总索引

## 摄取历史

历史摄取动作（如专题建模、批量摄取等）记录在操作日志，不在本页维护：

- [[知识库操作记录索引]]：全库操作时间线
- `outputs/logs/`：历史摄取动作详细记录

## 后续动作

- 记录本轮动作 → [[知识库操作记录索引]]
