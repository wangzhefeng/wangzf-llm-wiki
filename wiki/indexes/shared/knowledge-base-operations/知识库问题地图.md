# 知识库问题地图

这页不是主题正文，而是全库“从哪里开始问”的共享入口。它回答的是：**当前这个知识库里，哪些问题已经值得直接发起 query。**

## 怎么用这页

1. 先从下面选一个问题
2. 再按每个问题后面的“建议入口”给 Codex 指定上下文页
3. 问答完成后，把结果写进 `outputs/answers/` 或 `outputs/syntheses/`
4. 如果形成了新问题或新缺口，再回来更新这页
