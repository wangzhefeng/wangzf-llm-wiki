# 知识库操作记录索引

这页负责全库的时间导航。它不回答”某个主题里有什么”，而回答：**最近 ingest、query、lint、backfill、task 都做了什么。**

## 这页的作用

- 记录时间线，而不是内容结构
- 帮助下一轮维护快速接上上一轮动作
- 避免高价值操作只存在于对话上下文里

## 当前记录存放位置

- `outputs/logs/`

## 怎么总结一轮操作

每次完成一轮操作后，在 `outputs/logs/` 新建一个记录文件。

**命名规则**：`YYYY-MM-DD-主题-动作记录.md`

**记录模板**：

```markdown
---
date: YYYY-MM-DD
operation_type: ingest | query | lint | backfill | task
topic: 主题或范围名称
summary: 一句话总结本次动作
---

## 做了什么

（具体动作列表，使用 - 条目）

## 影响与变化

（本次操作对知识库的影响：新增了哪些文件、修改了哪些索引、修复了哪些链接）

## 遗留与待办

（下一轮应继续的事项）
```

**推荐搭配的 Prompt**：`prompts/logging/operation-log`

## 5 类操作记录标准

| 操作 | 典型记录内容 |
|---|---|
| `ingest` | 新增来源数量、来源卡位置、更新的索引 |
| `query` | 问题描述、输出位置、回流情况 |
| `lint` | 检查范围、发现的问题、修复数量 |
| `backfill` | 回流的输出页、补充的索引入口、新增的概念页 |
| `task` | 任务描述、输出文件、知识库变更 |

## 使用顺序建议

1. 新一轮整理前，先看最近 1 到 3 条记录
2. 确认上一轮补了什么、还缺什么
3. 再回到对应的工作流页继续做
