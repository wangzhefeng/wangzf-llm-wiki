# 知识库操作记录索引

这页负责全库的时间导航。它不回答”某个主题里有什么”，而回答：**最近 ingest、query、lint、backfill、task 都做了什么。**

## 这页的作用

- 记录时间线，而不是内容结构
- 帮助下一轮维护快速接上上一轮动作
- 避免高价值操作只存在于对话上下文里

## 当前记录存放位置

- `wiki/log.md`

## 怎么总结一轮操作

每次完成一轮操作后，直接向 `wiki/log.md` 追加一条记录。

**标题规则**：`## [YYYY-MM-DD] action | subject`

**记录模板**：

```markdown
## [YYYY-MM-DD] action | subject

- 目标：一句话说明本轮处理什么问题
- 入口与证据：列出关键 `raw/`、`wiki/`、`outputs/` 页面
- 实际动作：新增、更新、删除了哪些文件或入口
- 影响与变化：本轮补齐了什么，还剩什么
- 下一步：最多 3 条下一步
```

**推荐搭配的 Prompt**：`prompts/logging/operation-log`

## 5 类操作记录标准

| 操作 | 典型记录内容 |
|---|---|
| `ingest` | 新增来源数量、来源卡位置、更新的索引 |
| `query` | 问题描述、输出位置、回流情况 |
| `lint` | 检查范围、发现的问题、修复数量 |
| `backfill` | 回流的输出页、补充的索引入口、新增的概念页 |
| `task` | 任务描述、输出文件、知识库变更 |

3. 再回到对应的工作流页继续做
