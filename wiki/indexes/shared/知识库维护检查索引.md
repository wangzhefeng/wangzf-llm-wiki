# 知识库维护检查索引

## 定位说明

这页收口"如何检查当前知识库是否还健康"。如果你已经做完一轮 intake、研究、开发或输出回流，优先从这里开始收尾。

> 整合说明：本页位于 `shared/` 根目录，作为 lint 运维执行入口页；运维职责定义与完整边界以 LLM-Wiki总索引 为准。

## 适合场景

- 想知道当前库里最大的结构缺口是什么
- 想检查新来源、新索引、新输出是否已经回链
- 想在开始下一轮整理前先看上一轮遗留问题

## 关键资源

- LLM-Wiki总索引：运维边界与完整入口
- [[知识库-健康检查-最新]]：最近一次健康检查主报告
- [[知识库健康检查清单]]：逐项核查清单
- [[知识库-健康检查-日志]]：历史检查记录
- `prompts/maintenance/wiki-lint`
- `prompts/maintenance/llm-wiki-health-check`

## 执行步骤

1. 先读 LLM-Wiki总索引 了解运维边界与入口
2. 再读 [[知识库-健康检查-最新]]，确认本轮优先级
3. 运行标准检查命令：
   - `python3 .env/health/wiki_check.py --checks lint`
   - `python3 .env/health/wiki_check.py --checks health`
   - 或 `python3 .env/run_tool.py health check`
4. 先清真实 wikilink 错误，再刷新 sources / indexes / concepts，不带病重编译
5. 按 [[知识库健康检查清单]] 解读结果，必要时调用对应 prompt
6. 覆盖更新主报告，增量更新统一日志

## 当前收尾标准

- `lint` 继续通过
- `health` 的真实 wikilink 错误清零
- warning 要么顺手收敛，要么在主报告中被明确定义为当前允许边界
