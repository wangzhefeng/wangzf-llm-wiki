# wiki/indexes/shared

`shared/` 是知识库共享执行层：根目录存放跨主题工作流，子目录存放三主题定义层页面。

## 目录契约

- `shared/` 根目录：执行工作流与工作台
- `shared/llm-wiki-building/`：构建方法论（原则、阅读地图、来源清单）
- `shared/llm-wiki-operations/`：运维治理（运维总索引、运维阅读地图、运维来源清单）
- `shared/llm-wiki-usage/`：使用方法（使用总索引、使用阅读地图、使用来源清单）

## 使用建议

- 先从 [[知识库工作台]] 选择执行动作，再进入对应工作流页。
- 主题目录只承载定义与导航，不承载执行流正文。
