## 关键概念导航

```
MDP 基础
  → 贝尔曼方程 / 价值函数
    → Q-Learning（表格）
      → DQN（深度价值）
        → DDPG（连续动作）
          → Actor-Critic / A3C
            → PPO（策略优化）
              → GRPO（群体相对）
                → RLHF / DPO（对齐）
```
