# 机器学习阅读地图

## 阅读路线

### 第 1 站：建立机器学习直觉

**目标**：理解"机器学习是什么、有哪些类型、建模的完整流程"

- 先看 [[机器学习概览]]，了解监督/无监督/半监督的基本区别
- 再看建模 9 步流程（架构 → 数据 → 研究 → 准备 → 选模型 → 微调 → 展示 → 运维 → 优化）
- 重点理解偏差/方差权衡和过拟合/欠拟合
- 读完应该能回答：
  - 机器学习和传统编程的差异是什么？
  - 过拟合和欠拟合如何识别和应对？
  - 一个完整的 ML 项目包含哪些步骤？

**来源**：[[2023-02-24-机器学习概览]]

### 第 3 站：特征工程

### 第 4 站：核心算法

**目标**：掌握最常用的监督/无监督算法

**监督学习线**：
- [[线性回归]] → [[逻辑回归]] → [[决策树]] → [[支持向量机]] → [[K 近邻]]
- 重点：线性模型的假设、SVM 的核方法、决策树的可解释性

**无监督学习线**：
- [[聚类分析]] → 按方法类型阅读（K-Means → 层次 → DBSCAN → GMM）
- 重点：不同聚类方法的适用场景

**集成学习线**：
- [[集成学习]] → 随机森林 → GBDT → XGBoost → LightGBM → CatBoost
- 重点：Bagging vs Boosting 的本质区别

读完应该能回答：
- 什么场景下用什么算法？
- 集成学习为什么通常比单一模型好？
- 核方法如何解决非线性问题？
