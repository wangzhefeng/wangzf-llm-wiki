# 因果推断阅读地图

> 阶梯式学习路径：从基础概念到完整方法库

## 初级：理论基础

**前置要求**：基本统计学知识（均值、方差、相关性）

### 为什么需要因果推断？

从 [[2023-07-09-Yule-Simpson悖论与因果推断基础]] 开始：

- **Yule-Simpson 悖论** — 相关性为何不等于因果性？
  - Berkeley 录取率案例：总体上男性录取率高，但分专业后反而女性更高
  - 理解混杂偏倚（confounding bias）的危害

### 因果推断的基础框架

- **[[Rubin Causal Model]]** 概念页 — 潜在结果、个体与平均因果作用
  - 为什么我们无法直接观测个体因果作用？
  - 随机化如何解决可忽略性问题？
  
- **[[Causal Diagram]]** 概念页（可选）— 有向无环图直观表达

## 中级：应用方法与工具

**前置要求**：理解 RCM 基本概念，掌握回归分析

### 现实中的因果问题分类

从 [[2023-07-12-因果分析概念与方法论]] 深入：

- **因果分析三分类**
  - 原因 → 结果：因果推断（AB Test、RDD、DID）
  - 结果 ← 原因：逆向分析（鱼骨图）
  - 原因 ↔ 结果：互推（公式推导）

- **[[Propensity Score]]** 概念页 — 观察性研究的救星
  - 为什么需要倾向得分？
  - 匹配、分层、IPW 三种应用

### 工具与实现

学习 [[2023-07-15-DoWhy框架与工作流]]：

- 为什么 DoWhy 统一了图模型与潜在结果框架？
- **[[DoWhy Framework]]** 概念页 — 四步骤工作流
  1. **建模**（Model）— 将因果假设形式化为因果图
  2. **识别**（Identify）— 基于因果图确定可识别的因果效应表达式
  3. **估计**（Estimate）— 应用统计方法估计因果效应
  4. **反驳**（Refute）— 多种鲁棒性检查验证结论

## 高级：完整方法库

**前置要求**：掌握回归分析、面板数据、实验设计

### 各类情景的因果推断方法

从 [[2023-07-25-因果推断理论框架]] 系统学习：

- **[[Causal Inference Methods]]** 概念页 — 方法库完整对比

| 数据类型 | 情景 | 适用方法 | 关键假设 |
|---|---|---|---|
| 随机化数据 | 对照试验 | RCT（基准） | 随机化满足 |
| 观察数据 | 无自选 + 良好控制 | 回归调整、倾向评分 | 可忽略性 |
| 自然实验 | 排除限制成立 | 工具变量（IV）| 相关性、外生性 |
| 政策冲击 | 平行趋势成立 | 双重差分（DID） | 平行趋势 |
| 单个单位处理 | 无控制组 | 合成控制法 | 预处理期特征平衡 |
| 门槛效应 | 分割点明确 | 断点回归（RDD） | 连续性 |

### 深度理解各方法

- **工具变量（IV）与 2SLS**
  - 何时使用？相关性与外生性如何验证？
  
- **双重差分法（DID）**
  - 平行趋势假设如何检验？
  
- **断点回归设计（RDD）**
  - Sharp vs Fuzzy RDD 的区别

- **合成控制法（Synthetic Control）**
  - 权重构造与效应估计

## 学习建议

### 路径 A：理论优先（推荐学生）
初级 → 中级理论 → 高级理论 → 动手实践（DoWhy）

### 路径 B：问题驱动（推荐从业者）
从实际问题出发 → 判断适用方法（看方法库对比表） → 回溯理论基础 → DoWhy 实现

### 路径 C：工具优先（推荐快速上手）
DoWhy 工作流 → 具体方法 → 理论理解

## 常见问题

A：检查可忽略性假设是否合理。[[Rubin Causal Model]] 与 [[Propensity Score]] 两页会帮助判断。

**Q：DoWhy、CausalML、EconML 如何选择？**

**Q：如何验证我的因果结论？**
