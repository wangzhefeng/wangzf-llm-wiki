# Vibe-Coding工作流

> Vibe Coding 相关的工作流方法论与实践。

## 概述

Vibe Coding 工作流强调与 AI Agent 的自然协作、工具调用、RAG 与技能化工作流。

## 核心步骤

1. **环境配置** - 设置 AI Agent 工具链（Claude Code, Codex, MCP 等）
2. **任务分解** - 将复杂任务拆解为可执行的子任务
3. **工具调用** - 利用 AI Agent 调用合适的工具
4. **迭代优化** - 基于反馈循环持续改进输出
5. **知识沉淀** - 将经验沉淀为可复用的技能
