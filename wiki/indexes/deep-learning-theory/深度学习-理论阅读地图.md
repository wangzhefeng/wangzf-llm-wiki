# 深度学习-理论阅读地图

> 从数学基础到工程实践的完整学习路线
>
> 最后更新：2026-04-15

本地图为"深度学习理论"专题提供 **6 阶段递进式学习路线**，从数学基础出发，逐步深入各个架构族与工程实践。

## 第 1 站：深度学习数学基础

### 目标
理解神经网络如何通过反向传播和梯度下降进行参数优化。这是所有深度学习的基石。

### 核心问题
- 反向传播是什么？为什么神经网络能通过它自动计算梯度？
- 激活函数为什么不可少？各种激活函数有什么区别？
- 优化器的演进路线是什么（SGD → Adam）？

### 推荐学习路径

**第一步：反向传播与梯度**
- 阅读：[[2022-07-15-model-backpropagation]]
- 问题：链式法则如何应用到深层网络？
- 挑战：理解梯度消失/爆炸的原因

**第二步：激活函数**
- 阅读：[[2023-03-21-model-activation]]
- 对比：Sigmoid / Tanh / ReLU / GELU 的特性
- 实践：为什么 ReLU 成为默认选择？

**第三步：优化算法演进**
- 阅读：[[2022-07-15-model-optimizer]]
- 演进链：SGD → Momentum → AdaGrad → RMSProp → Adam
- 问题：不同优化器何时该用？

**补充阅读**：
- [[2026-04-11-2-Mathematical-Background-–-S&DS-431631-—-Optimization-and-Computation.md]] - 优化的数学严格推导

## 第 2 站：CNN 家族 - 从 LeNet 到现代架构

### 目标
理解卷积网络的设计思想与演进路线，掌握计算机视觉的基础范式。

### 核心问题
- 为什么卷积比全连接更适合图像？
- CNN 家族的演进逻辑是什么（LeNet → VGG → ResNet）？
- 现代高效网络（MobileNet、ShuffleNet）是如何优化的？

### 推荐学习路径

**第一步：CNN 基础概念**
- 阅读：[[2023-03-20-cnn-step]] - 分步讲解卷积、池化、全连接
- 核心：感受野、特征图、卷积滤波器的直观理解
- 实践：手工计算一个卷积操作的输出

**第二步：经典 CNN 网络演进（时间顺序）**

1. **LeNet-5** (1998)
   - 阅读：[[2023-01-27-cnn-lenet-5]]
   - 问题：为什么 LeNet 能识别手写数字？
   - 意义：神经网络的第一次工程成功

2. **AlexNet** (2012)
   - 阅读：[[2023-03-23-cnn-alexnet]]
   - 突破：深度、数据、计算力
   - 影响：深度学习复兴的标志

3. **VGG** (2014)
   - 阅读：[[2023-03-23-cnn-vgg]]
   - 洞察：深度 > 宽度
   - 设计：小卷积核的堆叠

4. **ResNet** (2015)
   - 阅读：[[2023-03-23-cnn-resnet]]
   - 创新：残差连接解决深度网络训练
   - 影响：打开了超深网络的大门

5. **GoogLeNet/Inception** (2014)
   - 阅读：[[2023-03-23-cnn-googlenet]]
   - 思想：多分支、多尺度特征
   - 效率：Inception 模块设计

**第三步：现代高效 CNN**

1. **MobileNet** (2017) - 移动端
   - 阅读：[[2023-03-23-cnn-mobilenet-v1]]
   - 创新：深度可分离卷积
   - 目标：参数少、速度快

2. **DenseNet** (2016)
   - 阅读：[[2023-03-23-cnn-densenet]]
   - 特点：密集连接、梯度流通畅

3. **ShuffleNet** (2017)
   - 阅读：[[2023-03-23-cnn-shufflenet-v1]]
   - 创新：通道混洗（Group Conv + Channel Shuffle）

**第四步：可视化与理解**
- 阅读：[[2023-03-24-cnn-zfnet]] - 卷积网络的可视化理解

## 第 3 站：序列与生成模型 - RNN 家族

### 目标
理解如何用神经网络处理序列数据，从经典 RNN 到现代 Transformer 的前身。

### 核心问题
- RNN 为什么能处理可变长度的序列？
- 为什么经典 RNN 容易梯度消失？LSTM 如何解决？
- 生成模型（GAN）的基本原理是什么？

### 推荐学习路径

**第一步：RNN 基础**
- 阅读：[[2022-07-15-models-rnn]]
- 概念：隐藏状态、展开、时间步
- 问题：为什么长序列时梯度会消失？

**第二步：门控机制 - 解决长期依赖**

1. **LSTM** (1997 提出，2015 后广泛)
   - 阅读：[[2022-07-15-models-rnn-lstm]] 和 [[2026-04-06-Long-Short-Term-Memory-(LSTM).md]]
   - 创新：三个门（输入、遗忘、输出）控制信息流
   - 效果：能够学习长期依赖

2. **GRU** (2014)
   - 阅读：[[2022-07-15-models-rnn-gru]]
   - 简化：合并遗忘门和输入门，参数少
   - 权衡：性能相当，计算更轻

**第三步：Seq2Seq 与 NMT**
- 阅读：[[2022-07-15-dl-seq2seq]]
- 应用：机器翻译、文本生成
- 架构：Encoder-Decoder with Attention（Attention 的前身）

**第四步：生成对抗网络 (GAN)**
- 阅读：[[2022-07-15-dl-gan]]
- 原理：两个网络（生成器 vs 判别器）的博弈
- 应用：图像生成、风格转移等

### 检验清单
- [ ] 能用图示说明 RNN 如何处理可变长序列
- [ ] 理解 LSTM 的三个门各自的作用
- [ ] 知道 GRU 相比 LSTM 的简化与优化
- [ ] 理解 GAN 的两网络博弈逻辑

## 第 4 站：Transformer 与现代范式

### 目标
理解自注意力机制和 Transformer 架构，掌握现代深度学习的主流范式。

### 核心问题
- Attention 是什么？为什么它比 RNN 更强？
- Transformer 的架构设计有什么智慧？
- 为什么 Transformer 能扩展到万亿参数？

### 推荐学习路径

**第一步：Attention 机制**
- 必读：[[2022-07-15-dl-attention]]
- 视角：查询-键-值（Query-Key-Value）
- 意义：模型能"动态关注"输入的不同部分

**第二步：自注意力（Self-Attention）**
- 阅读：[[2026-04-06-超详细图解Self-Attention.md]]
- 特点：输入自己和自己做 Attention
- 作用：捕捉输入内部的依赖关系

**第三步：完整 Transformer 架构**
- 必读：[[2022-07-15-dl-transformer]]
- 推荐补充：
  - [[2026-04-06-Transformer深入浅出.md]] - 中文深度讲解
  - [[2026-04-06-读懂Transformer的内核，了解大模型基石.md]] - 大模型视角
  - [[2026-04-06-StatQuestdecoder_transformer_from_scratch.md]] - 从零实现
  - [[2026-04-06-译-Transformer-是如何工作的：600-行-Python-代码实现-self-attention-和两类-Transformer（2019）.md]] - 代码实现

**第四步：Transformer 应用扩展**

1. **T5 统一框架** (2019)
   - 阅读：[[2023-03-17-dl-t5]]
   - 思想：用 Transformer 统一 NLP 各类任务

2. **Vision Transformer (ViT)** (2020)
   - 阅读：[[2026-04-06-Vision-Transformers-(ViTs)-Computer-Vision-with-Transformer-Models.md]]
   - 突破：将 Transformer 应用于计算机视觉
   - 路线：Patch Embedding → Transformer Encoder → Classification

3. **Sentence Transformer** - 文本相似度
   - 阅读：[[2026-04-06-Semantic-Textual-Similarity-—-Sentence-Transformers-documentation.md]]

4. **Mamba：后 Transformer 时代** (2023)
   - 阅读：[[2026-04-06-一文通透想颠覆Transformer的Mamba：从SSM、HiPPO、S4到Mamba(被誉为Mamba最佳解读)_mamba模型-CSDN博客.md]]
   - 问题：Transformer 的线性注意力成本能否优化？
   - 答案：用状态空间模型 (SSM) 取代注意力

**第五步：Transformer 可视化**
- 补充：[[2026-04-06-Transformers-Laid-Out.md]]

   - 优点：每个 GPU 独立反向传播，高效通信

3. **多进程最佳实践**
   - 阅读：[[2026-04-06-Multiprocessing-best-practices.md]]

**第二步：内存优化 - FSDP (Fully Sharded Data Parallel)**
- 必读：[[2026-04-06-FullyShardedDataParallel.md]]
- 快速开始：[[2026-04-06-Getting-Started-with-Fully-Sharded-Data-Parallel-(FSDP2).md]]

**第四步：超大规模训练**

### 时间规划

| 第 1-2 站 | 2-3 | 数学基础与 CNN 经典架构 |

**有 ML 基础的人**
1. 快速浏览第 1 站数学部分（1 周）
2. 深入第 2-4 站架构（3 周）
3. 重点是第 5-6 站工程实践（2 周）

**初学者**
1. 逐步完成全部 6 站（3 个月）
2. 每站完成后做小项目（CNN、RNN、Transformer）
3. 最后用分布式框架复现一个中等规模的模型

**工程师快速上手**
1. 跳过第 1-3 站推导
2. 快速了解第 4 站 Transformer
3. 重点深入第 5-6 站（分布式训练）
