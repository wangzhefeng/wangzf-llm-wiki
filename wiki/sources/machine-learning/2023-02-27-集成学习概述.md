# 来源卡：集成学习概述

## 这份材料讲了什么

- 原文：[[raw/local-notes/machine-learning/supervised/ensemble/2023-02-27-ml-ensemble-learning/index.md]]
集成学习是当前机器学习中最强大的预测方法之一，覆盖：

1. **集成学习基础**：Bagging、Boosting、Stacking 三大范式
2. **代表算法族**：
   - 随机森林（Bagging 代表）
   - GBDT/AdaBoost（Boosting 代表）
   - XGBoost（高效梯度提升）
   - LightGBM（大规模数据优化）
   - CatBoost（类别特征原生支持）

## 价值是什么

- 是监督学习专题中最实用的算法族
- 提供了从理论到 API 使用的完整链路
- 每个子算法都有独立的原理篇和 API 篇
