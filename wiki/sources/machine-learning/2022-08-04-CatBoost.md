# 来源卡：CatBoost

## 这份材料讲了什么

- 原文：[[raw/local-notes/machine-learning/supervised/ensemble/catboost/2022-08-04-ml-gbm-catboost/index.md]]
这篇材料重点讨论 CatBoost 如何处理类别特征与预测偏移问题，主线包括：

1. CatBoost 在类别特征场景中的定位与相对优势
2. 预测偏移在目标编码和梯度提升中的两类来源
3. Ordered TS、Ordered Boosting 等关键机制
4. 类别特征编码、高低基数特征处理和特征组合的策略

## 价值是什么

- 是集成学习专题里最能连接“树模型”和“特征工程”的一张来源卡
- 对类别特征较多的业务场景有很强实践价值
- 能补足 XGBoost / LightGBM 在类别特征处理上的短板认知
