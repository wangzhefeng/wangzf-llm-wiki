# 来源卡：线性回归

## 这份材料讲了什么

- 原文：[[raw/local-notes/machine-learning/supervised/2023-02-24-ml-linear-regression/index.md]]
线性回归是监督学习最基础的算法，覆盖：

1. **线性回归原理**：最小二乘法、解析解、梯度下降
2. **模型评估**：R²、MSE、MAE
3. **多项式回归**：非线性关系的线性建模
4. **正则化**：Ridge、Lasso、Elastic Net

## 价值是什么

- 是理解监督学习的"第一课"
- 正则化方法是控制过拟合的基础
- 与运筹优化专题的"线性规划"形成方法对照
