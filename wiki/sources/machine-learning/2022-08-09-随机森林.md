# 来源卡：随机森林

## 这份材料讲了什么

- 原文：[[raw/local-notes/machine-learning/supervised/ensemble/2022-08-09-ml-random-forest/index.md]]
这篇材料围绕随机森林的构造逻辑、性质和参数展开，主线包括：

1. Bootstrap 抽样和随机特征选择构成的“双随机性”
2. 决策树作为基学习器时的训练流程与 OOB 误差机制
3. 随机森林在分类、回归、特征选择中的典型用途
4. 模型优缺点、泛化误差、参数设置和适用场景

## 价值是什么

- 是 Bagging 系方法中最值得优先沉淀的代表来源
- 既能支撑集成学习概念，也能连接特征重要性和基准模型实践
- 对理解“单棵树”与“树集成”的差异很关键
