# 来源卡：决策树

## 这份材料讲了什么

- 原文：[[raw/localnotes/machine-learning/supervised/2022-08-09-ml-decision-tree/index.md]]
这篇材料系统介绍了决策树从建模到实现的主链条，覆盖：

1. 决策树作为规则集合与树状结构的基本表达
2. 特征划分准则：信息增益、信息增益率、Gini 指数
3. ID3、C4.5、CART 在分裂准则上的差异
4. 预剪枝、后剪枝和 sklearn 中分类/回归树的实现方式

## 价值是什么

- 是从“可解释的单模型”过渡到“树模型家族”的基础来源
- 为随机森林、GBDT 等集成方法提供了基学习器背景
- 适合作为后续补齐决策树概念页和树模型阅读路线的核心材料
