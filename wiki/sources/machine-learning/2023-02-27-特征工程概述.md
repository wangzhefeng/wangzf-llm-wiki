# 来源卡：特征工程概述

## 这份材料讲了什么

- 原文：[[raw/local-notes/machinelearning/model-utils/feature-engine/2023-02-27-feature-engine/index]]
特征工程是决定模型性能上限的关键步骤，覆盖：

1. **特征工程总览**：特征构建、缺失值处理、类型转换、重采样
2. **按数据类型的特征处理**：数值型、类别型、文本、图像、音频
3. **特征选择**：过滤法、包裹法、嵌入法
4. **异常值检测**：特征层面的异常识别
5. **重采样策略**：分类问题和回归问题的不同重采样方法

## 价值是什么

- 是特征工程专题的"总入口"
- 按数据类型组织处理方法，工程实用性强
- 与时间序列专题的"特征工程"形成互补
