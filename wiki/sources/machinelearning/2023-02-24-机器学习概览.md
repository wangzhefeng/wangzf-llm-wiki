# 来源卡：机器学习概览

## 这份材料讲了什么

- 原文：[[raw/local-notes/machinelearning/2023-02-24-ml/index]]
一份机器学习系统性入门材料，覆盖：

1. **机器学习系统的种类**：监督/无监督/半监督学习、批量/在线学习、基于实例/基于模型的学习
2. **机器学习的主要挑战**：训练数据不足/不代表性/质量差、无关特征、过拟合/欠拟合、偏差/方差权衡
3. **机器学习建模法则**：9 步完整流程（架构问题 → 获取数据 → 研究数据 → 准备数据 → 列出期望模型 → 微调模型 → 展示方案 → 启动监视维护 → 模型优化）
4. **实践项目**：泰坦尼克之灾、房价预测、数字识别

## 价值是什么

- 是机器学习专题的"总入口"文档，提供了从理论到实践的完整框架
- 建模 9 步流程是工程化的最佳实践总结
- 偏差/方差权衡的分解（泛化误差 = 偏差 + 方差 + 噪声）是理解过拟合/欠拟合的核心工具
