# Python 数值优化求解器实践来源摘要

- 原文：[[raw/notes/operations-research/2024-09-03-python-optimization/index.md]]

## 材料定位

这是专题内最详细的求解器工程实践文档（70KB+，2100+ 行），系统覆盖 Python 生态中三大主流商业/开源求解器的完整使用指南：
- **Gurobi**：线性/整数规划，工业级性能，Python API 完整
- **SCIP**：开源约束整数规划求解器，支持 MINLP、Pseudoboolean、SAT
- **CPLEX**：IBM 商业求解器，CPLEX Studio IDE

## 关键结论

### Gurobi Python API

**数据结构**：
- `Multidict`：一键创建多个一维决策变量
- `Tuplelist`：元组列表，支持高效筛选
- `Tupledict`：稀疏数据结构，加速约束收集

**核心操作**：
- 线性化技巧：max/min/absolute/and/or/indicator/piecewise linear
- Callback：控制求解过程（割平面、根松弛、可行解回调）
- 参数系统：`Model.setParam()` + `Param.*` 常量

**建模示例**：
- 多工厂排产问题
- 供应网络设计问题

### SCIP 特性

**解决的问题类型**（全面覆盖）：
- Linear Program (LP)
- Mixed-Integer Linear Program (MILP)
- Mixed-Integer NonLinear Program (MINLP)
- Constraint Integer Program (CIP)
- Convex MINLP
- Pseudoboolean optimization
- Satisfiability (SAT) and variants
- Multicriteria optimization
- Mixed-Integer SemiDefinite Program (MISDP)

**安装**：Conda 和 pip 两条路径

### CPLEX Python API

**安装方式**：
- pip：`pip install cplex`
- conda：`conda install -c ibmdb cplex`
- CPLEX Studio：完整 IDE 环境

**两类 API**：
- Mathematical Programming API（变量约束直接操作）
- Constraint Programming API（ scheduling、routing 等组合优化问题）
