# Clarabel 内点求解器来源摘要

- 原文：[[raw/web/operations-research/2026-04-06-oxfordcontrolClarabel.rs-Clarabel.rs-Interior-point-solver-for-convex-conic-optimisation-problems-in-Rust]]
- 工具：Clarabel.rs（Oxford Control Group，Rust + Python，开源 MIT 协议）

## 材料定位

Clarabel 是由牛津大学控制组开发的新一代内点求解器，基于 Rust 实现，支持凸锥优化（LP/QP/SOCP/SDP）。它是 CVXPY 1.x 的默认求解器之一，也是当前最活跃的开源内点法实现。

## 关键结论

- **核心算法**：同态嵌入（Homogeneous Embedding）内点法，处理原问题 + 对偶问题的联合嵌入，避免可行性假设。
- **支持的锥类型**：非负锥（LP）、二阶锥（SOCP）、正半定锥（SDP）、指数锥（GP）、幂锥。
- **语言**：Rust 实现（高性能、内存安全），提供 Python 绑定（`clarabel` 包）；另有 Julia 版本 Clarabel.jl。
- **集成**：CVXPY 默认调用；JuMP（Julia）可选调用；支持 MathOptInterface 接口标准。
- **开源优势**：MIT 协议，无许可证限制；对 SOCP/SDP 问题是 CVXOPT、SCS 的高质量替代。
- **适用范围**：中小规模凸锥问题；学术研究和工程原型；不适合超大规模 MILP（无整数支持）。
