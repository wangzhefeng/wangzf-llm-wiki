# Gurobi 优化器文档来源摘要

- 原文：[[raw/web/operations-research/2026-04-06-Getting-Started-with-Gurobi-Optimizer]]
- 工具：Gurobi Optimizer（商业 LP/QP/MILP/MIQP 求解器，行业标准）

## 材料定位

Gurobi 是当前运筹优化领域最主流的商业求解器，覆盖 LP、QP、MILP、MIQP、MIP 等问题类型。这组文档提供了官方 GitHub 项目入口、Help Center 支持中心、新手入门指南和建模示例集合。是使用 Gurobi 做工程建模的主要参考来源。

## 关键结论

- Gurobi 支持问题类型：LP、QP（二次目标）、QCP（二次约束）、MILP、MIQP、MIQCP，及非凸二次规划。
- Python API（gurobipy）是最主流接口；支持 C++/Java/.NET/MATLAB/R 等多语言。
- Gurobi 社区论坛（Gurobi Community Forum）是 GitHub 项目的官方讨论区。
- 建模示例集（Gurobi Modeling Examples）覆盖资源调度、网络流、设施选址、投资组合优化等经典问题。
- 使用 Apache-2.0 许可证开源其工具代码，但求解器核心需授权（学术免费，商业付费）。
- 与 Python 数据生态高度集成（NumPy/pandas/networkx），适合工程化部署。
