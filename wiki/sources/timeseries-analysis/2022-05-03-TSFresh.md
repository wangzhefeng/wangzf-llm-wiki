# 来源卡：TSFresh 时间序列特征提取库

## 这份材料讲了什么

- 原文：[[raw/notes/timeseries-analysis/2022-05-03-timeseries-lib-tsfresh/index.md]]
TSFresh 是一个自动提取时间序列特征的 Python 库，覆盖：

1. **综合特征提取**：计算 60+ 种特征，包括统计、时序、频域特征
2. **特征选择**：自动筛选与目标相关的特征
3. **大规模支持**：支持多序列并行特征提取

## 价值是什么

- 是特征工程专题中最具代表性的自动特征提取工具
- 与 Cesium 形成对比（TSFresh 更强调特征选择和可扩展性）
- 适合机器学习预测前的特征准备阶段
