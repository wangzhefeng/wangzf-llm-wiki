# 来源卡：TODS 异常检测系统

## 这份材料讲了什么

- 原文：[[raw/notes/timeseries-analysis/2023-03-05-timeseries-lib-tods/index.md]]
TODS（Texas Outlier Detection System）是一个专注于异常检测的 Python 库，覆盖：

1. **统计检测**：基于分布和统计方法的异常识别
2. **预测检测**：基于预测残差的异常识别
3. **深度学习检测**：基于自编码器等的异常识别
4. **自动流水线**：从数据到异常识别的自动化流程

## 价值是什么

- 是时间序列异常检测专题的重要工具来源
- 提供了多层次的异常检测方法
- 与异常检测概念页形成互补
