# 来源卡：时间序列可视化

## 这份材料讲了什么

- 原文：[[raw/notes/timeseries-analysis/2023-03-03-timeseries-visualization/index.md]]
时间序列可视化是理解数据和结果的重要手段，覆盖：

1. **基础可视化**：折线图、散点图、多序列对比
2. **分布可视化**：直方图、箱线图、小提琴图
3. **关系可视化**：散点矩阵、热力图、滞后图
4. **结果可视化**：预测曲线、残差图、置信区间

## 价值是什么

- 是 EDA 专题的核心工具
- 可视化是理解序列模式、异常和关系的最直观方式
- 在模型评估和结果展示中不可或缺
