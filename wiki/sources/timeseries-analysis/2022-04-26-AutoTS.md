# 来源卡：AutoTS 时间序列预测库

## 这份材料讲了什么

- 原文：[[raw/notes/timeseries-analysis/2022-04-26-timeseries-lib-autots/index.md]]
AutoTS 是一个自动化的时间序列预测 Python 库，覆盖：

1. **自动模型选择**：自动在多个候选模型中选择最优
2. **数据预处理**：缺失值处理、异常值检测
3. **多频率支持**：支持不同时间频率的序列数据
4. **预测流水线**：从数据加载到预测输出的完整流程

## 价值是什么

- 是时间序列预测工具生态中"自动化"方向的代表
- 适合快速基线建立，不需要手动调参
- 与 pmdarima、GluonTS 等工具形成互补（AutoTS 更强调自动化）
