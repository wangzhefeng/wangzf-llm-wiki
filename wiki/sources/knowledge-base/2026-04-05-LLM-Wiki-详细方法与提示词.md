## 材料定位

这篇中文文章是对 `LLM Wiki` Gist 的详细转述和操作性强化。它的价值不在于提出一个新模式，而在于把原始英文说明拆成更容易执行的中文工作流，并突出“这其实可以直接当作 agent 提示词起点”。

- 这篇文章明确指出 `LLM Wiki` 不是泛泛的理念，而是可以直接发给 agent 的“想法文件 / 提示词骨架”。

- 它补充了大量工具层细节，例如 Web Clipper、本地图片下载、Obsidian 图谱、Marp、Dataview 和 git 版本化。
