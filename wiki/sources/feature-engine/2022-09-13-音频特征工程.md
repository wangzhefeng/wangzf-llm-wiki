## 摘要

音频特征工程是从音频信号中提取能表示音频特性的数值特征。本文覆盖音频文件格式（WAV、MP3）的基础知识，Python wave 库的使用，以及常见的音频特征（频谱、梅尔频谱、MFCC）的提取方法。

## 核心内容

### 音频文件格式
- **WAV（Waveform Audio File Format）**
  - 无损格式，包含采样率、位深度等元数据
  - Python wave 库可直接读取
  
- **MP3**
  - 有损压缩格式
  - 需用 pydub、librosa 等库转换或处理

### Python 音频处理工具

#### Wave 库
- 读写 WAV 文件
- 获取采样率、通道数、帧数等
- 逐帧读取音频数据

#### librosa
- 功能全面的音频处理库
- 支持多种格式的音频加载
- 音频特征提取（MFCC、梅尔频谱等）

### 音频特征

#### 时域特征
- **振幅包络**：信号强度随时间的变化
- **短时能量**：短时间窗口内的能量

#### 频域特征
- **傅里叶变换（FFT）**：将时域转为频域
- **功率谱密度（PSD）**：频率分量的功率分布

#### 倒谱特征
- **MFCC（Mel-Frequency Cepstral Coefficients）**
  - 模拟人耳感知的频率特性
  - 应用：语音识别、音乐分类
  
- **梅尔频谱（Mel Spectrogram）**
  - 梅尔刻度下的频谱
  - 更贴近人耳听觉

#### 其他常用特征
- **零交叉率（Zero Crossing Rate, ZCR）**：信号过零的频率
- **色度特征（Chroma Features）**：音乐的音高成分

## 关键算法/方法

- wave 模块：WAV 读写
- librosa.load()：音频加载
- librosa.feature.mfcc()：MFCC 提取
- librosa.feature.melspectrogram()：梅尔频谱
- scipy.fftpack.fft：FFT 计算
