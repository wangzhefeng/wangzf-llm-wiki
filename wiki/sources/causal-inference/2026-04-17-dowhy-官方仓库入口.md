# DoWhy 官方仓库入口来源摘要

## 材料定位

`dowhy` 是 PyWhy 生态中的核心因果推断 Python 库官方仓库。它不是单篇介绍文章，而是 DoWhy 框架的源码、用户文档、示例 notebook 与测试体系的统一入口。

## 核心模块与结构

- `dowhy/`：核心源码
  - 因果效应识别与估计
  - `gcm/` 图形因果模型
  - `causal_refuters/` 反驳与敏感性分析
  - `graph_learners/` 与 timeseries 支撑模块
- `docs/source/`：官方用户文档、用户指南、案例与 notebook
- `tests/`：覆盖估计器、识别器、refuters、GCM 与时间序列功能

## 关键价值

- 它把 DoWhy 从“概念框架”变成“可追踪的工程实现”
- 明确展示 DoWhy 不只做 effect estimation，还覆盖 GCM、what-if、root cause analysis 与 causal prediction
- 仓库的 `docs + examples + tests` 三层结构，很适合用来理解一个因果推断框架如何从理念落到工程接口

## 在知识库中的位置

- 属于 `causal-inference` 主题的官方工具仓库入口
- 与 [[DoWhy-Framework]] 形成“概念页 -> 官方源码入口”的对应关系
- 作为 DoWhy 学习路径中的第三层：入门文章 -> 概念页 -> 官方仓库
