# 来源卡：Harness Engineering 在硅谷爆火，一文带你搞懂！

## 这份材料讲了什么

- 原文：[[raw/web/vibe-coding/2026-04-11-Harness-Engineering.md]]
- 来源：Datawhale 公众号，2026-03-29
- 类型：概念解析 + 实践指南

核心公式：**Agent = Model + Harness**。Harness 是给 AI 搭的"工作环境"，包含系统提示词、工具、文件系统、沙箱、编排逻辑和检查机制，回答三个问题：AI 在哪干活？用什么干活？怎么知道干得对不对？

OpenAI 案例：3 名工程师 5 个月让 Codex 写了 100 万行代码，工程师实际做的是：设计环境（整理好的文件台、分层文档）、设定标准（可机读的 Linter 错误信息、架构约束规则）、建立反馈（日志/指标/UI 全暴露给 AI）。

Anthropic 案例：把生成器和评估器拆成两个 AI，评估器实际操作页面并对照质量/原创性/工艺/功能四维打分，迭代 5-15 轮，实现创意跃升。

对普通人的迁移：整理工作台（分层文件结构）、设定验收单（明确 done 的标准）、建立返工机制（让 AI 看到自己的输出）。

## 价值是什么

提供了 Harness Engineering 的完整概念框架与双厂（OpenAI + Anthropic）实践案例，是理解"为什么不直接用 LLM 而要搭 Harness"这个问题的最佳入口材料。
