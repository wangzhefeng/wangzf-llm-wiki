# 来源卡：Create a CLI Codex can use

## 这份材料讲了什么

- 原文：[[raw/web/vibe-coding/2026-04-11-Create-a-CLI-Codex-can-use.md]]
- 来源：OpenAI Developers 文档
- 类型：操作指南（中级，约 1 小时）

教导如何为 Codex/Agent 构建**可组合 CLI 接口**，核心理念：把 Agent 反复要做的同类操作（搜索/读取/下载/草稿/上传/轮询/写入）封装成 CLI 命令，让 Agent 从任意文件夹可调用。

**工具链**：
- `$cli-creator`：设计命令面、构建 CLI、添加身份验证、安装到 PATH
- `$skill-creator`：创建伴生 Skill，记录何时使用 CLI、先运行哪些命令、写操作需要哪些审批

**CLI 设计原则**：
- 按职能分层：discovery（列出）→ read（按 ID 读）→ write（草稿优先，写操作需审批）
- 大型响应写到文件，命令只返回路径+摘要，避免 context 膨胀
- 身份验证通过环境变量/配置文件，绝不在 thread 中传递 secret
- 从另一个文件夹测试已安装命令（验证可跨 repo 使用）

**适用场景**：CI 日志获取、支持工单搜索、API 大响应分页、团队脚本步骤分解、文件下载。

## 价值是什么

填补了 Harness 工具层的实践指南空白：如何设计一个 Agent 友好的命令行接口（而非直接让 Agent 调 API），对实现干净的 Harness 工具层具有直接参考价值。
