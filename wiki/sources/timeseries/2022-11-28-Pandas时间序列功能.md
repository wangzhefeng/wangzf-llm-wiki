# 来源卡：Pandas 时间序列功能

## 这份材料讲了什么

Pandas 是时间序列数据处理的基础 Python 库，覆盖：

1. **时间索引操作**：日期范围、重采样、时区处理
2. **滚动窗口**：移动平均、滚动统计
3. **时间序列拆分**：train/test 按时间切分
4. **日期特征提取**：年、月、日、星期几等

## 价值是什么

- 是所有时间序列预测的前置工具
- 提供了最基础的时序数据处理能力
- 与特征工程专题直接相关（滞后特征、滚动统计等）
