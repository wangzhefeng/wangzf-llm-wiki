# tsproj_ml 训练测试预测闭环来源摘要


- 原文：[[raw/repos/repo-wangzhefeng-tsproj-ml.md]]
## 这个知识单元讲什么

这部分内容说明这个仓库不只是方法说明文，而是试图把数据加载、特征工程、模型训练、测试验证和预测输出组织成完整工程闭环。

## 核心做法

- README 把当前框架的优势概括为：
  - 模块化设计
  - 多策略支持
  - 训练、测试、预测的完整功能闭环
- 关键角色分工是：
  - `ModelConfig` 负责配置
  - `FeaturePreprocessor` 负责特征
  - `Model` 负责核心逻辑封装
- README 还给出实现 checklist，说明它不仅在讲概念，也在约束工程实现。

## 输入 / 输出

- 输入：
  - 时序数据
  - 外生变量
  - lag 配置
  - 预测 horizon
- 输出：
  - 训练好的机器学习模型
  - 测试阶段的性能对比
  - 多步预测结果

## 关键模块、脚本、配置

- 当前首轮明确可确认的模块角色：
  - `ModelConfig`
  - `FeaturePreprocessor`
  - `Model`
- 当前首轮明确可确认的流程节点：
  - 数据加载
  - 特征工程
  - 模型训练
  - 测试验证
  - 预测输出

## 适用场景

- 想把时间序列机器学习从“方法说明”落到“项目化执行”的场景。
- 想要一个机器学习预测项目模板或工程骨架时。
