# 来源卡：PyTS 时间序列分类库

## 这份材料讲了什么

- 原文：[[raw/localnotes/timeseries/timeseries-libs/2022-05-06-timeseries-lib-pyts/index.md]]
PyTS 是一个专注于时间序列分类的 Python 库，覆盖：

1. **分类算法**：BOSS、TDE、ST 等时间序列专属分类器
2. **特征提取**：SAX、PAA 等序列表示方法
3. **可视化工具**：序列和分类结果的可视化

## 价值是什么

- 是时间序列分类专题的重要工具来源
- 提供了 scikit-learn 风格的时间序列分类 API
- 与 tslearn 形成互补（PyTS 更强调分类算法的多样性）
