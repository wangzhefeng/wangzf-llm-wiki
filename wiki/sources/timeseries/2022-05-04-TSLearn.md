# 来源卡：TSLearn 时间序列学习库

## 这份材料讲了什么

- 原文：[[raw/local-notes/timeseries/timeseries-libs/2022-05-04-timeseries-lib-tslearn/index.md]]
TSLearn 是一个专注于时间序列机器学习的 Python 库，覆盖：

1. **时间序列分类**：基于 DTW、Shapelet 等方法
2. **时间序列聚类**：KMeans、层次聚类等
3. **预测**：基础预测模型
4. **距离度量**：DTW 等多种序列距离

## 价值是什么

- 是时间序列"分类"和"聚类"旁支任务的重要工具来源
- 提供了 DTW 距离的工程实现
- 与时间序列分类、聚类概念页形成互补
