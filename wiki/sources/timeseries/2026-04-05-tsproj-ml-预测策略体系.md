# tsproj_ml 预测策略体系来源摘要


- 原文：[[raw/repos/repo-wangzhefeng-tsproj-ml.md]]
## 这个知识单元讲什么

这部分内容系统比较了 7 种机器学习时间序列预测方式，把单变量/多变量、直接/递归/混合三类关键维度明确拆开，是这个仓库最有知识沉淀价值的核心部分。

## 核心做法

- 仓库把策略拆成 `USMDO`、`USMD`、`USMR`、`USMDR`、`MSMD`、`MSMR`、`MSMDR` 7 类。
- 这些方法的核心差异不只是模型，而是：
  - 特征来源是否只含目标变量滞后，还是包含全部内生变量滞后
  - 输出是一次性多步，还是单步递归
  - 是否需要同时预测所有内生变量
- README 进一步给出方法选择决策树，用来把问题条件映射到对应策略。

## 输入 / 输出

- 输入：
  - 目标变量历史
  - 其他内生变量历史
  - 外生变量
  - 时间特征
- 输出：
  - 目标变量未来多步
  - 或所有内生变量的未来一步/多步

## 关键模块、脚本、配置

- 当前首轮可确认的关键结构来自 README：
  - `ModelConfig`
  - `FeaturePreprocessor`
  - `Model`
- 可确认的方法选择知识：
  - 单变量 vs 多变量
  - 直接 vs 递归 vs 直接递归混合
  - `MSMD` 被作为多数场景下的重点推荐方案

## 适用场景

- 需要系统选择机器学习时间序列预测策略时。
- 需要把“多步预测”从模糊经验变成明确方法分类时。
- 需要在工程中判断是单变量直接预测，还是多变量直接预测、递归预测时。

## 局限与代价

- 当前首轮沉淀主要基于 README，总结层很强，但源码级实现路径还没逐个核对。
- README 给出了经验性性能对比，但不是严格实验报告，不能直接当作通用结论。
