## 知识链

```
强化学习基础（MDP/MP/MRP）
  → 价值函数与贝尔曼方程
    → Q-Learning / Sarsa（表格型）
      → DQN（深度 Q 网络）
        → DDPG（连续动作）
          → Actor-Critic / A3C
            → PPO（近端策略优化）
              → GRPO（群体相对策略优化）
                → RLHF / DPO（LLM 对齐）
```
