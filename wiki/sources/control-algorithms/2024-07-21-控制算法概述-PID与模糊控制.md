# 来源卡：控制算法概述（PID 与模糊控制）

## 这份材料讲了什么

- 原文：[[raw/local-notes/control-algorithms/2024-07-21-control-system/index.md]]
一份控制算法入门级综述，系统性地介绍了：

1. **控制系统基础**：开环/闭环概念、控制框图、典型应用场景（电机、无人机、汽车等）、控制器设计指标（稳定性、上升时间、超调量、稳态误差、鲁棒性）
2. **PID 控制**：P/I/D 三项的物理意义、离散公式、Python 实现、调参经验（先 P 再 I 后 D）、优缺点分析
3. **模糊控制**：为什么需要模糊控制、模糊化→知识库→推理→解模糊四步流程、模糊 PID（在线调整 PID 参数）、温度控制规则示例
4. **选择策略**：按对象复杂度、非线性程度、工况变化性选择控制算法的决策思路

## 价值是什么

- 是一份"从零到一"的控制算法入门材料，适合快速建立对 PID 和模糊控制的直觉理解
- 提供了多个类比（追目标、开车跟车、水缸加水、刹车）来解释 PID 三项，降低了学习门槛
- 给出了完整的 Python PID 实现代码，可直接作为实验基线
- 模糊 PID 的设计思路（误差+误差变化率 → ΔKp/ΔKi/ΔKd）是工程中最常见的落地方式
