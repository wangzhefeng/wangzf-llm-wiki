# 机器学习概览

一句话定义：机器学习是让计算机从数据中自动发现规律并做出预测或决策的技术，而非显式编程。

## 核心要点

### 机器学习系统的种类

| 分类维度 | 类型 | 说明 |
|----------|------|------|
| 学习信号 | 监督学习 | 有标签数据，预测目标值 |
| | 无监督学习 | 无标签数据，发现内在结构 |
| | 半监督学习 | 少量标签 + 大量无标签 |
| 学习方式 | 批量学习 | 一次性训练，离线更新 |
| | 在线学习 | 逐批次更新，适应数据变化 |
| 推理方式 | 基于实例 | 记忆训练样本，最近邻预测 |
| | 基于模型 | 学习参数泛化，抽象规律 |

### 机器学习的主要挑战

1. **数据不足**：训练样本量不够
2. **数据不代表性**：样本分布与真实场景偏差
3. **数据质量差**：噪声、缺失值、异常值
4. **无关特征**：冗余信息干扰模型
5. **过拟合**：模型记住了训练数据但无法泛化
6. **欠拟合**：模型太简单，连训练数据都拟合不好
7. **偏差/方差权衡**：泛化误差 = 偏差 + 方差 + 不可约误差

### 建模 9 步流程

1. **架构问题**：明确业务目标
2. **获取数据**：收集相关数据
3. **研究数据**：EDA 探索性分析
4. **准备数据**：清洗、特征工程
5. **列出期望模型**：选择候选算法
6. **微调模型**：超参调优
7. **展示解决方案**：可视化、报告
8. **启动、监视、维护**：上线运维
9. **模型优化**：持续迭代

### 过拟合 vs 欠拟合

| | 过拟合 | 欠拟合 |
|--|--------|--------|
| 训练误差 | 低 | 高 |
| 验证误差 | 高 | 高 |
| 原因 | 模型太复杂 | 模型太简单 |
| 应对 | 正则化、更多数据、简化模型 | 更复杂模型、更好特征 |
