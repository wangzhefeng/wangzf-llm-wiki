# 模型评估

一句话定义：模型评估是用系统性指标量化模型性能的过程，不同任务类型使用不同的评估体系。

## 核心要点

### 回归评估指标

| 指标 | 公式 | 特点 |
|------|------|------|
| MSE | $\frac{1}{n}\sum(y-\hat{y})^2$ | 对大误差敏感 |
| RMSE | $\sqrt{MSE}$ | 与目标同量纲 |
| MAE | $\frac{1}{n}\sum|y-\hat{y}|$ | 鲁棒性强 |
| R² | $1 - \frac{SS_{res}}{SS_{tot}}$ | 解释方差比例 |

### 分类评估指标

| 指标 | 说明 |
|------|------|
| 精确率 | 预测为正中，实际为正的比例 |
| 召回率 | 实际正中中，被正确预测的比例 |
| F1 | 精确率和召回率的调和平均 |
| ROC-AUC | 不同阈值下的 TPR-FPR 曲线面积 |

### 聚类评估指标

| 指标 | 说明 | 越高越好？ |
|------|------|------------|
| 轮廓系数 | 簇内紧密 vs 簇间分离 | 是 |
| Calinski-Harabasz | 簇间方差/簇内方差 | 是 |
| Davies-Bouldin | 簇内距离/簇间距离 | 否 |

### 评估与验证的关系

- **模型评估**回答"模型有多好"（用什么指标）
- **模型验证**回答"评估有多可信"（如何获得无偏估计）
