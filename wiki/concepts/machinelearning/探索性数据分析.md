# 探索性数据分析

一句话定义：探索性数据分析（EDA）是在建模前系统理解数据分布、关系和质量的過程，是特征工程和模型选择的前提。

## 核心要点

### EDA 的模块划分

| 模块 | 关注点 | 典型操作 |
|------|--------|----------|
| 单变量分析 | 单个特征的分布 | 直方图、箱线图、缺失值统计、偏度/峰度 |
| 多变量分析 | 特征间关系 | 散点图、相关系数矩阵、协方差、热力图 |
| 全局分析 | 数据集整体概览 | 样本量、特征数、类别分布、内存占用 |

### 自动 EDA 工具生态

| 工具 | 特点 |
|------|------|
| Pandas-Profiling | 最流行，交互式报告 |
| Sweetviz | 对比训练集/测试集分布 |
| AutoViz | 一键可视化，适合大数据 |
| Dataprep | 交互式 EDA + 数据清洗 |
| Klib | 轻量级，快速概览 |
| D-Tale | Web 界面，支持数据探索 |

### EDA 的核心产出

1. **数据质量报告**：缺失值、异常值、重复值
2. **分布理解**：每个特征的集中趋势和离散程度
3. **关系网络**：特征间的相关性和共线性
4. **假设生成**：哪些特征可能有预测力？哪些需要变换？

### EDA 与特征工程的关系

EDA 回答"数据是什么样"，特征工程回答"如何让数据更适合模型"。EDA 的产出直接指导特征工程的方向：
- 发现缺失值模式 → 决定填充策略
- 发现偏态分布 → 决定对数变换
- 发现共线性 → 决定特征选择
- 发现异常值 → 决定截断或剔除
