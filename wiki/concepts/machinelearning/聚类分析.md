# 聚类分析

一句话定义：聚类分析是将无标签数据划分为若干组（簇），使得同一组内样本相似、不同组间样本差异大的方法。

## 核心要点

### 聚类方法分类

| 类型 | 代表算法 | 需要指定 K？ | 适合形状 | 对噪声敏感？ |
|------|----------|-------------|----------|-------------|
| 基于中心点 | K-Means | 是 | 球形 | 是 |
| 基于中心点 | K-Medoids | 是 | 球形 | 否 |
| 基于层次 | AGNES/DIANA | 否 | 任意 | 否 |
| 基于密度 | DBSCAN | 否 | 任意 | 否（可识别噪声） |
| 基于分布 | GMM | 是 | 椭圆 | 中等 |

### K-Means 核心流程

1. 随机初始化 K 个中心
2. 将每个样本分配到最近中心
3. 重新计算每个簇的中心
4. 重复 2-3 直至收敛

### 如何选择 K

- **肘部法**：画 SSE-K 曲线，找拐点
- **轮廓系数**：选轮廓系数最大的 K
- **业务解释**：根据业务需求确定

### DBSCAN 的优势

- 不需要预设簇数量
- 能识别任意形状的簇
- 能识别噪声点（离群值）
- 参数：eps（邻域半径）、min_samples（核心点最小样本数）
