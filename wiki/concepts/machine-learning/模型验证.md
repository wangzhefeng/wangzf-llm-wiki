# 模型验证

一句话定义：模型验证是通过系统性重采样策略，评估模型在 unseen 数据上的泛化能力的方法。

## 核心要点

### 为什么需要模型验证

训练误差通常低估了泛化误差。模型验证的目标是获得对泛化误差的无偏估计。

### 交叉验证方法族

| 方法 | 适用场景 | 优点 | 缺点 |
|------|----------|------|------|
| Hold Out | 大数据集 | 快速 | 方差大 |
| K-Fold | 通用 | 方差小 | 计算成本高 |
| 分层 K-Fold | 类别不平衡 | 保持类别比例 | - |
| 分组 K-Fold | 有分组结构 | 防止数据泄漏 | - |
| Repeated K-Fold | 小数据集 | 更稳定 | 计算成本极高 |
| Nested K-Fold | 超参调优+评估 | 无偏估计 | 计算成本最高 |
| Leave-One-Out | 极小数据集 | 充分利用数据 | 方差可能很大 |

### 验证策略选择

| 数据规模 | 推荐策略 |
|----------|----------|
| > 10 万 | Hold Out（80/20 或 70/30） |
| 1 万 - 10 万 | 5-Fold 或 10-Fold |
| < 1 万 | Repeated K-Fold 或 Nested K-Fold |
| 有分组结构 | 分组 K-Fold |
| 类别不平衡 | 分层 K-Fold |

### 常见陷阱

1. **数据泄漏**：预处理（如标准化）在分割前做了
2. **时间泄漏**：用未来数据预测过去
3. **多次测试偏差**：反复调参后验证结果不再无偏
