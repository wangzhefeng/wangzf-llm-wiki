# 特征工程

## 定义

从原始数据中提取、选择和构造特征（特征变量）的过程，是机器学习的核心步骤之一。

## 核心步骤

### 1. 特征提取
从原始数据中提取有意义的特征表示。

**时间序列特征提取方法**:
- 时间相关特征（年、月、日、小时、星期等）
- 滞后特征（lag features）
- 滚动统计特征（均值、方差、最大/最小值等）
- 频域特征（FFT 系数）

### 2. 特征选择
选择对目标变量最有预测能力的特征子集。

**方法**:
- 过滤法（Filter）
- 包装法（Wrapper）
- 嵌入法（Embedded）

### 3. 特征构造
通过组合、变换构造新特征。

**技术**:
- 多项式特征
- 交互特征
- 分箱/离散化

## 特征离散化

将连续特征转换为离散区间。

**适用场景**:
- 特征与目标变量呈非线性关系
- 需要提高模型鲁棒性
- 降低过拟合风险
- 某些算法（如决策树）对离散特征更友好

## 缺失数据处理

### 常见策略

| 方法 | 适用场景 | 优缺点 |
|------|----------|--------|
| 删除 | 缺失比例极低 | 可能丢失信息 |
| 均值/中位数填充 | 缺失随机 | 不考虑特征关系 |
| KNN 填充 | 有相似样本 | 计算开销大 |
| 模型预测填充 | 特征间有相关性 | 复杂度高 |
| 作为单独类别 | 类别特征 | 简单有效 |

## 时间序列特征工程

### 时间相关特征
```python
# 示例
df['hour'] = df.index.hour
df['day_of_week'] = df.index.dayofweek
df['month'] = df.index.month
df['is_weekend'] = df.index.dayofweek >= 5
```

### 滞后特征
```python
# 示例
df['lag_1'] = df['value'].shift(1)
df['lag_24'] = df['value'].shift(24)  # 日周期
```

### 滚动特征
```python
# 示例
df['rolling_mean_7d'] = df['value'].rolling(window=7).mean()
df['rolling_std_7d'] = df['value'].rolling(window=7).std()
```
