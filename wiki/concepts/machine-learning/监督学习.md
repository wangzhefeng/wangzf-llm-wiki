# 监督学习

一句话定义：监督学习是从有标签的训练数据中学习输入-输出映射关系，从而对 unseen 数据做出预测的方法。

## 核心要点

### 监督学习的任务类型

| 任务 | 输出类型 | 代表算法 |
|------|----------|----------|
| 回归 | 连续值 | 线性回归、多项式回归、SVR |
| 二分类 | 0/1 | 逻辑回归、SVM、决策树 |
| 多分类 | 多类别 | Softmax、One-vs-Rest |
| 多标签 | 多标签组合 | 多标签分类器 |
| 多输出 | 多个目标值 | 多输出回归/分类 |

### 核心算法族

#### 线性模型
- **线性回归**：最小二乘法，假设线性关系
- **逻辑回归**：Sigmoid 映射到概率，分类基线
- **多项式回归**：非线性关系的线性建模
- **正则化**：Ridge（L2）、Lasso（L1）、Elastic Net

#### 树模型
- **决策树**：可解释性强，易过拟合
- **随机森林**：Bagging 集成，稳定可靠
- **GBDT/XGBoost/LightGBM/CatBoost**：Boosting 集成，性能天花板

#### 其他
- **K 近邻**：基于实例，无显式训练
- **支持向量机**：最大间隔分类器，核方法处理非线性
- **朴素贝叶斯**：条件独立假设，文本分类常用
- **感知机**：神经网络的前身

## 与模型评估和验证的关系

[[模型评估]] 和 [[模型验证]] 是监督学习不可或缺的组成部分。在选择算法后，必须通过系统的验证策略（如交叉验证）来获得可信的泛化误差估计，再通过合适的评估指标（如 MSE、AUC）量化模型性能。

### 如何选择算法

| 场景 | 优先选择 |
|------|----------|
| 快速基线 | 线性/逻辑回归 |
| 可解释性要求高 | 决策树、线性模型 |
| 结构化数据，追求精度 | XGBoost、LightGBM |
| 类别特征多 | CatBoost |
| 大规模数据 | LightGBM、线性模型 |
| 文本分类 | 朴素贝叶斯、线性模型 |
| 小样本 | SVM、KNN |
