# wiki/concepts/machine-learning

本目录存放机器学习相关概念与方法页。

## 核心概念页（Tier 1，5 个）

1. [[机器学习概览]] — ML 范式总览，监督/无监督/半监督学习类型与核心挑战
2. [[监督学习]] — 从标注数据学习的框架（回归、分类、多输出任务）
3. [[无监督学习]] — 从无标注数据发现规律的框架（聚类、降维、密度估计）
4. [[模型评估]] — 量化模型性能的指标体系（回归、分类、聚类各类指标）
5. [[集成学习]] — 组合多个学习器的元框架（Bagging、Boosting、Stacking）

## 方法级概念页（Tier 2，8 个）

6. [[探索性数据分析]] — 建模前的数据分布、关系与质量理解流程
7. [[模型验证]] — 通过重采样策略评估泛化能力（K 折、留出法）
8. [[交叉验证]] — 模型评估中的交叉验证专项技术
9. [[聚类分析]] — 无监督划分数据的具体方法（K-Means、DBSCAN、层次聚类）
10. [[XGBoost]] — 梯度提升树的高效实现，集成学习的代表算法
11. [[LightGBM]] — 基于直方图的轻量级提升框架
12. [[随机森林]] — Bagging 代表模型，适合结构化数据基线
13. [[梯度提升树]] — Boosting 系算法共同基础

## 入口建议

- **快速入门**：从 [[机器学习概览]] 建立整体认知
- **任务导向**：根据问题类型参考 [[监督学习]] 或 [[无监督学习]]
- **模型验证**：参考 [[模型评估]] 和 [[交叉验证]] 的方法选择
- **算法深化**：选择相关方法级概念页（XGBoost、LightGBM 等）
