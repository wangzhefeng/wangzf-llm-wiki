# 特征离散化

## 定义与背景

**特征离散化（Feature Discretization）**是指将连续数值特征转换为离散区间或类别特征的过程。

### 与连续特征对比

| 维度 | 连续特征 | 离散特征 |
|-----|---------|---------|
| 取值 | 无限多 | 有限个 |
| 表示 | 实数 | 区间或类别 |
| 存储 | 浮点数 | 整数或类别 |
| 非线性 | 模型学习 | 自动编码 |

### 核心问题：为什么离散化？

1. **捕获非线性关系**：一些特征与目标的关系是分段线性的
2. **提高鲁棒性**：对异常值不敏感
3. **简化模型**：离散特征易于解释
4. **处理过度拟合**：减少参数数量
5. **金融风控**：便于评分卡制作

---

## 核心离散化方法

### 1. 等宽分箱（Equal-Width Binning）

**方法**：将特征范围均分为 k 个等宽区间

```python
# Pandas 实现
df['age_bin'] = pd.cut(df['age'], bins=5)
# 将 age 分成 5 个等宽区间：
# (0, 20], (20, 40], (40, 60], (60, 80], (80, 100]

# sklearn 实现
from sklearn.preprocessing import KBinsDiscretizer
discretizer = KBinsDiscretizer(n_bins=5, encode='ordinal', strategy='quantile')
df['age_bin'] = discretizer.fit_transform(df[['age']])
```

**公式**：
```
区间宽度 = (max - min) / n_bins
Bin_i = [min + i*width, min + (i+1)*width]
```

**优点**：
- 简单直观
- 计算快速

**缺点**：
- 不同区间的样本数差异大（可能有空区间）
- 对异常值敏感（极端值会扩大范围）

**应用场景**：
- 初步探索
- 快速离散化

---

### 2. 等频分箱（Equal-Frequency Binning）

**方法**：将特征分成 k 个区间，每个区间包含相同数量的样本

```python
# Pandas 实现
df['age_bin'], bins = pd.qcut(df['age'], q=5, retbins=True)
# 如果有 1000 个样本，每个区间包含 200 个样本

# sklearn 实现
from sklearn.preprocessing import KBinsDiscretizer
discretizer = KBinsDiscretizer(n_bins=5, encode='ordinal', strategy='quantile')
```

**优点**：
- 各区间样本量平衡
- 对异常值相对鲁棒

**缺点**：
- 相邻区间边界可能接近（如果数据有聚集）
- 边界不太直观

**应用场景**：
- 样本不平衡的特征
- 需要平衡样本量的场景

---

### 3. 基于聚类的分箱

使用 K-means 或其他聚类算法确定分箱边界：

```python
from sklearn.cluster import KMeans
import numpy as np

# 获取聚类中心作为分箱边界
kmeans = KMeans(n_clusters=5)
kmeans.fit(df[['age']])
centers = np.sort(kmeans.cluster_centers_.flatten())
df['age_bin'] = pd.cut(df['age'], bins=centers)
```

**优点**：
- 自适应于数据分布
- 相似的样本会分到同一箱

**缺点**：
- 计算成本高
- 参数（聚类数）需要调优

---

### 4. 基于决策树的分箱

用决策树的分裂点作为分箱边界：

```python
from sklearn.tree import DecisionTreeClassifier
import numpy as np

# 训练决策树
tree = DecisionTreeClassifier(max_depth=3)  # 限制深度控制箱数
tree.fit(df[['age']], df['target'])

# 提取叶节点的边界作为分箱边界
# （需要遍历树结构）
```

**优点**：
- 基于目标变量的信息增益
- 分箱与预测任务相关

**缺点**：
- 复杂度高
- 易过拟合

**应用场景**：
- 需要最大化预测能力的场景
- 风险评分卡

---

### 5. 自定义分箱

基于领域知识手工指定边界：

```python
# 根据业务规则定义年龄段
age_bins = [0, 18, 30, 45, 60, 100]
df['age_group'] = pd.cut(df['age'], bins=age_bins,
                         labels=['0-18', '18-30', '30-45', '45-60', '60+'])
```

**优点**：
- 易于业务解释
- 融入领域知识

**缺点**：
- 需要专家判断
- 可能不是最优

**应用场景**：
- 业务规定的分类（如风险等级）
- 可解释性要求高的场景

## 工程实践

### 选择分箱数

| 样本数 | 推荐箱数 |
|--------|---------|
| < 100 | 3-5 |
| 100-1K | 5-10 |
| 1K-10K | 10-20 |
| > 10K | 20-50 |

**经验法则**：`n_bins ≈ sqrt(n_samples) / 2`

### 常见问题

#### 问题 1：分箱后信息损失
```python
# 连续特征通常包含更多信息
# 解决方案：
# 1. 试同时使用连续和离散特征
# 2. 用 one-hot 编码离散特征（保留足够维度）
# 3. 根据树模型选择合适的箱数
```

#### 问题 2：新数据落在分箱外
```python
# 新数据的特征值超出原训练集的范围
# 解决方案：
# 1. 扩大最外层箱的范围
# 2. 将极端值映射到相邻箱
# 3. 创建"Other"类别
```

#### 问题 3：分箱边界的不稳定性
```python
# 等频分箱在小样本时可能不稳定
# 解决方案：
# 1. 先进行数据清洗（移除离群点）
# 2. 用等宽分箱 + 手工调整
# 3. 使用基于树的分箱（更稳定）
```

## 离散化后的处理

### 编码

```python
# Ordinal 编码（保持顺序关系）
# bins: [0, 20], (20, 40], (40, 60]
# 编码: 0, 1, 2
df['age_encoded'] = pd.factorize(df['age_bin'])[0]

# One-Hot 编码（用于线性模型）
df_encoded = pd.get_dummies(df['age_bin'], prefix='age')
```

### 特征重要性的变化
离散化后，特征重要性通常会改变：
```python
# 连续特征可能排名低
# 离散特征（如果分箱得当）可能排名高
# 需要重新评估特征重要性
```

## 离散化的权衡

### 何时适合离散化

✓ **适合的场景**：
- 特征与目标呈非线性关系
- 存在离群点
- 需要可解释性强的模型
- 金融风控（评分卡）

✗ **不适合的场景**：
- 特征与目标呈线性关系
- 数据量很小（样本不足）
- 树模型（已能处理非线性）
- 深度学习（自动学习非线性）

### 与其他技术的对比

| 技术 | 优点 | 缺点 |
|------|-----|-----|
| 离散化 | 可解释、鲁棒 | 信息损失 |
| 多项式 | 保留连续性 | 外推差 |
| 树模型 | 自动处理 | 黑箱 |
| 神经网络 | 强大灵活 | 黑箱、数据需求多 |

## 进阶话题

### 二阶特征交互的离散化
```python
# 创建两个离散特征的组合
df['age_income_group'] = df['age_bin'].astype(str) + '_' + df['income_bin'].astype(str)
```

### 动态离散化
在生产环境中，随着新数据的到来，分箱边界可能需要更新

### WOE（信息值）的联系
离散化与 WOE 编码紧密相关：
- 先离散化为分箱
- 再计算每个箱的 WOE 值
