# 特征标准化

## 定义与背景

**特征标准化（也称无量纲化、规范化）**是指将特征值缩放到一个标准化范围的过程。

### 核心问题
原始特征通常存在以下问题：
- **量纲不同**：身高（厘米）、收入（万元）等单位不一致
- **数值范围差异大**：年龄（0-100）vs 工资（5000-500000）
- **模型敏感性**：梯度下降算法对数值范围敏感

### 标准化的重要性

**需要标准化的模型**：
- 线性回归、逻辑回归：梯度下降对特征尺度敏感
- 神经网络：激活函数在 0 附近性能最好
- SVM、KNN：基于距离的算法
- 正则化模型（L1/L2）：惩罚项受特征尺度影响

**不需要标准化的模型**：
- 决策树、随机森林：基于特征分裂，与尺度无关
- XGBoost、LightGBM、CatBoost：树模型天然处理

## 标准化方法

### 1. Z-Score 标准化

**公式**：`x_scaled = (x - mean) / std`

**目标**：将特征变换为均值 0，标准差 1 的标准正态分布

```python
from sklearn.preprocessing import StandardScaler
scaler = StandardScaler()
X_scaled = scaler.fit_transform(X)

# 手工实现
X_scaled = (X - X.mean()) / X.std()
```

**适用条件**：
- 特征呈正态分布（或接近）
- 线性模型、神经网络

**优点**：
- 广泛适用，效果稳定
- 保留数据分布形状

**缺点**：
- 对异常值敏感（异常值会影响 mean 和 std）
- 需要知道全体数据的统计量（对流数据不友好）

**示例**：
```python
# 假设特征：[1, 2, 3, 4, 5]
# mean = 3, std = 1.41
# 标准化后：[-1.41, -0.71, 0, 0.71, 1.41]
```

---

### 2. Min-Max 缩放（归一化）

**公式**：`x_scaled = (x - min) / (max - min)`

**目标**：将特征缩放到 [0, 1] 范围

```python
from sklearn.preprocessing import MinMaxScaler
scaler = MinMaxScaler()
X_scaled = scaler.fit_transform(X)

# 手工实现
X_scaled = (X - X.min()) / (X.max() - X.min())
```

**适用条件**：
- 特征有明确的上下界
- 神经网络（通常输入 [0, 1] 范围更稳定）

**优点**：
- 结果有直观的物理含义（0-1 之间）
- 易于理解

**缺点**：
- 对异常值非常敏感（一个极端值会影响整个缩放）
- 新数据超出原范围时，缩放结果可能 > 1 或 < 0

**示例**：
```python
# 假设特征：[1, 2, 3, 4, 5]
# min = 1, max = 5
# 缩放后：[0, 0.25, 0.5, 0.75, 1.0]
```

---

### 3. RobustScaler（稳健缩放）

**公式**：`x_scaled = (x - median) / IQR`

其中 IQR（四分位数范围）= Q3 - Q1

```python
from sklearn.preprocessing import RobustScaler
scaler = RobustScaler()
X_scaled = scaler.fit_transform(X)
```

**优点**：
- 对异常值鲁棒（使用中位数和 IQR）
- 不会让异常值主导缩放

**缺点**：
- 不是标准的正态分布
- 在缺少异常值的数据上，效果可能不如 StandardScaler

**适用条件**：
- 数据包含异常值
- 需要稳健的缩放

---

### 4. MaxAbsScaler

**公式**：`x_scaled = x / max(|x|)`

**目标**：缩放到 [-1, 1] 范围（基于最大绝对值）

```python
from sklearn.preprocessing import MaxAbsScaler
scaler = MaxAbsScaler()
X_scaled = scaler.fit_transform(X)
```

**优点**：
- 保留零值（稀疏数据不会变成密集）
- 对异常值相对鲁棒

**适用条件**：
- 稀疏数据（如文本的 TF-IDF）
- 需要保留零值的含义

## 工程实践

### 标准化工作流

```python
# Step 1: 在训练集上拟合
scaler = StandardScaler()
scaler.fit(X_train)

# Step 2: 变换训练集
X_train_scaled = scaler.transform(X_train)

# Step 3: 用同一个 scaler 变换测试集
X_test_scaled = scaler.transform(X_test)

# Step 4: 用同一个 scaler 变换新的预测数据
X_new_scaled = scaler.transform(X_new)
```

### 常见错误

#### 错误 1：在全数据上拟合
```python
# 错误：信息泄露
scaler = StandardScaler()
scaler.fit(X)  # X = X_train + X_test
X_train_scaled = scaler.transform(X_train)

# 正确：仅在训练集
scaler = StandardScaler()
scaler.fit(X_train)
X_train_scaled = scaler.transform(X_train)
X_test_scaled = scaler.transform(X_test)
```

#### 错误 2：变换目标变量
```python
# 错误：不应该标准化目标
y_scaled = scaler.fit_transform(y.reshape(-1, 1))

# 正确：仅标准化特征
X_scaled = scaler.fit_transform(X)
y = y  # 保持原样
```

#### 错误 3：混淆不同的缩放方法
```python
# 错误：在训练集用 StandardScaler，在测试集用 MinMaxScaler
train_scaler = StandardScaler()
X_train_scaled = train_scaler.fit_transform(X_train)

test_scaler = MinMaxScaler()  # 错误！
X_test_scaled = test_scaler.fit_transform(X_test)

# 正确：全程使用同一个 scaler
scaler = StandardScaler()
X_train_scaled = scaler.fit_transform(X_train)
X_test_scaled = scaler.transform(X_test)
```

## 何时标准化

### 决策流程

```
模型类型是什么？
├─ 树模型（DT、RF、XGBoost、LightGBM）
│  └─ 不需要标准化 ✗
├─ 线性模型（线性回归、逻辑回归）
│  └─ 强烈推荐 ✓✓
├─ 神经网络
│  └─ 推荐 ✓
├─ SVM/KNN
│  └─ 必需 ✓✓
└─ 聚类（K-means）
   └─ 推荐 ✓
```

### 特征类型

| 特征类型 | 是否标准化 |
|---------|----------|
| 数值特征 | 是（通常） |
| 分类特征 | 否（应编码，不直接标准化） |
| 文本特征 | 取决于表示方法（TF-IDF 需要） |

## 进阶话题

### 个别特征的不同标准化

```python
from sklearn.compose import ColumnTransformer
from sklearn.preprocessing import StandardScaler, MinMaxScaler

preprocessor = ColumnTransformer(
    transformers=[
        ('numeric', StandardScaler(), numeric_features),
        ('minmax', MinMaxScaler(), range_bounded_features),
    ])

X_processed = preprocessor.fit_transform(X)
```

### 标准化与特征缩放的关系

- **标准化**：特指 Z-Score（均值 0，方差 1）
- **缩放**：更广泛的概念（包括所有范围变换方法）
- **规范化**：有时特指 L2 范数归一化（用于 SVM）

### 时间序列中的标准化

```python
# 滑动窗口标准化（避免未来信息泄露）
for i in range(window_size, len(data)):
    window = data[i-window_size:i]
    scaler = StandardScaler()
    scaler.fit(window)
    data_scaled[i] = scaler.transform(data[i])
```
