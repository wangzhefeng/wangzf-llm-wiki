# 特征编码

## 定义与背景

**特征编码**是将分类（离散）特征转换为机器学习模型可接受的数值表示的过程。

### 为什么需要编码？
- 大多数机器学习算法（线性、神经网络）只接受数值输入
- 需要将字符串或类别值映射到数值
- 不同编码方法会影响模型性能

### 应用场景
- 用户类别、商品类别、地理位置等离散特征
- 高基数特征（数千或数万个不同值）
- 有序与无序类别的区分处理

---

## 核心方法

### 1. 标签编码（Label Encoding）
**方法**：为每个不同的值分配 0, 1, 2, ..., n-1 的整数 ID

**优点**：
- 简洁，维度不变
- 计算高效

**缺点**：
- 引入虚假顺序（0 < 1 < 2）
- 模型可能误认为存在大小关系

**适用场景**：
- 树模型（对顺序不敏感）
- 有序类别（学位等级：高中 → 本科 → 硕士）
- 临时编码使用

**代码示例**：
```python
from sklearn.preprocessing import LabelEncoder
le = LabelEncoder()
df['color_encoded'] = le.fit_transform(df['color'])
# 'red' → 0, 'blue' → 1, 'green' → 2
```

---

### 2. 独热编码（One-Hot Encoding）
**方法**：为 k 个类别创建 k 个二进制列（或 k-1 列以避免多重共线性）

**优点**：
- 无虚假顺序，信息完整
- 标准方法，广泛应用

**缺点**：
- 高基数特征会导致维数膨胀（如邮编：>30000 维）
- 增加模型训练时间和内存占用
- 特征稀疏，可能导致过拟合

**适用场景**：
- 低基数特征（< 100 个不同值）
- 线性模型（需避免虚假顺序）
- 神经网络（适合高维稀疏输入）

**代码示例**：
```python
import pandas as pd
df = pd.get_dummies(df, columns=['color'], drop_first=True)
# drop_first=True 避免多重共线性
```

---

### 3. 目标编码（Target Encoding）
**方法**：用特征值对应的目标变量均值替代

**具体变种**：
- **基础 Target 编码**：`encoding[x] = mean(y | feature=x)`
- **Leave-One-Out (LOO)**：排除当前样本计算均值，避免数据泄露
- **K-fold**：交叉验证版本，训练集内 K-fold 计算，测试集用全量均值
- **Bayesian**：加入贝叶斯平滑，防止稀有类别过拟合

**优点**：
- 信息量大，直接利用目标信息
- 维度不增加
- 对高基数特征友好

**缺点**：
- 易过拟合（特别是小样本）
- 需要交叉验证防止数据泄露
- 新值处理需要特殊策略

**适用场景**：
- 竞赛最佳实践（通常 +5-10% 性能提升）
- 高基数特征
- 足够样本量时

**代码示例**：
```python
from category_encoders import TargetEncoder
te = TargetEncoder()
df['color_encoded'] = te.fit_transform(df['color'], df['target'])
```

---

### 4. WOE 编码（Weight of Evidence）
**方法**：衡量特征对目标的差异程度

**原理**：`WOE(x) = ln(% of Goods / % of Bads)`

**计算步骤**：
1. 将特征离散化为分箱
2. 计算每个分箱的好/坏客户比例
3. WOE 值反映该分箱与整体的偏离程度

**关键指标 - 信息值（Information Value, IV）**：
- `IV = sum(WOE * (% of Goods - % of Bads))`
- 衡量特征对目标的预测能力
- IV > 0.3：强预测特征

**优点**：
- 基于统计学原理，可解释性强
- 能识别特征与目标的关系
- 常用于风险管理和金融

**缺点**：
- 仅适用于二分类问题
- 需要特征分箱，涉及人为决策

**适用场景**：
- 金融风控、欺诈检测
- 二分类问题
- 需要强可解释性

**代码示例**：
```python
from category_encoders import WOEEncoder
we = WOEEncoder()
df['color_encoded'] = we.fit_transform(df['color'], df['target'])
```

---

### 5. 其他高级编码方法

#### CatBoost 编码
- CatBoost 模型内置的有序目标编码
- 自适应处理新值
- 不需交叉验证防止泄露

#### 哈希编码（Hashing）
- 使用哈希函数映射到固定维度
- 优点：处理超高基数特征，固定内存占用
- 缺点：哈希碰撞损失信息，可解释性差

#### 计数编码
- 用类别值出现频率替代
- 简单但信息有限，常配合其他方法

## 实践应用

### 决策流程图
```
开始（有分类特征）
    ↓
基数多少？
├→ 低（<10）：OneHot 编码
├→ 中（10-100）：OneHot 或 Target（根据模型）
└→ 高（>100）
    ├→ 线性模型：WOE/Target 编码
    ├→ 树模型：标签编码或 CatBoost 编码
    └→ 神经网络：Embedding 或 Target 编码
```

### 常见陷阱

#### 1. 数据泄露
**问题**：用整个数据集计算目标编码，导致训练和测试集信息混淆
**解决**：必须用训练集拟合编码器，再应用于测试集

#### 2. 新值处理（Out-of-Vocabulary, OOV）
**问题**：测试集出现训练集未见过的类别值
**解决方案**：
- 分配全局均值
- 创建"其他"类别
- 使用哈希编码（固定处理）

#### 3. 高基数特征爆炸
**问题**：OneHot 编码导致维数过高
**解决**：
- 合并低频类别
- 使用频率编码或目标编码
- 使用哈希编码

### 性能对比（典型数据竞赛）
| 编码方法 | 性能 | 速度 | 可解释性 |
|---------|-----|-----|---------|
| OneHot | 基准 | 快 | 中 |
| 标签编码 | 差 | 快 | 低 |
| 目标编码 | +5-10% | 中 | 中 |
| WOE | 类似 | 慢 | 高 |
| CatBoost | 类似 | 快 | 中 |

## 进阶话题

### 多维编码
当特征间有交互时，可创建联合编码：
```python
df['color_size_interaction'] = df['color'] + '_' + df['size']
# 然后对交互特征编码
```

### Embedding 方法
深度学习中，使用可学习的嵌入层：
```python
# TensorFlow/Keras
model.add(Embedding(input_dim=num_categories, output_dim=8))
```
- 自动学习最优的类别表示
- 适合超高基数特征

### 上下文编码
特征的编码依赖上下文（如推荐系统中的用户-商品对）
