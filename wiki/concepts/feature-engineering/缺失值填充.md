# 缺失值填充

## 定义与背景

**缺失值**是指数据集中某些样本的特定特征没有观测值的情况。

### 常见原因
- 数据收集过程中的遗漏（传感器故障、人为错误）
- 用户未填写（问卷调查）
- 隐私保护（数据脱敏）
- 业务流程（某些交易中特定字段不适用）

### 缺失类型（统计视角）

#### MCAR（完全随机缺失）
- 缺失完全随机，与其他变量无关
- 如：数据库随机故障导致部分数据丢失
- 处理：删除或简单填充均可

#### MAR（随机缺失）
- 缺失依赖于其他观测变量
- 如：高收入人群更不愿意透露具体收入数额
- 处理：基于其他变量的预测填充

#### MNAR（非随机缺失）
- 缺失与该变量本身相关
- 如：高血压患者更不愿意测血压
- 处理：需要特殊方法或外部信息

---

## 处理策略

### 1. 删除方法

#### 按行删除（样本级）
```python
df_clean = df.dropna()  # 删除任何包含缺失值的行
df_clean = df.dropna(thresh=0.5)  # 保留至少 50% 非缺失值的行
```

**适用条件**：
- 缺失比例很小（< 5%）
- MCAR 类型的缺失
- 样本数充足

**优点**：
- 简单直接
- 无需参数调整

**缺点**：
- 丢失信息
- 可能导致样本不足

#### 按列删除（特征级）
```python
df_clean = df.dropna(axis=1)  # 删除包含缺失值的列
df_clean = df.drop(columns=df.columns[df.isnull().sum() > 100])
```

**适用条件**：
- 特征有大量缺失（> 50%）
- 特征重要性低
- 替代特征存在

---

### 2. 填充方法

#### 常数填充
```python
# 用指定常数填充
df['age'].fillna(0, inplace=True)
df['category'].fillna('Unknown', inplace=True)

# 用前一个值填充（时间序列）
df['value'].fillna(method='ffill', inplace=True)

# 用后一个值填充
df['value'].fillna(method='bfill', inplace=True)
```

**优点**：快速简单
**缺点**：可能引入偏差，不保存数据关系

#### 统计填充
```python
# 均值填充（数值特征）
df['age'].fillna(df['age'].mean(), inplace=True)

# 中位数填充（对异常值鲁棒）
df['income'].fillna(df['income'].median(), inplace=True)

# 众数填充（分类特征）
df['category'].fillna(df['category'].mode()[0], inplace=True)
```

**何时使用**：
- 特征与目标独立时
- 缺失比例不大（< 20%）

**优点**：
- 保持分布形状
- 实现简单

**缺点**：
- 忽视特征间关系
- 低估方差

#### 模型填充
```python
# sklearn SimpleImputer（K-NN）
from sklearn.impute import SimpleImputer
imputer = SimpleImputer(strategy='mean')  # 或 'median'
X_imputed = imputer.fit_transform(X)

# KNN 填充：用相邻样本的平均值
from sklearn.impute import KNNImputer
knn_imputer = KNNImputer(n_neighbors=5)
X_imputed = knn_imputer.fit_transform(X)
```

**原理**：
- 基于特征间的相似性
- 比统计方法更灵活

**优点**：
- 考虑特征关系
- 性能通常更好

**缺点**：
- 计算成本高
- 对异常值敏感

---

### 3. 插值方法

特别适合时间序列数据：

```python
# 线性插值
df['value'].interpolate(method='linear', inplace=True)

# 多项式插值（平滑）
df['value'].interpolate(method='polynomial', order=2, inplace=True)

# 时间加权插值
df['value'].interpolate(method='time', inplace=True)

# 向前填充 + 向后填充的组合
df['value'].fillna(method='ffill').fillna(method='bfill')
```

**应用场景**：
- 时间序列中的缺失值
- 需要平滑曲线

---

### 4. 多重插补

处理不确定性的高级方法：

```python
# MICE（多重插补链式方程）
from sklearn.experimental import enable_iterative_imputer
from sklearn.impute import IterativeImputer

imputer = IterativeImputer()
X_imputed = imputer.fit_transform(X)
```

**原理**：
- 多次迭代估计缺失值
- 反映不确定性

**优点**：
- 更全面地处理缺失
- 保留数据不确定性

**缺点**：
- 计算复杂
- 参数多

---

### 5. 特殊处理：将缺失作为特征

```python
# 创建缺失指示符
df['age_missing'] = df['age'].isna().astype(int)

# 填充值本身
df['age'].fillna(-1, inplace=True)  # 负值表示缺失

# 为缺失单独分类（分类特征）
df['category'] = df['category'].fillna('Missing')
```

**何时使用**：
- 缺失本身有信息（如 MAR 或 MNAR）
- 缺失与目标相关

## 实践指南

### 填充方法选择决策树

```
缺失比例？
├─ < 5%：删除或均值填充
├─ 5-30%：模型填充（KNN、插值）
└─ > 30%：
    ├─ 时间序列：插值
    ├─ 关键特征：KNN 或 MICE
    └─ 低重要性：删除列

缺失类型？
├─ MCAR：任何方法都可
├─ MAR：模型填充或多重插补
└─ MNAR：加入缺失指示符
```

### 常见错误

#### 错误 1：全数据填充
```python
# 错误：先合并数据，再计算均值
mean_value = df['age'].mean()  # 包含测试数据
df['age'].fillna(mean_value, inplace=True)

# 正确：仅在训练数据上计算
train_mean = train_df['age'].mean()
train_df['age'].fillna(train_mean, inplace=True)
test_df['age'].fillna(train_mean, inplace=True)
```

#### 错误 2：为分类特征填充均值
```python
# 错误
df['color'].fillna(df['color'].mean())  # 无意义

# 正确
df['color'].fillna(df['color'].mode()[0])  # 众数
```

#### 错误 3：忽视缺失的信息性
```python
# 如果缺失与目标相关，只删除可能引入偏差
# 更好的方式：加入缺失指示符
df['income_missing'] = df['income'].isna().astype(int)
df['income'].fillna(df['income'].median(), inplace=True)
```

## 评估填充质量

### 方法
```python
# 完整情况分析：仅用无缺失的行
model_complete = train_model(df.dropna())

# 填充数据分析：用填充后数据
model_imputed = train_model(df.fillna(...))

# 比较两个模型的性能差异
```

### 指标
- 填充前后的分布变化
- 模型性能的影响
- 异常值增加情况

---

## 进阶话题

### 缺失值的预测性
缺失本身可能预测目标，不应完全忽视：
```python
# Titanic 数据集：某些乘客的舱位信息缺失，缺失可能指示其生存率
df['cabin_missing'] = df['Cabin'].isna()
```

### 时间序列的缺失
需要考虑时间依赖性，不能随意填充

### 因果推理中的缺失
处理不当会导致因果推断错误
