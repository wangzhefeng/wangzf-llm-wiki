# 数据增强

## 定义与背景

**数据增强（Data Augmentation）**是指通过对原始数据进行变换，生成新的、多样化的训练样本的技术。

### 核心目标
1. **增加训练数据量**：特别是在数据稀缺的场景
2. **提高模型泛化能力**：使模型对不同形式的输入更鲁棒
3. **缓解过拟合**：在有限数据上训练深度模型
4. **处理不平衡**：为少数类生成合成样本

### 适用场景
- 计算机视觉（图像分类、目标检测）
- 自然语言处理（文本数据不易增强）
- 医学图像分析（获取标注数据困难）
- 不平衡数据集处理

## 图像数据增强

### 几何变换

#### 旋转（Rotation）
- 在合理范围内旋转图像（如 ±15°）
- 保留图像内容但改变方向
- 适用于物体识别（车、人脸等）

#### 平移与裁剪
- **平移**：沿 x、y 方向移动图像
- **裁剪**：移除图像边缘，关注中心内容
- 模拟不同拍摄位置

#### 缩放（Zooming）
- 放大或缩小图像
- 模拟相机距离变化
- 需注意边界填充方式

#### 翻转（Flip）
- 水平或垂直翻转
- 简单但有效
- 需考虑翻转后的合理性（如文字识别不适合）

#### 透视变换
- 改变图像的视角
- 模拟从不同角度观看

---

### 光度变换

#### 亮度调整
```python
# 随机调整亮度
brightness_adjusted = image * random(0.7, 1.3)
```
- 增加亮度变化，适应不同光照条件

#### 对比度调整
```python
# 增加或降低对比度
contrast_adjusted = image + random(-30, 30)
```

#### 色彩抖动（Color Jittering）
- 随机改变 RGB 通道的亮度、对比度、饱和度
- 增加颜色变化

#### 高斯噪声
- 加入随机噪声，模拟图像压缩或传感器噪声

---

### 高级增强方法

#### Mixup
- 线性插值混合两张图像及对应标签
- `x_mix = λ * x_i + (1 - λ) * x_j`
- `y_mix = λ * y_i + (1 - λ) * y_j`
- 优点：增加样本多样性，改善模型鲁棒性

#### CutMix
- 从另一张图像中裁剪一个区域，粘贴到当前图像
- 标签也按区域比例混合
- 相比 Mixup 保留了更多局部特征

#### RandAugment
- 随机应用一系列数据增强操作
- 控制增强的幅度
- 自动化、高效的增强策略

#### AutoAugment
- 使用强化学习或贝叶斯优化自动搜索最优增强策略
- 对特定数据集学习，性能更佳
- 计算成本高

## 数值/表格数据增强

### SMOTE 及其变种
- [[样本不平衡处理|详见样本不平衡处理]]
- 在特征空间中合成少数类样本

### 噪声注入
```python
# 给数值特征加高斯噪声
X_noisy = X + random_normal(0, std=0.1, size=X.shape)
```
- 增加数据扰动，改善模型鲁棒性
- 防止过拟合

### 特征缩放与变换
- 日志变换、幂变换处理长尾分布
- 间接形成数据增强

## 文本数据增强

### 回译（Back-Translation）
1. 翻译文本为另一语言：en → fr
2. 再翻译回原语言：fr → en
3. 保留语义但改变表述

### EDA（Easy Data Augmentation）
四种简单操作：
- **随机插入**：插入随机词汇
- **随机交换**：交换词汇顺序
- **随机删除**：随机删除词汇
- **同义词替换**：用同义词替换

### 文本生成
- 使用预训练模型（GPT）生成相似样本
- 需保证生成样本质量

## 工程实践

### 何时使用数据增强

| 数据量 | 模型复杂度 | 建议 |
|--------|----------|-----|
| 大 (>10K) | 简单 | 不必需 |
| 小 (<1K) | 复杂 | **必需** |
| 小 | 简单 | 可选 |
| 大 | 复杂 | **推荐** |

### 增强强度控制
- **过弱**：效果不明显
- **过强**：生成不合理样本，反而伤害性能
- **平衡点**：保持样本有效性，同时增加多样性

### 常见陷阱

#### 测试集不增强
**错误**：在测试集上应用增强
**后果**：评估不准确
**正确做法**：仅在训练集增强

#### 标签不一致
**错误**：只增强特征，忘记对应的标签
**后果**：错误的特征-标签对应
**正确做法**：特征和标签同时增强

#### 增强后过拟合
**现象**：训练集性能好，测试集差
**原因**：增强不足或模型过于复杂
**解决**：加强增强、正则化、更多数据

## 工具库

### Python 库

#### albumentations
```python
import albumentations as A
transform = A.Compose([
    A.HorizontalFlip(p=0.5),
    A.RandomBrightnessContrast(p=0.2),
    A.Rotate(limit=10, p=0.3),
], bbox_params=A.BboxParams(format='pascal_voc'))
```
- 高效、易用的图像增强库
- 支持不同图像格式和标注类型

#### imgaug
```python
import imgaug.augmenters as iaa
seq = iaa.Sequential([
    iaa.Fliplr(0.5),
    iaa.Affine(rotate=(-15, 15)),
    iaa.Multiply((0.8, 1.2))
])
```

#### torchvision 和 Keras Preprocessing
- PyTorch 和 TensorFlow 的内置支持
- 集成在训练管道中

## 进阶话题

### 元学习数据增强（Meta-Learning）
- 学习数据增强策略，而不是手动设计
- 对特定任务优化

### 对抗性数据增强（Adversarial Examples）
- 生成对抗样本，提高模型鲁棒性
- 同时用于安全研究

### 条件数据增强
- 基于样本特性的自适应增强
- 如对少数类更激进的增强
