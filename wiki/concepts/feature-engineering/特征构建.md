# 特征构建

## 定义与背景

**特征构建（Feature Engineering）**是指从现有特征出发，通过数学运算或领域知识创造新特征的过程。

### 核心目标
1. **提高表达能力**：创造更好地表示问题本质的特征
2. **捕获非线性关系**：使用特征交互、多项式等
3. **融入领域知识**：基于业务理解创造特征
4. **提升模型性能**：通常带来最大的性能提升

### 核心理念
> **"特征工程是 80% 的工作，模型调优只占 20%"** —— Kaggle 竞赛经验

---

## 核心方法

### 1. 交互特征（Interaction Features）

**定义**：两个或多个特征的乘积或组合

#### 二阶交互（最常见）
```python
# 数值特征交互
df['age_income'] = df['age'] * df['income']  # 捕获购买力
df['age_exp_ratio'] = df['age'] / df['experience']  # 相对值
```

**何时有用**：
- 特征间存在乘法关系（如年龄 × 收入 = 购买力）
- 模型是线性的（线性模型无法自动学习交互）

**优点**：
- 显式捕获特征关系
- 对线性模型有明显帮助

**缺点**：
- 计算成本高（n 个特征产生 n² 个交互）
- 需要领域知识判断哪些交互有意义

#### 应用示例
```python
# 电商推荐中的交互特征
df['user_product_score'] = df['user_rating'] * df['product_popularity']

# 时间序列中的交互
df['peak_hour_traffic'] = df['hour'] == 18 * df['traffic_volume']
```

---

### 2. 多项式特征（Polynomial Features）

生成高阶项和交互项的特征：
```python
from sklearn.preprocessing import PolynomialFeatures

# 2 阶多项式：(x1, x2) -> (1, x1, x2, x1², x2², x1*x2)
poly = PolynomialFeatures(degree=2)
X_poly = poly.fit_transform(X)
```

**数学形式**：
```
对于 (x1, x2)，2 阶多项式生成：
x1, x2, x1², x1*x2, x2²
```

**使用建议**：
- 低维数据（< 5 特征）：2-3 阶多项式
- 高维数据：仅生成有意义的交互，避免特征爆炸

**优点**：
- 自动化生成交互特征
- 对非线性关系建模

**缺点**：
- 特征数增长快（3 阶多项式会产生很多特征）
- 可能过拟合

---

### 3. 特征组合（Feature Grouping）

基于决策树的特征组合方法：

**思想**：决策树的每条路径代表一种特征组合方式

#### 例子：房价预测
```python
# 原特征：location, size, age
# 树学到的组合：
# (location=downtown) AND (size>2000) -> 高价格
# 创造组合特征：
df['downtown_large'] = (df['location']=='downtown') & (df['size']>2000)
```

**步骤**：
1. 训练决策树学习特征组合
2. 根据树的分裂规则提取组合
3. 创造新的组合特征

### 4. 自动特征工程（Automated Feature Engineering）

#### featuretools 库
自动化从多表关系数据生成特征

```python
import featuretools as ft

# 定义实体关系
entities = {
    "customers": (customers_df, "customer_id"),
    "orders": (orders_df, "order_id", "order_date")
}

# 自动生成深度特征
feature_matrix, feature_defs = ft.dfs(
    entities=entities,
    relationships=[
        ("customers", "customer_id", "orders", "customer_id")
    ],
    target_entity="customers",
    max_depth=2
)
```

**优势**：
- 自动从关系型数据生成特征
- 节省大量手工工作
- 挖掘隐藏的特征关系

**适用场景**：
- 多表关系数据
- 时间序列聚合特征

## 常见特征构建模式

### 时间序列特征

```python
# 时间特征
df['hour'] = df['datetime'].dt.hour
df['day_of_week'] = df['datetime'].dt.dayofweek
df['is_weekend'] = df['datetime'].dt.dayofweek.isin([5, 6])

# 滞后特征（前 n 步的值）
df['lag_1'] = df['value'].shift(1)
df['lag_7'] = df['value'].shift(7)

# 滚动统计
df['rolling_mean_7'] = df['value'].rolling(7).mean()
df['rolling_std_7'] = df['value'].rolling(7).std()
```

### 计数和聚合特征

```python
# 按类别计数
df['user_purchase_count'] = df.groupby('user_id')['order_id'].transform('count')

# 按类别统计
df['category_avg_price'] = df.groupby('category')['price'].transform('mean')
df['category_price_std'] = df.groupby('category')['price'].transform('std')

# 比例特征
df['purchase_ratio'] = df['purchases'] / df['visits']
```

### 文本特征

```python
# 文本长度
df['text_length'] = df['text'].str.len()
df['word_count'] = df['text'].str.split().str.len()

# 词汇丰富度
df['unique_word_ratio'] = df['text'].apply(lambda x: len(set(x.split())) / len(x.split()))
```

## 实践指南

### 特征构建工作流

```
1. 理解数据和问题
   ├─ 领域专家咨询
   └─ 数据探索性分析（EDA）

2. 特征构想
   ├─ 基于领域知识列举可能的特征
   ├─ 分析特征与目标的关系
   └─ 尝试不同的变换

3. 特征验证
   ├─ 统计显著性检验
   ├─ 模型性能影响评估
   └─ 交叉验证验证稳定性

4. 特征选择
   └─ 移除不相关或冗余特征

5. 迭代改进
   └─ 基于模型反馈，构建新特征
```

### 何时构建新特征

**好信号**：
- 特征能被业务解释
- 对目标有明显的单调或非线性关系
- 在多个模型和数据集上都有效

**坏信号**：
- 特征与目标几乎独立
- 交叉验证性能提升不稳定
- 无法解释

### 常见陷阱

#### 数据泄露
**问题**：构建特征时使用了测试集的信息
**例**：计算全局均值用于填充，未分离训练测试
**解决**：总是在训练集上计算统计量

#### 过度构建
**问题**：创造过多特征，导致过拟合
**症状**：训练集性能高，测试集性能差
**解决**：特征选择，正则化

#### 忽视特征交互
**问题**：特征本身可能无用，但交互有用
**例**：年龄本身无预测力，但年龄×收入有用
**解决**：主动考虑交互

## 特征构建检查清单

- [ ] 新特征是否可被业务解释？
- [ ] 特征对目标有关联性吗？
- [ ] 交叉验证中性能提升是否稳定？
- [ ] 是否检查了数据泄露？
- [ ] 新特征是否与现有特征冗余？
- [ ] 对新特征的缺失值有处理吗？

## 进阶话题

### 深度学习的特征学习
神经网络可以自动学习特征，无需手工构建：
- 卷积层自动学习图像特征
- 嵌入层学习类别表示

### 基于模型的特征生成
使用中间层的激活作为新特征（迁移学习）
