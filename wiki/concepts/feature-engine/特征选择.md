# 特征选择

## 定义与背景

**特征选择**是从原始特征集中选择一个相关性强的特征子集的过程，同时移除不相关或冗余的特征。

### 核心目标
1. **降低维度**：减少特征数，加速模型训练
2. **提高模型性能**：移除噪声特征，避免过拟合
3. **提升可解释性**：简化模型，更易理解
4. **节省资源**：降低存储和计算需求

### 为什么需要特征选择？
- 高维数据易导致过拟合
- 冗余特征增加计算负担
- 不相关特征引入噪声
- 特征过多难以解释

### 经验法则
> **"More data beats clever algorithms, but better features beat more data"** — Andrew Ng

---

## 特征选择方法分类

### 1. 过滤方法（Filter Methods）

特点：基于特征与目标的统计关系，独立于模型。

#### 方差阈值
移除方差很小的特征（几乎所有样本都是常数）：
```python
from sklearn.feature_selection import VarianceThreshold
selector = VarianceThreshold(threshold=0.01)
X_filtered = selector.fit_transform(X)
```

#### 相关系数
计算特征与目标的相关性：
```python
# 皮尔逊相关系数（数值特征）
correlation = X.corr(y)
selected = correlation[abs(correlation) > 0.1].index

# 互信息（分类特征）
from sklearn.feature_selection import mutual_info_classif
scores = mutual_info_classif(X, y)
```

#### 统计检验
- **卡方检验**（分类特征）：检验特征与类的独立性
- **ANOVA F-检验**（数值特征）：检验不同类的均值差异

#### 优点与缺点
- **优点**：快速、计算效率高、独立于模型
- **缺点**：忽视特征间交互，不考虑模型需求

---

### 2. 包装方法（Wrapper Methods）

特点：基于模型性能评估，选择最优特征子集。

#### 前向选择（Forward Selection）
```
从空特征集开始
  循环：
    添加能最大化模型性能的特征
    直到性能不再提升
```
- 贪心策略，逐步添加特征
- 计算成本中等

#### 后向消除（Backward Elimination）
```
从所有特征开始
  循环：
    移除对模型性能影响最小的特征
    直到性能下降
```

#### 递归特征消除（RFE）
```python
from sklearn.feature_selection import RFE
from sklearn.ensemble import RandomForestClassifier

rf = RandomForestClassifier()
rfe = RFE(rf, n_features_to_select=10)
X_rfe = rfe.fit_transform(X, y)
```
- 递归训练模型，根据特征权重移除
- 常用，效果良好

#### 优点与缺点
- **优点**：考虑特征交互，与模型相关，性能通常最好
- **缺点**：计算成本高，易过拟合

---

### 3. 嵌入方法（Embedded Methods）

特点：在模型训练过程中进行特征选择。

#### 基于系数的选择
线性模型的系数大小反映特征重要性：
```python
from sklearn.linear_model import Lasso
lasso = Lasso(alpha=0.01)
lasso.fit(X, y)
# 系数接近 0 的特征可移除
```

#### 基于树的特征重要性
```python
from sklearn.ensemble import RandomForestClassifier
rf = RandomForestClassifier()
rf.fit(X, y)
importances = rf.feature_importances_
important_features = X.columns[importances > threshold]
```
- 决策树、随机森林、XGBoost 等都提供特征重要性
- 快速、有效

#### 优点与缺点
- **优点**：计算高效，避免过拟合
- **缺点**：依赖特定算法，可能忽视低阶交互特征

## FeatureSelector 工具

[[2026-04-06-FeatureSelector特征选择工具|FeatureSelector 库]]提供了自动化的特征选择，包含 5 个关键方法：

### 1. 缺失值特征过滤
识别并移除缺失值比例过高的特征：
```python
fs.identify_missing(missing_threshold=0.6)
# 移除缺失值超过 60% 的特征
```

### 2. 单值特征过滤
移除方差接近 0 的特征（几乎所有样本都是同一值）：
```python
fs.identify_single_unique_value()
```

### 3. 共线特征识别
计算特征间相关性，移除相关性过高的冗余特征：
```python
fs.identify_collinear(correlation_threshold=0.95)
# 移除相关性 > 0.95 的特征对中的一个
```

### 4. 零重要性特征
基于 LightGBM 训练，移除重要性为 0 的特征：
```python
fs.identify_zero_importance(task='classification')
```

### 5. 低重要性特征
移除重要性低于设定阈值的特征：
```python
fs.identify_low_importance(importance_threshold=0.01)
```

## 实践指南

### 特征选择工作流

```
1. 基线建立
   └─ 用全量特征训练模型，记录性能

2. 快速过滤（Filter）
   ├─ 移除方差低的特征
   ├─ 移除缺失值过多的特征
   └─ 特性选择后重新评估

3. 包装/嵌入方法
   ├─ 基于模型重要性排名特征
   └─ 递归移除不重要特征

4. 交叉验证
   └─ 确保特征选择稳定性

5. 最终评估
   └─ 在完全独立的测试集评估
```

### 常见陷阱

#### 数据泄露
**问题**：在全数据集上执行特征选择后再划分训练测试集
**后果**：测试集性能过度乐观
**解决**：先划分训练测试集，在训练集上选择特征

#### 过度选择
**问题**：移除太多特征，导致模型欠拟合
**症状**：训练集和测试集性能都很差
**解决**：逐步调整阈值，找到平衡点

#### 忽视业务含义
**问题**：仅基于统计指标，移除业务上重要的特征
**解决**：与业务专家沟通，保留关键特征

## 特征数量指南

### 经验法则

| 样本数 | 推荐特征数 |
|--------|-----------|
| < 100 | 5-10 |
| 100-1K | 10-50 |
| 1K-10K | 50-200 |
| > 10K | 200+ |

### 模型相关指导

| 模型类型 | 特征敏感性 | 建议 |
|---------|----------|-----|
| 线性模型 | 高 | 严格选择，避免多重共线性 |
| 树模型 | 低 | 可保留更多特征 |
| 神经网络 | 中 | 需避免过多稀疏特征 |
| SVM | 高 | 建议特征缩放和选择 |

## 进阶话题

### 动态特征选择
在训练过程中动态调整使用的特征集

### 特征交互选择
不仅选择单特征，还考虑有意义的特征交互

### 自动机器学习中的特征选择
AutoML 工具（如 Auto-sklearn）自动执行特征选择和超参优化
