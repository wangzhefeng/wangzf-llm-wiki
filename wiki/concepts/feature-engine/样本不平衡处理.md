# 样本不平衡处理

## 定义与背景

**样本不平衡（Class Imbalance）**是指机器学习数据集中，不同类别的样本数量差异大的现象。

### 典型场景
- **欺诈检测**：欺诈案例通常 < 1%
- **疾病诊断**：患病样本远少于健康样本
- **故障预测**：故障案例 < 5%
- **推荐系统**：正反馈远少于负反馈

### 核心问题
- 模型偏向多数类，对少数类预测能力差
- 使用准确率（Accuracy）作为指标会误导（即使全部预测为多数类也有高准确率）
- 少数类的重要特征可能被忽视

---

## 问题诊断

### 不平衡程度衡量
```python
# 类分布
positive = (y == 1).sum()
negative = (y == 0).sum()
imbalance_ratio = positive / negative  # 或 negative / positive
```

**不同等级的影响**：
- 比例 1:10：轻度不平衡，部分算法可接受
- 比例 1:100：中度不平衡，需采取措施
- 比例 1:1000+：严重不平衡，必须专门处理

---

## 核心解决方案

### 1. 采样方法

#### 过采样（Oversampling）- 增加少数类

**随机过采样**
- 简单复制少数类样本
- **优点**：简单直接
- **缺点**：易过拟合，无新信息

**SMOTE（Synthetic Minority Over-sampling Technique）**
- 在少数类样本的特征空间中合成新样本
- 算法：为每个少数类样本找 k 个最近邻，在其和邻居之间的线段上随机生成新样本
- **优点**：生成新样本，降低过拟合风险
- **缺点**：计算成本高，可能生成噪声样本

**ADASYN（Adaptive Synthetic Sampling）**
- 自适应合成采样
- 对难分类的少数样本生成更多合成样本
- **优点**：专注于决策边界困难区域
- **缺点**：复杂度更高

**Borderline-SMOTE**
- 仅在决策边界附近合成样本
- 更加高效和专注

**代码示例**：
```python
from imblearn.over_sampling import SMOTE, ADASYN

# SMOTE
smote = SMOTE(random_state=42)
X_resampled, y_resampled = smote.fit_resample(X_train, y_train)

# ADASYN
adasyn = ADASYN(random_state=42)
X_resampled, y_resampled = adasyn.fit_resample(X_train, y_train)
```

---

#### 欠采样（Undersampling）- 减少多数类

**随机欠采样**
- 随机移除多数类样本
- **优点**：快速，减少训练数据
- **缺点**：丢失重要信息

**NearMiss**
- 保留与少数类距离较近的多数类样本
- 保留信息更充分

**TomekLinks**
- 移除多数类与少数类边界上的多数类样本
- 专注于清理模糊边界

**代码示例**：
```python
from imblearn.under_sampling import RandomUnderSampler, NearMiss

# 随机欠采样
rus = RandomUnderSampler(random_state=42)
X_resampled, y_resampled = rus.fit_resample(X_train, y_train)

# NearMiss
nm = NearMiss(version=1)
X_resampled, y_resampled = nm.fit_resample(X_train, y_train)
```

---

#### 混合方法

**结合过采样和欠采样**
```python
from imblearn.pipeline import Pipeline
from imblearn.over_sampling import SMOTE
from imblearn.under_sampling import RandomUnderSampler

# 先 SMOTE 后欠采样
pipeline = Pipeline([
    ('smote', SMOTE(random_state=42)),
    ('under', RandomUnderSampler(random_state=42))
])
X_resampled, y_resampled = pipeline.fit_resample(X_train, y_train)
```

### 2. 损失函数与权重调整

#### 加权交叉熵
为少数类分配更大权重：
```python
# sklearn LogisticRegression
clf = LogisticRegression(class_weight='balanced')
# 自动计算权重：weight = n_samples / (n_classes * n_samples_per_class)

# 自定义权重
class_weights = {0: 1, 1: 10}  # 少数类权重 10 倍
clf = LogisticRegression(class_weight=class_weights)

# PyTorch
criterion = nn.CrossEntropyLoss(weight=torch.tensor([1.0, 10.0]))
```

#### Focal Loss
为困难样本动态调整权重：
```
Focal Loss = -α_t * (1 - p_t)^γ * log(p_t)
```
- 困难分类（p_t 小）的权重更大
- 常用于目标检测（RetinaNet）

---

### 3. 模型与阈值调整

#### 集成方法
- **EasyEnsemble**：多个欠采样数据集的集成
- **RUSBoost**：欠采样 + Boosting
- **BalancedRandomForest**：每棵树使用平衡样本

#### 阈值调整
默认分类阈值为 0.5，可根据业务需求调整：
```python
# 提高阈值，偏向多数类
y_pred_adjusted = (model.predict_proba(X)[:, 1] > 0.7).astype(int)

# 降低阈值，偏向少数类
y_pred_adjusted = (model.predict_proba(X)[:, 1] > 0.3).astype(int)
```

## 实践应用

### 工作流程
1. **诊断**：确定不平衡程度和比例
2. **选择方法**
   - 轻度：用评估指标（F1、AUC）替代准确率
   - 中度：过采样（SMOTE）或加权
   - 严重：组合方法（SMOTE + 欠采样 + 加权 + 集成）
3. **验证**：必须在训练集采样，测试集保持原始分布
4. **评估**：使用不平衡友好的指标

### 常见陷阱

#### 错误 1：在测试集上采样
**后果**：破坏原始分布，评估不准确
**正确做法**：仅在训练集采样

#### 错误 2：仅用准确率评估
**后果**：模型全部预测为多数类也有高准确率
**正确做法**：使用 F1、Precision-Recall、ROC-AUC

#### 错误 3：忽视业务成本
**后果**：假正例和假负例成本不对等
**正确做法**：根据成本矩阵调整阈值

## 评估指标选择

### 不平衡友好的指标

| 指标 | 含义 | 适用场景 |
|-----|-----|---------|
| **F1-Score** | P 和 R 的调和平均 | 平衡精确率和召回率 |
| **Precision** | TP / (TP + FP) | 关心误报（如医学诊断） |
| **Recall** | TP / (TP + FN) | 关心漏报（如欺诈检测） |
| **ROC-AUC** | 受试者工作特性曲线 | 不受阈值和分布影响 |
| **PR-AUC** | 精确率-召回率曲线 | 高度不平衡数据 |

### 混淆矩阵理解
```
             实际正例  实际负例
预测正例      TP        FP
预测负例      FN        TN

P = TP / (TP + FP)  （精确率）
R = TP / (TP + FN)  （召回率）
F1 = 2 * P * R / (P + R)
```

## 进阶话题

### 回归中的不平衡
虽然不如分类明显，但极端目标值样本过少也会困难：
```python
from imblearn.regression import RandomUnderSampler, SMOTE

# 基于目标值的采样
undersampler = RandomUnderSampler(random_state=42)
```

### 多分类不平衡
处理方式类似，可选择 one-vs-rest 策略

### 代价敏感学习
根据错分代价（误报 vs 漏报）调整模型优化目标
