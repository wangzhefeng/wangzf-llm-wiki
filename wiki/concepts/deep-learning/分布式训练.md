# 分布式训练

## 定义

分布式训练是将模型训练任务分配到多个 GPU 或多台机器上，以加速训练或支持超大模型的技术。

## 主要范式

### 1. 数据并行（Data Parallelism）

- **DistributedDataParallel (DDP)**: PyTorch 原生分布式训练
- 每个 GPU 持有一份模型副本，数据分片
- 通信开销：梯度同步

### 2. 模型并行（Model Parallelism）

- **张量并行（Tensor Parallelism）**: 将单层切分到多个 GPU
- **流水线并行（Pipeline Parallelism）**: 将层切分到多个 GPU

### 3. 混合并行

- **FSDP (Fully Sharded Data Parallel)**: ZeRO 优化，分片存储模型参数、梯度、优化器状态
- **3D Parallelism**: 数据并行 + 张量并行 + 流水线并行

## 关键工具

| 工具 | 特点 |
|------|------|
| **torchrun** | PyTorch 原生启动器 |
| **DeepSpeed** | Microsoft 分布式训练框架 |
| **Megatron-LM** | NVIDIA 大规模训练框架 |

## 在大模型训练中的应用

- **万亿参数模型**: 需要千卡 GPU，3D 并行
- **LLaMA 训练**: 使用 FSDP + 数据并行
- **DeepSeek-V3**: MoE 架构 + 分布式训练
