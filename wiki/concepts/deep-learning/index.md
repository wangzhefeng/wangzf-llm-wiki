# wiki/concepts/deep-learning

本目录存放深度学习相关概念与方法页。

## 核心概念页（Tier 1，5 个）

1. [[深度学习概览]] — 深度学习作为表示学习与基于梯度优化的神经网络总览
2. [[反向传播与梯度问题]] — 梯度高效计算的核心训练机制，梯度消失/爆炸问题
3. [[深度学习优化算法]] — 梯度计算后的参数更新框架（SGD、Momentum、Adam 等）
4. [[注意力机制]] — 使模型聚焦相关信息的核心架构组件（自注意力、多头注意力）
5. [[循环神经网络]] — 处理序列与时序数据的核心架构族（隐状态传播）
