# Regression Discontinuity Design（断点回归设计）

## 定义

断点回归设计（Regression Discontinuity Design，RDD）是一种**准实验方法**，利用**政策或规则的离散变化**产生的自然断点来识别因果效应。当处理的分配基于**一个阈值变量（运行变量）的取值**时，在阈值附近，两组个体在除了处理分配外的所有特征上都是可比的，从而可以识别处理的因果效应。

**核心思想**：在截断点处，处理的分配具有类似于随机的特性，因此可以比较截断点两侧的结果变化。

## 基本思想

### 运行变量与处理分配

设 $R_i$ 为**运行变量**（Running Variable），$c$ 为截断阈值：
- 若 $R_i \geq c$：个体 $i$ 接受处理（$Z_i = 1$）
- 若 $R_i < c$：个体 $i$ 不接受处理（$Z_i = 0$）

**关键特征**：
- 处理的分配完全由 $R_i$ 与 $c$ 的关系决定
- 在截断点 $c$ 处，处理从 0 跳跃到 1（或从某个水平跳到另一个水平）

### 本地随机化的直观理解

在截断点 $c$ 的**邻域内**：
- 若两个个体的 $R_i$ 值非常接近（分别略大于和略小于 $c$），则它们只因为 $R_i$ 跨越了阈值而被分配到不同的处理组
- 这类似于一个**本地的随机实验**，使得处理分配独立于其他潜在混杂因子

**因果图表示**：
```
运行变量 R ⊥ 潜在结果 Y(0), Y(1) | R ≈ c
```

## Sharp RDD vs Fuzzy RDD

### Sharp RDD（锐利型）

处理的分配由运行变量**严格确定**（无例外）：

$$Z_i = \mathbb{1}(R_i \geq c)$$

其中 $\mathbb{1}(\cdot)$ 是指示函数。

**特点**：
- 在截断点处，处理分配发生**跳跃**
- 无论个体是否遵从分配规则，效应都是明确的
- 估计相对简单

**应用**：
- 教育政策：入学年龄截断
- 考试招生：分数线截断
- 福利制度：收入线截断

### Fuzzy RDD（模糊型）

处理的分配由运行变量**决定，但存在不遵从**：

$$P(Z_i = 1 | R_i \geq c) > P(Z_i = 1 | R_i < c)$$

但在两侧处理的概率都不是 0 或 1。

**特点**：
- 处理分配在截断点处**不是完全的跳跃**，而是概率增加
- 需要使用 IV 方法（Wald 估计）纠正遵从性问题
- 估计的是**局部平均处理效应（LATE）**

**应用**：
- 学生资助与上学人数（不是所有有资格的都申请）
- 试验推广：每个地区有一定概率参加

## 关键假设

### 1. 连续性假设（Continuity Assumption）

潜在结果 $Y_i(0)$ 和 $Y_i(1)$ 在运行变量 $R_i$ 处**连续**：

$$\lim_{r \to c^+} E[Y_i(1) | R_i = r] = E[Y(1) | R_i = c]$$
$$\lim_{r \to c^-} E[Y_i(0) | R_i = r] = E[Y(0) | R_i = c]$$

**含义**：
- 在截断点处，处理的跳跃引起的结果变化就是处理效应
- 运行变量本身不应该在截断点处跳跃（即无自选效应）

**验证方法**：
- 检验运行变量的分布在截断点处是否连续（McCrary 检验）
- 检验其他前期特征在截断点处是否连续

### 2. 排除限制（Exclusion Restriction）

运行变量对结果的影响**完全通过**处理分配：

$$E[Y_i | R_i = r, Z_i = z] \text{ 在 } r \text{ 处连续，对所有 } z$$

**含义**：
- 在控制处理分配 $Z$ 后，$R_i$ 对 $Y_i$ 的影响应该是光滑的
- 不能存在 $R_i$ 在截断点处对 $Y_i$ 的**直接、非线性跳跃**

**违反案例**：
```
政策：当收入 > 10 万时，无法获得福利
问题：即使无处理，恰好处于临界收入的人也可能因多种因素而处于临界
      福利金额本身可能在阈值处设计有特殊考量
```

### 3. 没有对截断点的操纵（No Manipulation）

个体无法精确控制自己在运行变量的取值，特别是在截断点附近。

**验证**：McCrary 检验、运行变量在截断点处的密度检验

**违反案例**：
- 学生可以选择参加高考的年份，以规避截断规则
- 企业可以操纵报表收入，以避免达到特定的财税阈值

## 识别与估计方法

### 局部线性回归（Local Linear Regression）

这是 RDD 中最常用的估计方法。

**模型**：在截断点 $c$ 附近（带宽 $h$ 内），分别为左右两侧拟合线性回归：

**左侧**（$R_i < c$）：
$$E[Y_i | R_i] = \alpha_L + \beta_L (R_i - c) + \text{higher order terms}$$

**右侧**（$R_i \geq c$）：
$$E[Y_i | R_i] = \alpha_R + \beta_R (R_i - c) + \text{higher order terms}$$

**处理效应估计**：
$$\tau = \alpha_R - \alpha_L$$

即在截断点处，两条线性拟合曲线的**纵向距离**。

### Sharp RDD 的参数形式

$$Y_i = \alpha + \beta_L (R_i - c) \mathbb{1}(R_i < c) + \beta_R (R_i - c) \mathbb{1}(R_i \geq c) + \tau Z_i + \epsilon_i$$

其中 $Z_i = \mathbb{1}(R_i \geq c)$ 是处理指示。

参数 $\tau$ 直接估计的是因果效应。

### Fuzzy RDD（工具变量方法）

在 Fuzzy RDD 中，使用工具变量：
$$Z_i = \mathbb{1}(R_i \geq c)$$

通过 2SLS 估计：
$$\hat{\tau}_{Fuzzy} = \frac{E[Y_i | R_i \geq c] - E[Y_i | R_i < c]}{E[Z_i | R_i \geq c] - E[Z_i | R_i < c]}$$

这估计的是**局部平均处理效应（LATE）**。

### 带宽选择

局部线性回归的关键是带宽 $h$ 的选择：
- $h$ 太大：可能违反局部线性假设
- $h$ 太小：样本量少，方差大

**标准做法**：
- 使用数据驱动的带宽选择（如 Imbens-Kalyanaraman 带宽）
- 进行敏感性分析：用不同带宽重复估计，检查结果稳定性

## 应用案例

### 案例 1：教育入学年龄与学业成就（经典研究）

**背景**：许多国家规定 9 月 1 日前出生的儿童入学

**运行变量**：出生日期（相对于 9 月 1 日）

**处理**：入学年龄（早一年 vs 晚一年）

**结果变量**：PISA 成绩、毕业率等

**机制**：
- 同一个班级，出生日期早的学生年龄稍大，可能有学业优势
- 在截断点两侧，其他因素相同，仅年龄不同
- 因此可以识别年龄对学业成就的因果效应

**发现**：一年的年龄差异导致约 3-5% 的成绩差异

### 案例 2：贫困线与福利效应评估

**背景**：福利项目通常有收入阈值，低于阈值的家庭可获得福利

**运行变量**：家庭收入（相对于贫困线）

**处理**：是否获得福利

**结果变量**：儿童教育、健康指标、长期收入等

**机制**：
- 在阈值附近，两个相似的家庭因收入稍有不同而获得不同福利
- 比较截断点两侧的结果，识别福利的因果效应

**考量**：
- Sharp RDD：硬性规则，严格按收入线分配
- Fuzzy RDD：有些符合条件的家庭未申请，或有例外处理

### 案例 3：考试分数与大学录取

**背景**：大学录取通常有最低分数线

**运行变量**：考试成绩

**处理**：被大学录取

**结果变量**：毕业率、就业前景、收入等

**识别**：
- 在截断点附近，略高于分数线和略低于分数线的考生，其他能力相似
- 分数线导致的录取差异完全源于被录取本身，而非潜在能力差异

## 常见陷阱与误区

### 陷阱 1：违反连续性假设的不当截断

❌ **错误**：使用经济上有显著意义的阈值（如 10 万元收入线），而不验证连续性

✓ **正确**：总是进行 McCrary 密度检验，确认运行变量分布在截断点连续

**案例**：
- 如果许多企业有激励在阈值处报告收入，密度会在截断点处不连续
- 这违反了 RDD 的基本假设

### 陷阱 2：忽视运行变量的可操纵性

❌ **错误**：假设个体无法在截断点处操纵运行变量

✓ **正确**：评估是否存在对截断点的**精确操纵**

**案例**：
- 学生可以选择何时参加高考（年级、场次），可能在截断点处自选
- 企业可以调整报表收入，以避免达到特定税收阈值

**解决方法**：
- 使用**意图处理（ITT）**方法，这对轻微的操纵不敏感
- 进行敏感性分析，假设存在小程度的操纵

### 陷阱 3：带宽选择的武器化

❌ **错误**：尝试多个带宽，选择给出"想要的"结果的带宽（p-hacking）

✓ **正确**：预先指定带宽选择方法，或进行鲁棒性检查

**标准做法**：
- 使用 Imbens-Kalyanaraman 或 Cross-Validation 的数据驱动带宽
- 总是报告在几个不同带宽下的估计

### 陷阱 4：忽视本地性

❌ **错误**：将 RDD 估计的效应推广到整个人口

✓ **正确**：清楚 RDD 只估计**在截断点附近的局部因果效应**

**含义**：
- RDD 估计的是 $E[\tau_i | R_i = c]$（截断点处的效应）
- 对于远离截断点的个体，处理效应可能不同
- 这类似于工具变量估计的 LATE

### 陷阱 5：前期特征的虚假不平衡

❌ **错误**：在截断点处发现一个前期特征不平衡，就否定 RDD

✓ **正确**：进行多重比较校正，或预先指定关键特征

**背景**：
- 在截断点附近进行多次平衡检验，由于多重检验，会有假阳性
- 应该在事先指定的关键特征上检查平衡

## 与其他方法的对比

| 方法 | 利用的变异 | 假设强度 | 适用条件 | 效应类型 |
|---|---|---|---|---|
| **RDD** | 截断点的确定性 | 中等（连续性、排除限制） | 有清晰的政策截断 | 局部（截断点附近） |
| **工具变量** | 外生的政策变化 | 强（排除限制）| 有外生工具 | 全局（LATE） |
| **倾向得分** | 观测协变量的变异 | 中等（可忽略性） | 充分的重叠 | 全局（ATE） |
| **DID** | 时间×组别变异 | 中等（平行趋势） | 多时期面板数据 | 全局 |
| **随机对照试验** | 实验随机化 | 最弱 | 可执行实验 | 全局 |
