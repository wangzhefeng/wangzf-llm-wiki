# Causal Inference Methods（因果推断方法库）

## 概述

因果推断方法众多，各适用于不同的数据特征和研究问题。本页提供方法库的系统分类、对比与选择指南。

## 方法分类

### 按数据类型分类

#### 随机化实验数据（Experimental Data）
**特点**：处理随机分配，可忽略性自动满足

| 方法 | 难度 | 适用 | 备注 |
|---|---|---|---|
| **简单差异** | ⭐ | 完全随机化 | 直接计算处理组 - 对照组均值 |
| **回归调整** | ⭐ | 完全/分组随机化 | 控制基线特征，降低方差 |

#### 观察性数据（Observational Data）
**特点**：处理自选，存在混杂偏倚，需假设可忽略性

| 方法 | 难度 | 关键假设 | 优/缺点 |
|---|---|---|---|
| **回归调整** | ⭐ | 模型规格正确 | 简单/易有模型误设 |
| **倾向评分匹配** | ⭐⭐ | 可忽略性、重叠 | 直观/样本损失 |
| **倾向评分分层** | ⭐ | 可忽略性、重叠 | 保留全样本/信息丢失 |
| **IPW** | ⭐⭐ | 可忽略性、重叠、权重稳定 | 灵活/权重波动 |
| **双重机器学习** | ⭐⭐⭐ | 可忽略性 | 高维数据/复杂 |

#### 自然实验数据（Natural Experiment）
**特点**：存在排除限制（IV）或分割点（RDD）

| 方法 | 难度 | 关键假设 | 适用 |
|---|---|---|---|
| **工具变量** | ⭐⭐ | 相关性、外生性、排除限制 | 存在 IV |
| **RDD** | ⭐⭐ | 连续性、排除限制 | 存在分割点 |
| **DID** | ⭐⭐ | 平行趋势 | 政策冲击 |
| **合成控制法** | ⭐⭐ | 预处理期平衡 | 单个单位处理 |

### 按因果效应类型分类

#### 1. 平均处理效应（ATE）

**定义**：$\text{ATE} = E[Y(1) - Y(0)]$

**适用方法**：
- 随机化：简单差异、回归
- 观察性：PSM、回归、IPW
- 自然实验：IV、RDD、DID

**优点**：总体平均，便于决策

**缺点**：掩盖异质性

#### 2. 条件平均处理效应（CATE）

**定义**：$\text{CATE}(x) = E[Y(1) - Y(0) | X=x]$

**适用方法**：
- 条件回归
- 因果森林（Causal Forest）
- 因果树（Causal Trees）
- X-Learner、R-Learner

**优点**：反映异质性

**缺点**：样本需求大，模型复杂

#### 3. 局部平均处理效应（LATE）

**定义**：$\text{LATE} = E[Y(1) - Y(0) | Z=1, Z_i \text{ complier}]$

**适用方法**：
- 模糊 RDD（Fuzzy RDD）
- 弱工具变量下的 IV

**优点**：有明确的群体定义

**缺点**：样本子集，推广性有限

## 主要方法详解

### 1. 倾向评分匹配（PSM）

**核心思想**：匹配具有相似倾向得分的处理与对照个体

**优点**：
- 直观，易于解释
- 易于检验平衡性

**缺点**：
- 样本损失（未匹配个体被排除）
- 对匹配算法敏感

**何时用**：
- 中等样本（n=1000-10000）
- 需要审视假设与平衡性

**代码示例（Python）**：
```python
from dowhy import CausalModel
model = CausalModel(..., method_name='backdoor.propensity_score_matching')
```

### 2. 工具变量（IV）

**核心思想**：存在外生变量 $Z$（工具变量）满足：
- 相关性：$\text{Cov}(Z, X) \neq 0$
- 外生性：$Z \perp \{Y(1), Y(0)\}$
- 排除限制：$Z$ 仅通过 $X$ 影响 $Y$

**估计方法**：
- 二元工具：Wald 估计器
- 多个工具：两阶段最小二乘法（2SLS）

**优点**：
- 不依赖观测协变量
- 可处理内生性

**缺点**：
- 需要良好的工具变量（难找）
- 假设无法检验

**适用场景**：
- 天然政策实验（如分数线入学）
- 基于距离的政策（如评估教育补助）

### 3. 断点回归设计（RDD）

**核心思想**：处理在某个分割点处有跳跃

$$\text{ATE} = \lim_{x \to x_0^+} E[Y|X=x] - \lim_{x \to x_0^-} E[Y|X=x]$$

**Sharp RDD**：处理由分割点完全决定

**Fuzzy RDD**：分割点仅影响处理概率

**优点**：
- 最接近实验的因果推断
- 假设相对合理

**缺点**：
- 需要精确的分割点
- 仅识别局部效应

**适用场景**：
- 考试成绩与奖学金
- 投票年龄与参与度
- 收入与福利资格

### 4. 双重差分法（DID）

**核心思想**：利用时间变化与对照组来识别政策效应

$$\text{DID} = [E[Y_{\text{treatment,after}}] - E[Y_{\text{treatment,before}}]] - [E[Y_{\text{control,after}}] - E[Y_{\text{control,before}}]]$$

**关键假设**：平行趋势（Parallel Trends）

**优点**：
- 允许处理组和对照组有恒定的水平差异
- 灵活，易于扩展

**缺点**：
- 平行趋势难以检验
- 需要面板数据

**适用场景**：
- 政策改革（如税收改革）
- 地区政策（如最低工资）
- 行业监管变化

### 5. 合成控制法（Synthetic Control）

**核心思想**：用对照单位的加权组合模拟处理单位的反事实轨迹

$$Y_{\text{treatment}}^{\text{counterfactual}} = \sum_{j} w_j Y_{\text{control},j}$$

**优点**：
- 处理单个单位
- 透明的权重

**缺点**：
- 样本需求少（仅 1 个处理单位）
- 权重选择敏感

**适用场景**：
- 国家/城市级别政策评估
- 企业并购效应评估

### 6. 双重机器学习（Double Machine Learning）

**核心思想**：结合机器学习与参数模型，避免维度诅咒

$$\text{DML ATE} = \frac{1}{n}\sum_i \frac{(Z_i - \hat{e}(X_i))(Y_i - \hat{m}(X_i))}{\mathbb{V}(Z|X)}$$

**优点**：
- 处理高维协变量
- 参数收敛速度快

**缺点**：
- 需要两个模型
- 参数选择复杂

**适用场景**：
- 高维数据（$p > n$）
- 图像/文本特征

## 方法选择决策树

```
你有什么数据？
├─ 随机化实验？
│  └─ YES → 简单差异 或 回归调整 ⭐⭐⭐
├─ 观察数据 + 可忽略性？
│  ├─ 低维 → PSM 或 回归调整 ⭐⭐⭐
│  └─ 高维 → 双重机器学习 ⭐⭐
├─ 存在工具变量？
│  └─ YES → IV / 2SLS ⭐⭐
├─ 存在分割点？
│  └─ YES → RDD ⭐⭐⭐
├─ 政策冲击 + 面板数据？
│  └─ YES → DID ⭐⭐⭐
├─ 单个单位处理？
│  └─ YES → 合成控制法 ⭐⭐⭐
└─ 关心异质性？
   └─ YES → 因果森林 / X-Learner ⭐⭐⭐
```

## 方法对比表

| 方法 | 数据类型 | 关键假设 | 样本需求 | 计算复杂度 | 当前热度 |
|---|---|---|---|---|---|
| PSM | 观察 | 可忽略性 | 中等 | 低 | 经典 |
| IPW | 观察 | 可忽略性、重叠 | 中等 | 低 | 常用 |
| 回归 | 实验/观察 | 模型规格 | 低 | 低 | 基础 |
| IV | 自然实验 | 排除限制 | 中等 | 中 | 稳定 |
| RDD | 自然实验 | 连续性 | 中等 | 中 | 流行 |
| DID | 面板 | 平行趋势 | 高 | 低 | 常用 |
| 合成控制 | 单位处理 | 预处理平衡 | 低 | 中 | 流行 |
| 双重 ML | 高维观察 | 可忽略性 | 高 | 高 | 前沿 |
| 因果森林 | 任意 | 可忽略性 | 高 | 高 | 前沿 |

## 常见错误与建议

❌ **一刀切**：只用一种方法
✓ **建议**：多方法估计，比较结果稳健性

❌ **忽视假设**：盲目应用方法
✓ **建议**：明确假设，进行敏感性分析

❌ **忽视异质性**：只看平均效应
✓ **建议**：检验是否存在异质性，必要时估计 CATE

❌ **样本量不足**：用高维方法
✓ **建议**：根据样本量选择合适复杂度的方法
