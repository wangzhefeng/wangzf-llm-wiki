# Causal Discovery（因果发现）

## 定义

因果发现（Causal Discovery）是从**观测数据**中自动或半自动地推断出**因果结构**（有向无环图 DAG）的过程。与传统的因果推断方法不同，后者假设因果图已知，而因果发现方法尝试从数据中**学习图的结构本身**。

**核心问题**：给定数据，如何识别哪些变量因果影响哪些变量？

## 问题定义与挑战

### 识别问题的根本困难

#### 1. Markov 等价类

多个不同的有向无环图可能产生**相同的条件独立关系**，因此无法从观测数据中唯一区分它们。

**经典例子**：
```
图 1: X → Y ← Z
图 2: X ← Y → Z
图 3: X → Y → Z
```

这三个图都可能与某一组观测数据兼容，仅用条件独立关系无法区别。

#### 2. 非参数不可识别性

即使假设因果关系的函数形式，观测数据中的相关性仍可能来自：
- $X$ 因果影响 $Y$
- $Y$ 因果影响 $X$
- $Z$ 同时影响两者

**含义**：无法仅从关联强度推断因果方向

#### 3. 遗漏变量问题

隐藏的混杂因子可能导致虚假的相关性，被算法误识别为直接因果关系。

### 数据要求

- **数据量**：通常需要相当大的样本量
- **变量数**：变量越多，识别难度呈指数增长
- **数据质量**：测量误差会削弱因果结构的识别

## 约束条件法（Constraint-Based Methods）

### 核心思想

利用**条件独立关系**识别 DAG：
1. 从完全图开始（所有变量都相连）
2. 检验条件独立关系
3. 删除不满足独立关系的边
4. 根据 Markov 条件推断因果方向

### PC 算法（Peter-Clark Algorithm）

**步骤**：

**第 1 步**：从完全无向图开始

**第 2 步**：条件独立检验
- 对每对变量 $(X, Y)$，测试是否存在变量集合 $S$ 使得 $X \perp Y | S$
- 若存在，删除边 $(X, Y)$
- 从大小为 0 的 $S$ 开始，逐步增大

**第 3 步**：方向推断
- 使用 v-structure（碰撞）规则和其他规则推断边的方向
- V-structure：若 $X \rightarrow Z \leftarrow Y$，且 $X \perp Y$ 但都与 $Z$ 相关，则可推断此结构

**算法伪代码**：
```
输入：观测数据，显著性水平 α
输出：因果有向无环图

1. 初始化：完全图 G
2. For each order of conditioning sets S:
     For each pair of vertices (X, Y):
       If X ⊥ Y | S (p > α):
         删除边 (X, Y) from G
3. 对所有可识别的 v-structures 推断方向
4. 应用传播规则推断其他边的方向
返回：有向无环图
```

### FCI 算法（Fast Causal Inference）

PC 算法的扩展，处理**隐藏混杂因子**的情况。

**关键改进**：
- 允许潜在的混杂因子（未观测变量）存在
- 使用双边箭头（↔）表示可能的混杂关系
- 输出：**部分祖宗图（Partial Ancestral Graph，PAG）**，包含有向和双向边

**优点**：更现实（承认存在隐藏变量）

**缺点**：计算复杂，输出的不确定性更大

### 约束法的优缺点

**优点**：
- 理论上对 Markov 等价类有清晰认识
- 对样本量需求相对较少（相比评分法）
- 直接利用条件独立理论

**缺点**：
- 条件独立检验在高维数据上不稳定
- 分别进行多次独立性检验会累积 I 型错误
- 对测量误差敏感

## 评分法（Score-Based Methods）

### 核心思想

定义**评分函数**衡量 DAG 与数据的拟合程度，搜索**得分最高的图**。

$$\text{Score}(G | D) = \text{Likelihood}(D | G) + \text{Penalty}(G)$$

### 常见评分函数

#### BIC（贝叶斯信息准则）

$$\text{BIC}(G) = -2 \log L(D | G) + k \log n$$

其中 $L(D | G)$ 是数据的似然，$k$ 是参数数量，$n$ 是样本量。

#### MDL（最小描述长度）

基于信息论，倾向于选择**更简洁的图**（边数少）。

#### 对数似然 + 正则化

$$\text{Score}(G) = \log L(D | G) - \lambda \cdot |E(G)|$$

其中 $|E(G)|$ 是边的数量，$\lambda$ 控制对复杂性的惩罚。

### 搜索策略

由于搜索所有可能的 DAG 是 NP-hard 的，采用**启发式搜索**：

#### 贪心搜索
逐步添加或删除边，选择使得分数提升最大的操作。

**优点**：计算快速

**缺点**：容易陷入局部最优

#### 模拟退火（Simulated Annealing）
允许暂时接受更差的状态，以跳出局部最优。

#### 遗传算法
维护多个候选图的种群，通过"交叉"和"变异"进化。

### 评分法的优缺点

**优点**：
- 能处理缺失值和测量误差
- 可以量化不同图的相对可能性
- 适合高维数据

**缺点**：
- 需要较大样本量
- 评分函数的选择影响结果
- 搜索复杂度高
- 仍然受 Markov 等价类限制

## Markov 等价类与可识别困难

### 等价性的本质

两个不同的 DAG $G_1$ 和 $G_2$ 被称为 **Markov 等价**，若它们诱导相同的条件独立关系。

**等价类中的 DAG 具有**：
- 相同的骨架（底层无向图）
- 相同的 v-structures（碰撞点）
- 但有向边的方向可能不同

### 完全祖宗图（CPDAGs）与等价类的表示

为了紧凑地表示一个等价类，使用**完全部分有向无环图（CPDAG）**：
- 有向边：在等价类的所有成员中都有相同方向
- 无向边：在等价类中可能有不同的方向

### 从数据识别的根本限制

**定理**（Verma & Pearl）：
仅从观测数据的条件独立关系，**无法唯一识别因果方向**，只能确定一个等价类。

**含义**：
- 即使有无限的数据，也无法区分 $X \rightarrow Y$ 和 $Y \rightarrow X$（若它们 Markov 等价）
- 识别因果方向**需要额外的信息或假设**

### 突破等价类的方法

#### 1. 非高斯假设与非线性关系
若变量间存在**非线性因果关系**，可以利用此特性识别方向。

**原理**：若 $Y = f(X) + \epsilon$，$f$ 非线性，则 $X$ 和 $\epsilon$ 不相关（由因果模型保证）。反过来，若 $X = g(Y) + \delta$，一般 $Y$ 与 $\delta$ 会相关（除非模型巧合具有特殊对称性）。

**工具**：线性非高斯无环模型（LiNGAM）

#### 2. 时间信息
若有**时间顺序数据**，因果必然沿时间箭头。可显著限制搜索空间。

#### 3. 领域知识约束
施加**先验约束**（某些边不存在、某个方向必然等），限制 DAG 空间。

#### 4. 隐变量模型
允许隐含变量，使用 FCI 或相关算法，降低对完全可观测性的依赖。

#### 5. 因果强度的异质性
若因果效应在不同子群体中异质，可利用此信息识别因果方向（Heterogeneous Effect Discrimination）。

## 实践工具

### 1. Tetrad（Java）

**特点**：
- 支持 PC、FCI 等多种约束法算法
- 可视化因果图
- 支持隐变量

**使用场景**：社会科学、心理学研究

**下载**：https://www.cmu.edu/tetrad/

### 2. causalml（Python）

**特点**：
- 支持多种因果发现和因果推断方法
- 与 sklearn 兼容的接口
- 积极维护

**代码示例**：
```python
from causalml.inference.tree import CausalTreeRegressor
from causalml.discovery import PC

# PC 算法
pc = PC()
dag = pc.fit(data, threshold=0.05)
```

### 3. DoWhy（Python）

**特点**：
- 集因果图、识别、估计于一体
- 支持多种识别和估计方法
- 文档完善

**工作流**：定义因果图 → 识别 → 估计 → 敏感性分析

### 4. pgmpy（Python）

**特点**：
- 概率图模型库
- 支持贝叶斯网络、马尔可夫网络
- 包含学习算法（PC、Hill Climbing 等）

```python
from pgmpy.estimators import PC
pc = PC(data)
model = pc.estimate()
```

### 5. causal-learn（Python）

**特点**：
- 现代化重新实现，支持多种算法
- 并行计算支持
- 性能优于早期 Tetrad 实现

```python
from causallearn.search.ConstraintBased.PC import pc
model, _ = pc(data)
```

## 应用案例

### 案例 1：医学诊断中的症状-疾病关系

**问题**：从患者的症状和检查数据，发现哪些疾病导致哪些症状

**方法**：
- 收集患者的多个症状和诊断标记
- 使用 PC 或 FCI 算法学习因果结构
- 允许隐藏的混杂因子（未测量的遗传或环境因子）

**输出**：症状和疾病之间的因果关系网络，指导诊断决策

### 案例 2：金融市场中的风险传导

**问题**：识别不同金融资产价格之间的因果传导路径

**方法**：
- 高频交易数据
- 使用时间 Granger 因果性检验（基于预测性）
- 结合信息熵减少法识别因果方向

**应用**：风险管理、投资组合对冲

### 案例 3：社交网络中的信息扩散

**问题**：理解用户行为之间的因果影响

**方法**：
- 收集用户的发帖、转发、点赞历史
- 学习用户间的影响网络
- 识别有影响力的节点（核心用户）

**应用**：推荐系统、舆论引导

## 常见陷阱与误区

### 陷阱 1：过度相信自动发现

❌ **错误**：运行因果发现算法，相信输出的图是"真实的因果结构"

✓ **正确**：认识到算法输出是基于数据和假设的**候选图**，需要专家验证

**理由**：
- Markov 等价类的存在意味着多个图都可能解释数据
- 算法假设（如 Causal Sufficiency）可能被违反
- 隐藏变量、测量误差、样本偏差都会影响结果

### 陷阱 2：忽视假设的脆弱性

❌ **错误**：假设数据满足 Causal Sufficiency（没有隐变量）

✓ **正确**：使用允许隐变量的方法（FCI），并进行敏感性分析

**现实**：
- 几乎总是存在未观测的混杂因子
- 使用 FCI 处理不可观测的混杂

### 陷阱 3：混淆相关与因果

❌ **错误**：强相关的变量会被识别为有因果关系

✓ **正确**：理解算法的工作原理，识别相关性何时指向因果

**背景**：
- PC 和 FCI 算法通过条件独立（失去相关性）来删除边
- 强相关不等于因果，但某些模式可以指导因果推论

### 陷阱 4：样本量不足

❌ **错误**：在小样本上应用因果发现，期望得到可靠结果

✓ **正确**：了解样本需求，进行 bootstrap 等稳定性检验

**经验法则**：
- 约束法：$n > p^2$（$p$ 是变量数）
- 评分法：$n > p^3$ 或更多

### 陷阱 5：评分函数的任意选择

❌ **错误**：尝试多个评分函数（BIC、MDL 等），选择"最好"的结果

✓ **正确**：预先指定评分函数，或进行稳定性分析

**风险**：p-hacking，根据数据选择评分函数以得到想要的结构
