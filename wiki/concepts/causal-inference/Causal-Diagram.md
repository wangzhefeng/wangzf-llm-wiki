# Causal Diagram（因果图）

## 定义

因果图（Causal Diagram），也称有向无环图（DAG，Directed Acyclic Graph），是由 Judea Pearl 提出的图形化表示因果关系的方法。在图中，节点代表变量，有向边代表因果关系方向。因果图通过可视化形式显式表达变量间的因果假设，是进行因果推断时澄清假设的强大工具。

## 核心要素

### 节点（Nodes）
- 代表研究中的每个变量（处理变量、结果变量、混杂因子、工具变量等）

### 有向边（Directed Edges）
- **箭头方向表示因果方向**
  - $A \rightarrow B$：A 有因果作用于 B
  - 反向箭头：$B \leftarrow A$（等价表示）

### 无环约束
- **无环性（Acyclicity）**：不存在闭环，避免逻辑矛盾
- **有向无环图保证了因果关系的可识别性**

## Pearl 的三层因果推理

### 1. 关联（Association）
观测数据中的统计相关性：$P(Y|X)$

### 2. 干预（Intervention）
通过设定变量的值进行假想干预：$P(Y | \text{do}(X=x))$

**Do 算子**：区别于观察，表示因果干预
- $P(Y | \text{do}(X=x)) \neq P(Y | X=x)$（除非满足特定条件）

### 3. 反事实（Counterfactual）
给定当前观察，假想另一个世界中的结果：$Y_x(u)$

## 识别准则（Identification Criteria）

### 后门准则（Back-door Criterion）
用于识别通过"后门路径"的混杂偏倚

**条件**：若变量集合 $Z$ 满足以下两点，则可通过控制 $Z$ 识别因果效应
1. $Z$ 阻断所有从 $X$ 到 $Y$ 的包含指向 $X$ 箭头的路径（后门路径）
2. $Z$ 中没有节点是 $X$ 的后代

**应用**：确定需要在回归中控制哪些变量

### 前门准则（Front-door Criterion）
用于不存在后门准则成立时的情况

**条件**：若中介变量 $M$ 和参数满足特定条件，即使存在不可观测的混杂因子，也能识别因果效应

## 常见图形模式

### 混杂（Confounding）
```
    Z
   / \
  v   v
  X   Y
```
$Z$ 同时影响 $X$ 和 $Y$，不控制 $Z$ 会产生混杂偏倚

### 中介（Mediation）
```
  X → M → Y
```
$M$ 是 $X$ 到 $Y$ 的中介变量，可分解为直接和间接效应

### 碰撞（Collider）
```
  X   Y
   \ /
    v
    Z
```
$Z$ 是 $X$ 和 $Y$ 的共同结果，**控制 $Z$ 反而会产生偏倚**

### 工具变量（Instrumental Variable）
```
  Z → X → Y
```
$Z$ 不直接影响 $Y$，只通过 $X$ 影响，可作为工具变量

## 优势与局限

### 优势
- **澄清假设**：显式表达所有因果假设，避免隐含假定
- **直观可视**：相比数学表达，更容易沟通与验证
- **方向指引**：指导应该控制哪些变量、使用哪种识别策略
- **跨学科应用**：社会科学、医学、经济学广泛应用

### 局限
- **需要先验知识**：图的正确性依赖于对问题的深刻理解
- **不能从数据中唯一确定**：同一数据可能对应多个不同的图
- **假定不可验证**：因果方向通常无法从数据直接检验
- **复杂系统中易变复杂**：变量众多时图会变得难以管理

## 与 Rubin Causal Model 的关系

| 维度 | Causal Diagram（Pearl） | Rubin Causal Model |
|---|---|---|
| 框架 | 图形 + do 算子 | 潜在结果 |
| 焦点 | 识别（identification） | 估计（estimation） |
| 优势 | 澄清假设、直观 | 精确估计、灵活 |
| 结合 | DoWhy 框架统一两者 | 识别 + 估计 |

## 应用实例

### A/B 测试
```
处理分配 → 处理 → 结果
                ↖
             用户特征
```
随机化使得用户特征 ⊥ 处理，后门路径被阻断

### 观察性研究
```
         混杂因子 Z
        /        \
       v          v
    处理 X      结果 Y
```
需要控制 Z 以识别 $X \rightarrow Y$ 的因果效应

## 常见错误

❌ **错误 1**：认为相关性方向可以从数据中看出
✓ **正确**：相关性是对称的，因果方向必须来自领域知识

❌ **错误 2**：盲目控制所有可能的混杂因子
✓ **正确**：根据因果图，只控制需要控制的变量（避免碰撞偏倚）

❌ **错误 3**：认为因果图可以从数据中唯一确定
✓ **正确**：多个不同的图可能产生相同的条件独立关系
