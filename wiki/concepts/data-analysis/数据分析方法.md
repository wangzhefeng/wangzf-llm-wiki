# 数据分析方法

数据分析方法是围绕业务问题定义、数据采集、指标构建、统计检验、解释与回流的完整闭环。

## 关键步骤

1. 明确问题与假设
2. 设计数据采集与埋点
3. 做描述性统计与异常检查
4. 做检验、相关或因果分析
5. 输出结论并回流到知识库
