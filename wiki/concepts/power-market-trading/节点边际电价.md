# 节点边际电价

> 在考虑传输网络约束的条件下，特定节点新增单位负荷所需的系统边际成本，是集中式电力现货市场最成熟的空间差异化定价机制。

## 概述

节点边际电价（Locational Marginal Price, LMP）是集中式电力市场出清的核心价格信号。与统一出清价格不同，LMP 为电网每个节点分别定价，反映了「在该位置多消耗 1 MWh 电能」对系统总成本的实际影响——包括发电成本、传输损耗与阻塞代价。

LMP 被认为是电力市场中考虑安全约束最全面、价格信号最真实的定价机制，已在美国（PJM、MISO、CAISO）、澳大利亚（NEM）等成熟市场广泛应用，中国的集中式现货市场设计也采用了类似框架。

## 价格分解

LMP 通常分解为三个部分：

```
LMP_i = λ_energy + λ_loss_i + λ_congestion_i
```

| 分量 | 含义 | 特征 |
|---|---|---|
| **能量分量**（λ_energy） | 系统边际发电成本（所有节点相同） | 反映最后一台调度机组的边际成本 |
| **损耗分量**（λ_loss_i） | 该节点供电的边际传输损耗成本 | 随节点位置、潮流方向变化 |
| **阻塞分量**（λ_congestion_i） | 传输阻塞导致的附加成本 | 阻塞时同一约束两侧价格出现「价差跳变」|

## 网损因子与惩罚因子

**网损因子（Loss Factor, LF_i）**

定义：节点 i 的边际传输损耗率，即在节点 i 增加 1 MW 发电所引起的系统总损耗变化量：

```
LF_i = ∂P_loss / ∂P_gen_i
```

**网损惩罚因子（Penalty Factor, PF_i）**

对节点 i 的电价进行损耗修正：

```
PF_i = 1 / (1 - LF_i)
```

- PF > 1：该节点位于传输损耗较高区域（通常为负荷中心），实际支付价格高于系统边际价格
- PF < 1：该节点位于电源侧或损耗较低区域，实际支付价格低于系统边际价格

## 阻塞剩余的形成与分配

当传输线路达到容量上限（阻塞），阻塞两侧节点产生价差。这一价差形成「阻塞剩余（Congestion Surplus）」，通常分配给输电网所有者或用于降低用户电费，其计算为：

```
阻塞剩余 = Σ (LMP_注入节点 × 注入功率) - Σ (LMP_抽出节点 × 抽出功率)
```

阻塞剩余是评估是否需要新建输电线路的经济信号——持续高额阻塞剩余意味着当前传输容量不足。

## 价格信号的经济含义

1. **时间价值**：同一节点不同时段价格差异反映供需松紧（高峰/低谷价差）
2. **空间价值**：同一时段不同节点价格差异反映传输阻塞（阻塞前后价差）
3. **短期信号**：引导负荷在低价时段/节点集中，在高价时段/节点削减
4. **长期信号**：持续价差揭示输电投资和电源布局的经济方向

## 局限性

- 价格数据复杂，用户理解门槛高
- 极端情况下节点价格可为负值（弃风/弃光时）或触及涨跌幅上限
- 短期实时价格波动剧烈，对无套保合约的市场主体造成极大风险（需通过 [[差价合约]] 对冲）
