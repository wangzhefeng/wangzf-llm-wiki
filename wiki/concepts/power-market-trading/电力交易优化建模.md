# 电力交易优化建模

> 将电力市场交易从“规则理解”推进到“可求解问题”的桥接方法页。核心任务是把价格机制、资源约束、不确定性与执行反馈统一到一个滚动优化闭环中。

## 概述

电力交易优化建模不是单独的一种算法，而是一类问题组织方式。它把市场规则、物理约束和业务目标转写成可预测、可优化、可执行、可结算的模型系统。

在 `power-market-trading` 主题中，这一页承担桥接作用：

- 向上连接 [[电力现货市场]]、[[电力中长期交易]]、[[节点边际电价]]、[[电力交易结算]] 等机制页
- 向下连接 [[风光储测算]]、新能源出力模拟、储能调度和工程实现
- 向外连接 [[算电协同]]、虚拟电厂、时序预测与运筹优化算法体系

## 统一问题框架

电力交易优化建模通常可以压缩为一个统一闭环：

```
预测 -> 场景生成 -> 优化决策 -> 实时执行 -> 结算反馈 -> 模型修正
```

这条链路对应了交易系统的六个关键环节：

1. **预测层**
   - 负荷预测
   - 风电/光伏出力预测
   - 日前/实时价格预测
2. **场景层**
   - 将天气、负荷、价格不确定性展开为场景或区间
3. **决策层**
   - 形成报价、分时计划、储能充放电与购售电组合
4. **执行层**
   - 在实时阶段根据实际出力和负荷偏差滚动修正
5. **结算层**
   - 将物理偏差映射为收入、成本和惩罚
6. **反馈层**
   - 用实际执行和结算结果修正模型参数与策略规则

## 建模对象

### 1. 市场对象

- 中长期合约量与价格
- 日前市场申报曲线
- 实时偏差暴露
- 辅助服务中标容量与调用量

### 2. 资源对象

- 常规机组出力
- 风电、光伏等不确定性资源
- 储能荷电状态、充放电功率与循环约束
- 柔性负荷、数据中心、可中断负荷等可调资源

### 3. 网络与位置对象

- 节点价格
- 线路拥塞
- 损耗
- 接网位置对收益与风险的影响

## 常见目标函数

不同业务场景下，目标函数通常是以下几类的组合：

- **收益最大化**：市场收入 - 购电成本 - 偏差成本 - 运维成本
- **总成本最小化**：建设成本 + 能源采购成本 + 惩罚成本
- **风险调整收益最大化**：收益与 CVaR、波动率、极端损失联合优化
- **多目标优化**：同时考虑经济性、绿电比例、自发自用率、碳排和系统安全

## 关键约束

### 市场约束

- 中长期合约履约约束
- 日前与实时申报边界
- 辅助服务可用容量约束
- 偏差考核与结算规则

### 物理约束

- 功率平衡约束
- 机组出力上下限与爬坡约束
- 储能 SOC 递推约束
- 风光出力和可用资源上限

### 工程约束

- 数据时效性
- 调度刷新频率
- 求解时限
- 模型规模与可解释性

## 方法分层

### 规则层

对应市场设计本身，回答“按什么规则结算、什么资源可以参与、什么信号决定价格”。

相关页面：
- [[电力现货市场]]
- [[电力中长期交易]]
- [[电力交易结算]]
- [[节点边际电价]]

### 资源层

对应资源能力刻画，回答“到底能发多少、能调多少、能存多少”。

相关页面：
- [[风光储测算]]
- [[算电协同]]

### 决策层

对应优化模型本身，回答“面对这些价格与约束，最优行动是什么”。

常用方法包括：

- 线性规划 / 混合整数规划
- 两阶段随机优化
- 鲁棒优化
- CVaR 风险约束优化
- 滚动优化 / MPC

## 为什么它是桥接层

如果只看市场规则，会知道价格怎么形成，但不知道策略如何落地。  
如果只看风光储测算，会知道资源能力如何估算，但不知道这些资源怎样进入交易收益模型。

电力交易优化建模的作用，就是把这两件事接起来：

- 用 [[节点边际电价]] 和 [[电力交易结算]] 把价格与偏差成本引入模型
- 用 [[风光储测算]] 把新能源出力和储能能力引入模型
- 用滚动优化把日前决策和实时执行连接起来
- 用工程实现把模型转成可持续运行的系统

## 典型应用场景

### 新能源参与电力市场

- 预测风光出力
- 设计申报策略
- 控制偏差风险
- 优化储能协同收益

### 园区 / 数据中心绿电协同

- 评估本地风光储容量配置
- 在电价和绿电比例约束下做购电决策
- 将柔性负荷参与需求响应或现货市场

### 虚拟电厂聚合交易

- 聚合分布式资源
- 优化日前承诺与实时响应
- 平衡市场收益和履约风险
