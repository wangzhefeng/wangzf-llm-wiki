# 电力交易结算

> 电力市场中将物理交割转换为资金流的制度安排，通过三层结算机制（合约层→日前偏差层→实时偏差层）平衡价格稳定性与市场效率的需求。

## 概述

电力市场的结算机制设计需要在两个目标之间平衡：
1. **价格稳定性**：避免实时价格波动对用户账单造成剧烈冲击
2. **市场效率**：通过真实价格信号引导发用电行为，激励优化

中国集中式电力市场采用「三层结算」架构，不同层次的电量按各自对应的市场价格结算，使不确定性高的部分（实时偏差）在市场中定价，同时通过合约层为大部分电量提供价格保护。

## 三层结算机制

### 第一层：合约电量结算

- **结算价格**：中长期合约约定价格（固定价格）
- **结算电量**：合约量（经合约分解后的小时曲线）
- **特点**：价格最稳定，不受现货波动影响；偏差量（实际与合约的差）转入下一层

### 第二层：日前偏差结算

- **结算价格**：日前市场出清节点价格（LMP_DA）
- **结算电量**：日前调度计划量 - 合约分解量（日前偏差）
- **特点**：日前价格相对稳定（基于次日供需预测形成），中等不确定性

### 第三层：实时偏差结算

- **结算价格**：实时市场 5 分钟出清节点价格（LMP_RT）
- **结算电量**：实际计量电量 - 日前调度计划量（实时偏差）
- **特点**：价格最不稳定，受突发事件（机组跳闸、天气变化等）影响大

**综合账单：**
```
总电费 = 合约价格 × 合约电量
       + 日前节点价格 × 日前偏差电量
       + 实时节点价格 × 实时偏差电量
```

## 精准计划的激励作用

三层结算机制天然激励市场主体提高计划精度：
- 计划越准确（实际接近合约量），暴露在高波动实时价格下的电量越少
- 实时价格高峰时段超用电量将面临高额实时价格结算
- 发电企业偏低申报实际发电量会在实时市场形成偏差，承担相应价格风险

## 拥塞剩余处理

当传输阻塞导致不同节点出现价差，系统中产生「拥塞剩余」：

```
拥塞剩余 = 输电阻塞产生的价差收益
```

拥塞剩余的分配方式（各地有所不同）：
- 返还给输电网使用者，降低输电费
- 分配给持有输电权（FTR/CRR）的市场主体
- 统一进入系统运营费用池

## 不平衡费用分摊

系统级别的总供需不平衡产生的「不平衡费用」，通常按以下规则分摊：
- 造成正偏差（超发/欠用）的主体：获得补偿或承担惩罚
- 造成负偏差（欠发/超用）的主体：支付补偿或获得奖励
- 具体规则与各省市场设计相关

## 辅助服务结算（独立核算）

辅助服务费用独立于能量市场结算：
- 容量费：按申报中标的备用能力（MW）收取，不论是否实际被调用
- 调用费：实际调用时按调节电量（MWh）结算
- 费用来源：通常在所有市场主体间按用电量比例分摊
