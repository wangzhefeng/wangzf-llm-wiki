# 控制系统基础

一句话定义：控制系统基础是理解"如何让系统输出按照期望变化"的知识体系，包括开环/闭环、控制框图、设计指标等基础概念。

## 核心要点

### 控制系统的本质

控制算法的目标是让系统输出 `$y$` 按照期望值 `$r$` 变化，并在扰动、噪声和模型不确定性存在时保持稳定、快速、准确。

从工程角度看，控制算法主要解决四个问题：
1. 系统是否**稳定**
2. 响应是否**足够快**
3. 超调和振荡是否**可接受**
4. 稳态误差是否**足够小**

### 控制系统的基本组成

控制系统由以下部分组成：
1. **参考输入**（目标值）
2. **控制器**（根据误差计算控制量）
3. **执行机构**（将控制量转为实际动作）
4. **被控对象**（需要被调节的系统）
5. **传感器与反馈通道**（测量输出并回传）

信号流：控制器 → 执行器 → 被控对象 → 传感器 → 比较器（计算误差）→ 控制器（闭环）

### 开环 vs 闭环

| 维度 | 开环 | 闭环 |
|------|------|------|
| 反馈 | 无 | 有 |
| 结构 | 简单 | 复杂 |
| 成本 | 低 | 高 |
| 抗扰动 | 差 | 强 |
| 精度 | 低 | 高 |

**开环控制**不使用反馈，结构简单、成本低，但难以抵抗扰动。
**闭环控制**利用输出反馈来修正误差，精度更高、鲁棒性更好，是现代控制系统更常见的形式。

闭环控制的一般过程：
1. 采集系统输出
2. 与目标值比较得到误差
3. 控制器根据误差生成控制信号
4. 被控对象响应后再次反馈

### 控制算法分类

常见控制算法大致可分为：
- **经典控制**：P、PI、PD、PID
- **现代控制**：状态反馈、最优控制、LQR、MPC
- **智能控制**：模糊控制、神经网络控制、专家控制
- **特殊结构控制**：前馈控制、自适应控制、鲁棒控制

### 设计控制器时的关注指标

- **稳定性**：系统不能发散
- **上升时间**：达到目标附近的速度
- **超调量**：是否冲过目标过多
- **调节时间**：多久能稳定下来
- **稳态误差**：最终是否仍有偏差
- **鲁棒性**：参数变化和外部扰动下是否仍可靠

## 如何选择控制算法

工程中没有"最好的控制算法"，只有"更适合当前对象的控制算法"。选择思路：

| 对象特征 | 优先选择 |
|----------|----------|
| 对象简单、模型稳定 | PID |
| 需要快速落地、实现成本低 | PID 或 PI |
| 非线性较强、模型难建 | 模糊控制或模糊 PID |
| 工况变化大但仍希望保留 PID 结构 | 模糊 PID |
| 多变量、强约束、高性能 | 现代控制方法（LQR、MPC） |

常见路线不是"二选一"，而是：
1. 先用 PID 建立可工作的基线系统
2. 再通过模糊规则、自适应策略或前馈补偿提升性能

## 典型应用场景

- 电机转速控制
- 无人机姿态控制
- 机器人关节位置控制
- 温度、压力、流量过程控制
- 汽车巡航、怠速与转向系统
