# Few-shot Learning

Few-shot Learning 指通过在上下文中提供少量示例，让模型在不额外训练的情况下学会目标任务格式和行为约束。

## 核心要点

- 更适合格式受约束、标签空间有限的任务。
- 示例质量通常比示例数量更重要，差示例会直接污染输出模式。
- 当示例过多导致上下文拥挤时，应转向 [[上下文工程]] 或 [[模型微调]]。
