# LLM 对齐

LLM 对齐是把模型输出拉向“有用、诚实、无害”的系统方法集合，通常通过指令微调、偏好优化和安全策略共同实现。

## 核心要点

- 对齐不是单一步骤，而是贯穿数据构造、训练目标、评估与部署策略的系统工程。
- 典型训练链路是 [[后训练]] 中的 SFT、RLHF、DPO 等方法。
- 安全拒答、系统提示和红队测试属于对齐在部署侧的延伸实现。
