# NLP任务

NLP 任务是 LLM 应用的直接落地层，常见包括文本分类、序列标注、问答、关键词抽取、语义匹配与生成任务。

## 核心要点

- 不同任务对数据标注、评估指标和推理链路要求不同。
- 传统 NLP 任务可以作为 LLM 能力边界与微调收益的基准。
- 任务抽象应与业务流程绑定，避免只追求模型分数而忽略可用性。
