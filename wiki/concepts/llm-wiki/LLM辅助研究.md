# LLM 辅助研究

## 定义

使用大语言模型（LLM）辅助个人知识管理、研究和内容创作的方法论。

## 核心方法

### Karpathy LLM Wiki

Andrej Karpathy 提出的方法：
- 使用 LLM 作为研究助手
- 结合 Obsidian 等本地知识管理工具
- 构建可查询的个人知识库
- 通过提示词工程提高输出质量

### 工作流程

1. **摄取 (Ingest)**: 收集原始资料到 `raw/` 目录
2. **摘要 (Summarize)**: 生成来源卡到 `wiki/sources/`
3. **索引 (Index)**: 更新索引到 `wiki/indexes/`
4. **概念化 (Concept)**: 沉淀概念页到 `wiki/concepts/`

## 关键工具

- **Obsidian**: 本地 Markdown 知识库管理工具
- **LLM API**: OpenAI、Claude、本地模型等
- **提示词模板**: 标准化的处理流程
