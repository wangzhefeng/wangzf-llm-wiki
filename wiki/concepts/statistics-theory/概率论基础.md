# 概率论基础

## 定义与地位

**概率论**是研究随机现象规律的数学分支，为所有统计推断、机器学习、决策理论提供理论基础。

在知识体系中的位置：
- **数学基础**：集合论、测度论
- **核心层**：随机事件、概率定义、概率运算
- **应用层**：大数定律、中心极限定理、分布理论
- **扩展**：随机过程、参数估计、假设检验

---

## 核心概念与定义

### 1. 随机事件与样本空间

**样本空间（Ω）**：随机实验所有可能结果的集合。
- 例：抛硬币 Ω = {正面, 反面}
- 例：测温度 Ω = ℝ（实数集）

**随机事件**：样本空间的子集，称为一个事件。
- **必然事件**：Ω，一定会发生
- **不可能事件**：∅，不会发生
- **基本事件**：单个样本点

**事件关系与运算**：
- **包含**：A ⊆ B，A 发生则 B 必发生
- **并（和）**：A ∪ B，A 或 B 至少一个发生
- **交（积）**：A ∩ B，A 和 B 同时发生
- **对立**：A^c，A 不发生
- **德摩根律**：(A ∪ B)^c = A^c ∩ B^c

### 2. 概率的定义与性质

**概率的三种定义**：

**古典概率**（适用于有限等可能）：
$$P(A) = \frac{|A|}{|\Omega|}$$
例：抛公平骰子出现 6 的概率 = 1/6

**频率概率**（基于大量重复）：
$$P(A) = \lim_{n \to \infty} \frac{n_A}{n}$$
其中 n_A 是 n 次试验中 A 发生的次数

**几何概率**（区间/区域上均匀）：
$$P(A) = \frac{|A|\text{的几何度量}}{|\Omega|\text{的几何度量}}$$
例：向正方形内随机投点，落入内接圆的概率

**公理化定义**（科尔莫哥洛夫）：
给定样本空间 Ω，事件域 F，概率 P 满足：
1. P(Ω) = 1（必然事件概率为 1）
2. 0 ≤ P(A) ≤ 1（概率在 0 到 1 之间）
3. P(A₁ ∪ A₂ ∪ ...) = ∑ P(Aᵢ)（可加性）

**概率的基本性质**：
- P(A^c) = 1 - P(A)
- P(∅) = 0
- P(A ∪ B) = P(A) + P(B) - P(A ∩ B)
- 若 A ⊆ B，则 P(A) ≤ P(B)

### 3. 条件概率与独立性

**条件概率**：在 B 已发生的条件下，A 发生的概率
$$P(A|B) = \frac{P(A \cap B)}{P(B)}, \quad P(B) > 0$$

**乘法规则**：
$$P(A \cap B) = P(A|B) \cdot P(B) = P(B|A) \cdot P(A)$$

**全概率公式**：若 B₁, B₂, ..., Bₙ 构成 Ω 的分割，则
$$P(A) = \sum_{i=1}^{n} P(A|B_i) P(B_i)$$

**贝叶斯公式**：
$$P(B_i|A) = \frac{P(A|B_i) P(B_i)}{\sum_{j=1}^{n} P(A|B_j) P(B_j)}$$

**独立事件**：两个事件 A 和 B 独立，当且仅当
$$P(A \cap B) = P(A) \cdot P(B)$$
或等价地 P(A|B) = P(A)

### 4. 随机变量与分布

**随机变量**：从样本空间到实数集的函数 X: Ω → ℝ

**离散型随机变量**（概率分布列）：
- 可能取值有限或可数
- 概率分布：P(X = xᵢ) = pᵢ
- 分布函数：F(x) = P(X ≤ x) = ∑ pᵢ（xᵢ ≤ x）

**连续型随机变量**（概率密度）：
- 由概率密度函数 f(x) 描述
- P(a < X ≤ b) = ∫ₐᵇ f(x)dx
- 分布函数：F(x) = P(X ≤ x) = ∫₋∞ˣ f(t)dt

**常见分布**：
- **离散**：二项分布 B(n,p)、泊松分布 Poisson(λ)、超几何分布
- **连续**：正态分布 N(μ,σ²)、均匀分布、指数分布、卡方分布 χ²(k)

## 核心原理与定理

### 大数定律

**弱大数定律（切比雪夫）**：
设 X₁, X₂, ..., Xₙ 是独立同分布的随机变量，期望为 μ，方差为 σ²，则对任意 ε > 0：
$$P\left(\left|\frac{1}{n}\sum_{i=1}^n X_i - \mu\right| > \varepsilon\right) \to 0, \quad n \to \infty$$

**含义**：样本均值收敛到总体期望，是统计推断的理论基础。

### 中心极限定理

**李雅普诺夫中心极限定理**：
设 X₁, X₂, ..., Xₙ 是独立同分布的随机变量，期望为 μ，方差为 σ²，则
$$\frac{\sum_{i=1}^n X_i - n\mu}{\sqrt{n}\sigma} \xrightarrow{d} N(0,1)$$

**含义**：
- 无论 Xᵢ 服从什么分布，其和渐近正态分布
- 是参数估计与假设检验的理论基础
- 解释为什么许多自然现象近似正态分布

## 实战应用

### 应用 1：风险评估（保险精算）

问题：已知某事故发生概率 p = 0.02，年内 1000 人中预期有多少人出险？

**解法**：
- X ~ B(1000, 0.02)，期望 E(X) = np = 1000 × 0.02 = 20
- 方差 Var(X) = np(1-p) = 20 × 0.98 ≈ 19.6
- 标准差 σ ≈ 4.43
- 保险公司需为 20 ± 2×4.43 = [11.14, 28.86] 做准备（95% 置信）

### 应用 2：医学检验（贝叶斯诊断）

问题：某病的患病率 0.1%，检验灵敏度 95%，特异度 98%。若检验阳性，患者真正患病的概率？

**解法**：
- 设 D = 患病，+ = 检验阳性
- P(D) = 0.001，P(+|D) = 0.95，P(+|D^c) = 1 - 0.98 = 0.02
- P(+) = P(+|D)P(D) + P(+|D^c)P(D^c) = 0.95×0.001 + 0.02×0.999 = 0.02095
- **P(D|+) = P(+|D)P(D) / P(+) = 0.95×0.001 / 0.02095 ≈ 4.5%**

结论：虽然灵敏度和特异度都很高，但由于患病率低，阳性患者患病概率仅 4.5%。

### 应用 3：抽样调查（中心极限定理）

问题：某城市 10 万人，欲估计月平均收入。随机抽 400 人，样本均值 5000 元，样本方差 400 万。95% 置信区间？

**解法**：
- 由中心极限定理，样本均值 X̄ 近似正态分布
- 标准误 SE = σ/√n = √(400万)/√400 = 2000/20 = 100
- 95% 置信区间 = 5000 ± 1.96×100 = [4804, 5196]

## 常见问题

**Q1：概率 0.5 和频率 0.5 有什么区别？**

A：
- **概率**是理论值，反映事件发生的本质可能性
- **频率**是实验值，是多次实验中事件的发生比例
- 大数定律保证：重复次数足够多时，频率趋向于概率

**Q2：条件概率 P(A|B) 和联合概率 P(A∩B) 的区别？**

A：
- P(A∩B)：A 和 B 都发生的概率
- P(A|B)：在 B 已发生的条件下 A 发生的概率
- 关系：P(A|B) = P(A∩B) / P(B)
- 直观：条件概率"缩小"了样本空间

**Q3：为什么数据分析中经常假设数据近似正态分布？**

A：
- 中心极限定理保证：独立同分布的随机变量和近似正态
- 许多自然现象可看作多个因素的综合，故近似正态
- 不过要验证正态性假设，使用正态性检验

**Q4：独立和互不相容有什么区别？**

A：
- **互不相容（互斥）**：A ∩ B = ∅，不能同时发生，P(A∩B) = 0
- **独立**：P(A∩B) = P(A)P(B)，一个发生不影响另一个概率
- 注意：互不相容（P(A∩B)=0）通常不独立；独立也不互不相容

**Q5：样本量与精度的关系？**

A：
- 标准误 SE = σ/√n，精度与 √n 成正比
- 要使精度提高 2 倍，样本量需增加 4 倍
- 样本量确定需考虑：期望精度、总体方差、置信水平
