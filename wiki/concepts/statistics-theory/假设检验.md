# 假设检验

## 定义与地位

**假设检验**是利用样本数据对关于总体的某个假设进行统计判断的方法，判断样本与假设的不一致是由随机波动还是本质差别造成的。

在知识体系中的位置：
- **前置**：[[概率论基础]]、[[参数估计]]、抽样分布
- **核心**：零假设、备择假设、显著性、p 值
- **类型**：参数检验、非参数检验、多重比较
- **应用**：A/B 检验、质量控制、医学实验

---

## 核心概念

### 1. 假设的建立

**零假设（H₀）**：待检验的假设，通常代表"无效应"或"无差异"的状态
- H₀: μ = 100（均值等于 100）
- H₀: μ₁ = μ₂（两组均值相等）
- H₀: p = 0.5（概率为 0.5）
- H₀: 因子 A 无主效应

**备择假设（H₁）**：零假设不成立时的假设，代表"有效应"或"有差异"
- **双侧检验**：H₁: μ ≠ 100（不等于）
- **单侧检验**：H₁: μ > 100（大于）或 μ < 100（小于）

**选择原则**：
- 问题中的"是否相等"→ 双侧检验
- 问题中有方向性（高于、低于）→ 单侧检验
- 生产：H₀ 产品合格，H₁ 产品不合格（保护消费者）

### 2. 检验统计量与拒绝域

**检验统计量**：用于判断 H₀ 是否成立的统计量
- 均值检验：t = (X̄ - μ₀) / (S/√n) ~ t(n-1)
- 方差检验：χ² = (n-1)S²/σ₀² ~ χ²(n-1)
- 两个均值比较：t = (X̄₁ - X̄₂) / SE ~ t(n₁+n₂-2)

**拒绝域（临界区）**：检验统计量的取值范围，在此范围内拒绝 H₀
- **双侧**：|t| > t_{α/2} 或 p < α/2
- **单侧（右侧）**：t > t_α 或 p < α
- **单侧（左侧）**：t < -t_α 或 p < α

**接受域**：不在拒绝域内的部分，接受 H₀

### 3. 显著性水平与 p 值

**显著性水平 α**：犯第一类错误（弃真）的容许概率
- α = 0.05（5%），常用标准
- α = 0.01（1%），更严格
- α = 0.10（10%），较宽松

**p 值**：在 H₀ 为真的条件下，观察到当前样本或更极端结果的概率
- p < 0.05：显著，拒绝 H₀
- p < 0.01：非常显著，强烈拒绝 H₀
- p ≥ 0.05：不显著，接受 H₀

**关键区别**：
- α：事先设定，控制错误风险的阈值
- p：根据数据计算，样本证据的强度

### 4. 两类错误与功效

**第 I 型错误（假阳性）**：H₀ 为真时拒绝 H₀
- 概率 = α（显著性水平）
- 例：产品实际合格，但检验判断为不合格

**第 II 型错误（假阴性）**：H₀ 为假时接受 H₀
- 概率 = β
- 例：产品实际不合格，但检验判断为合格

**统计功效（检验功效）**：1 - β，正确拒绝假假设的概率
- 功效 = P(拒绝 H₀ | H₀ 为假)
- 通常要求功效 ≥ 0.80

**平衡**：
- 减小 α 则 β 增大（互相制约）
- 增加样本量同时减小 α 和 β
- 实务中常固定 α = 0.05，通过样本量控制 β

## 常见检验方法

### 参数检验

**单样本 t 检验**：检验一个样本的均值是否等于已知值
$$t = \frac{\bar{X} - \mu_0}{S/\sqrt{n}} \sim t(n-1)$$

**独立样本 t 检验**：检验两个独立样本的均值是否相等
$$t = \frac{\bar{X}_1 - \bar{X}_2}{\sqrt{S_p^2(1/n_1 + 1/n_2)}} \sim t(n_1+n_2-2)$$

**配对样本 t 检验**：检验配对数据的差值均值是否为 0
$$t = \frac{\bar{D}}{S_D/\sqrt{n}} \sim t(n-1)$$

**方差检验（F 检验）**：检验多个样本的方差是否相等（ANOVA）
$$F = \frac{\text{组间方差}}{\text{组内方差}} \sim F(k-1, n-k)$$

### 非参数检验

**秩和检验（Mann-Whitney U 检验）**：两样本比较，不假设正态性
- 用于分布形状未知的数据
- 检验"位置"是否相同，而非均值

**Wilcoxon 配对秩和检验**：配对数据比较，不假设正态性
- 用于非正态或有离群值的配对数据

**卡方检验（χ²）**：离散数据的检验
- 拟合优度检验：观察频率 vs. 理论频率
- 独立性检验：两个分类变量是否独立

## 实战应用

### 应用 1：新药疗效评估

**问题**：新降压药临床试验，60 个高血压患者用药 8 周后，收缩压平均下降 15 mmHg（标准差 20）。该药是否有显著效果？（α = 0.05）

**步骤**：
1. 建立假设：H₀: μ = 0（无效果），H₁: μ ≠ 0（有效果）
2. 计算检验统计量：t = 15 / (20/√60) = 15 / 2.58 ≈ 5.81
3. 查表：t(59, 0.025) ≈ 2.00，|5.81| > 2.00，落入拒绝域
4. 计算 p 值：p < 0.001（非常显著）
5. **结论**：拒绝 H₀，该药有显著的降压效果

### 应用 2：产品质量控制

**问题**：某零件标准直径 10 mm。抽检 25 个零件，平均 10.1 mm，标准差 0.15 mm。生产是否偏离标准？（α = 0.05）

**步骤**：
1. H₀: μ = 10，H₁: μ ≠ 10
2. t = (10.1 - 10) / (0.15/√25) = 0.1 / 0.03 ≈ 3.33
3. t(24, 0.025) ≈ 2.06，|3.33| > 2.06
4. **结论**：拒绝 H₀，生产过程有显著偏离

### 应用 3：A/B 测试

**问题**：网站改版 A/B 测试，版本 A（旧）点击率 3.2%（500 次，16 次点击），版本 B（新）点击率 3.8%（520 次，20 次点击）。版本 B 是否显著更好？（α = 0.05）

**步骤**：
1. H₀: p_A = p_B，H₁: p_A ≠ p_B
2. 计算合并比例：p̂ = (16+20)/(500+520) = 36/1020 ≈ 0.0353
3. SE = √[0.0353×(1-0.0353)×(1/500 + 1/520)] ≈ 0.0127
4. z = (0.038 - 0.032) / 0.0127 ≈ 0.47
5. p 值 ≈ 0.64（>0.05），不显著
6. **结论**：不能拒绝 H₀，版本 B 的改进不具统计显著性

## 常见问题

**Q1：p 值 = 0.05 时应该拒绝还是接受 H₀？**

A：
- 按惯例，p < 0.05 拒绝，p ≥ 0.05 接受
- p = 0.05 是边界，实务中通常接受 H₀（保守）
- 最好报告精确 p 值而非仅说"显著"或"不显著"

**Q2：p 值 < 0.001 是否意味着效应很大？**

A：
- **否**，p 值只反映统计显著性，不反映效应大小
- 大样本时，即使微小的差异也可能显著（p < 0.001）
- 需要同时报告**效应量**（如平均差、相关系数）

例：新药降压 0.1 mmHg，但样本量 10000 人，可能 p < 0.001，但临床无意义

**Q3：不显著（p > 0.05）是否意味着 H₀ 为真？**

A：
- **否**，不显著只表示"证据不足以拒绝 H₀"
- 可能是真的无效应，也可能是样本量不足（低功效）
- 应该说"未发现显著证据"而非"证明无效应"

**Q4：如何在α和β之间平衡？**

A：
1. **增加样本量**：最有效的方法，同时减小 α 和 β
2. **调整 α**：严格把控（如 α = 0.01）降低假阳性，但增加假阴性
3. **设计改进**：减少噪声、增加精度
4. **实务建议**：
   - 医学：α = 0.05，β = 0.20（功效 80%）
   - 制造：α = 0.05，β = 0.10（功效 90%）

**Q5：为什么要做单侧检验而不是双侧？**

A：
- **双侧**：发现任何方向的差异，更保守，推荐
- **单侧**：有理由预期特定方向效应时，更强大（更易显著）
- **风险**：如果方向预测错误，可能漏掉反方向的显著差异
