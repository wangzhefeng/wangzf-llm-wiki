# Vibe Coding

> 一种强调与 AI Agent 自然协作的编程风格与方法论。

## 定义

Vibe Coding 是一种编程风格，强调开发者与 AI Agent 之间的自然协作，通过工具调用、RAG 和技能化工作流来提升开发效率。

## 核心原则

1. **协作优先** - AI Agent 作为协作者而非工具
2. **工具链集成** - 无缝集成 MCP、Claude Code、Codex 等工具
3. **迭代式开发** - 快速原型与持续反馈
4. **知识沉淀** - 将成功的工作流转化为可复用的技能

## Harness 工程层（2026-04 新增）

Vibe Coding 的生产化阶段依赖 Harness 工程体系：

- [[Harness工程]]：核心工程学科，Agent = Model + Harness
- [[Claude-Managed-Agents]]：Anthropic 官方托管 Harness，消除基础设施搭建负担
- [[浏览器自动化工具]]：Web 交互接口，Accessibility Tree 方案
