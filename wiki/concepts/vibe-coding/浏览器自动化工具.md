# 浏览器自动化工具（Agent 视角）

## 一句话定义

面向 AI Agent 的浏览器自动化工具，通过 Accessibility Tree（而非 DOM）暴露页面结构，让 LLM 能以稳定的 ref 机制操作浏览器，是 Harness 工具层的 Web 交互组件。

## 核心要点

- **两种方案对比**：
  - **DOM 方案**（传统）：依赖 CSS 选择器，结构脆弱，LLM 难以可靠定位元素
  - **Accessibility Tree 方案**（Agent 友好）：暴露语义化页面树，元素分配稳定 ref（如 `@e2`），LLM 可直接引用而无需解析 HTML

- **agent-browser（Vercel Labs）**：原生 Rust CLI，代表性工具
  - `snapshot` 命令返回可访问性树 + ref 映射
  - `click @ref` / `fill @ref "text"` 基于 ref 操作，无需选择器
  - `find` 命令支持自然语言元素定位
  - `screenshot` 返回带注释的截图（适合多模态 LLM）
  - 以守护进程运行，支持多标签管理

- **Agent CLI 设计原则**（Create a CLI Codex can use）：
  - 按发现→读→写分层，写操作需显式审批
  - 大型响应写文件，命令只返回路径+摘要
  - 伴生 Skill 记录何时用、先运行什么、哪些操作需审批

- **在 Harness 中的定位**：浏览器自动化是 Harness 工具层的一个子模块，与文件系统工具、代码执行工具并列，共同构成 Agent 的"感知-行动"接口
