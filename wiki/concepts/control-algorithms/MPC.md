# MPC（模型预测控制）

## 定义

模型预测控制（Model Predictive Control, MPC）是一类"基于模型、显式处理约束、在线滚动重优化"的控制与优化框架。在每个采样时刻，控制器利用当前状态和未来预测信息，求解一个有限时域优化问题，只执行第一步控制，再在下一时刻重复这一过程。

## 知识体系位置

MPC 是现代控制方法的核心代表，处于 [[控制系统基础]] → [[现代控制方法]] 进化路线的高级阶段。与经典 [[PID控制]] 的核心差异不在于"是否最优"，而在于把**模型、约束、预测、反馈**统一进了在线优化闭环。

```
经典控制: PID → LQR → MPC → NMPC
                          ↑
                    现代控制方法
```

## 核心工作原理

MPC 的滚动时域机制：

1. **状态估计**：获得当前系统状态 $x_k$
2. **预测**：利用模型预测未来 $N$ 步的系统行为
3. **优化**：求解有限时域最优控制问题
4. **执行**：只将控制序列的第一步 $u_{k|k}^*$ 下发到真实系统
5. **滚动**：下一时刻获取新状态，重复以上步骤

```mermaid
flowchart LR
    A[状态估计 x_k] --> B[构造有限时域优化问题]
    B --> C[求解 QP / NLP]
    C --> D[仅执行第一步 u_k]
    D --> E[系统演化到 x_{k+1}]
    E --> A
```

## 与 PID/LQR 的核心差异

| 维度 | PID | LQR | MPC |
|------|-----|-----|-----|
| 约束处理 | 饱和限制（补丁式） | 无 | 显式、端到端 |
| 预测能力 | 无 | 名义稳态 | 有限时域前瞻 |
| 优化目标 | 误差消除 | 二次型代价 | 任意代价函数 |
| 适用场景 | SISO、简单对象 | MIMO、线性系统 | MIMO、约束、多目标 |

## MPC 的工程分层

从算法工程师视角，MPC 最重要的不是"控制理论名词"，而是背后的工程分层：

- **上层**：预测模型与场景生成（你的时间序列预测优势在此）
- **中层**：约束优化求解（QP/NLP/MILP）
- **下层**：滚动时域把预测误差纳入闭环修正

```
预测模块（时间序列） → 优化模块（QP/NLP） → 控制模块（执行）
        ↑                    ↑                   ↑
   你擅长：负荷/价格/风光预测   建模与求解        滚动优化
```

## 工程选型决策树

**快速工程落地路径**：
1. 先从**线性/凸经济 MPC** 做主干
2. 把不确定性通过**场景化、软约束、滚动重优化**吸收
3. 若必须处理强非线性 → 引入 **CasADi/GEKKO/do-mpc**
4. 若涉及离散规则（启停、充放互斥）→ 整理成 **MILP/QP**，用 **Gurobi/CPLEX**

## 关键优势

1. **显式约束处理**：输入限幅、状态边界、坡度约束、终端区域等直接写入优化问题
2. **滚动修正**：预测误差在下一轮闭环中纠正，而不是一次计划走到黑
3. **多目标平衡**：跟踪，平滑，经济性，安全性可同时纳入目标函数
4. **预测集成**：天然适合接入时间序列预测（如负荷/价格/风光预测）

## 应用场景

- **能源系统**：储能调度、虚拟电厂、电动汽车充电
- **工业控制**：化工过程、炼油厂、发电厂
- **机器人**：轨迹跟踪、移动机器人
- **电力市场**：报价优化、日前-日内-实时调度
