# 现代控制方法

现代控制方法关注的是：当系统具有多变量耦合、状态约束、非线性或未来优化需求时，如何超越经典 PID，直接基于模型、状态和目标函数设计控制器。

## 核心范围

在当前知识库里，现代控制方法主要包括：

- **LQR / iLQR**：用最优控制思想处理线性或局部线性化系统
- **MPC / NMPC**：把未来时域上的约束和目标直接写成在线优化问题
- **状态反馈与最优控制**：从系统状态而非单一误差构造控制律

## 与经典控制的关系

- [[PID-控制]] 适合简单、低成本、快速落地的闭环控制
- 现代控制方法更适合：
  - 多变量系统
  - 显式约束
  - 跟踪问题
  - 非线性系统
  - 需要前瞻规划的场景

两者不是替代关系，而是复杂度与能力逐步提升的连续谱：

`控制系统基础 -> PID -> LQR -> MPC / NMPC`
