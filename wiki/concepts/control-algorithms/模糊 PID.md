# 模糊 PID

模糊 PID 是在经典 PID 基础上引入模糊推理进行**在线参数整定**的控制方法——输入当前误差 e 和误差变化率 Δe，通过模糊规则动态调整 ΔKp/ΔKi/ΔKd，使 PID 能适应工况变化。

## 核心要点

**与纯 PID 的关键区别**：

| 特性 | 经典 PID | 模糊 PID |
|---|---|---|
| 参数 | 固定 Kp/Ki/Kd | 实时调整 Kp/Ki/Kd |
| 适应性 | 对工况变化敏感 | 能跟随工况自适应 |
| 设计复杂度 | 低 | 中（需设计规则表） |
| 原理 | 误差线性反馈 | 误差 + 规则知识 |

> 模糊 PID 是**增强**而非替代——PID 提供基础控制框架，模糊推理负责动态优化参数。

**调整逻辑**：

| 误差状态 | 调整方向 | 原因 |
|---|---|---|
| 误差大 | 增大 Kp，减小 Ki | 加快响应，避免积分过调 |
| 误差大且变化快 | 增大 Kd | 抑制超调 |
| 误差中等 + 变化快 | 增大 Kd，减小 Ki | 防振荡 |
| 误差小 | 增大 Ki，减小 Kd | 消除稳态误差，降低噪声敏感性 |

## 基本结构

```
       e, Δe
         ↓
   ┌──────────────┐
   │  模糊推理器   │ → ΔKp, ΔKi, ΔKd
   │（规则表+隶属）│
   └──────────────┘
         ↓
   Kp = Kp0 + ΔKp
   Ki = Ki0 + ΔKi
   Kd = Kd0 + ΔKd
         ↓
   ┌──────────────┐
   │  经典 PID    │ → 控制量 u(k)
   └──────────────┘
```

- 输入：误差 e 和误差变化率 Δe
- 模糊语言变量：NB（负大）/ NM（负中）/ NS（负小）/ ZO（零）/ PS（正小）/ PM（正中）/ PB（正大）
- 输出：参数增量 ΔKp、ΔKi、ΔKd

## 典型应用

- 温控系统（非线性热惯性）
- 电机转速控制（负载变化）
- 无人机姿态控制（气流扰动）
- 车辆纵向控制（质量/坡度变化）
- 化工过程控制（时变对象）

## 优缺点

**优点**：
- 保留 PID 简单性和成熟性，增加自适应能力
- 不需要精确数学模型
- 规则直觉可解释（专家知识可编码）

**缺点**：
- 规则表设计带有主观性，需要调试
- 规则数量随输入维度指数增长（规则爆炸）
- 稳定性分析比经典 PID 复杂
- 性能依赖规则质量，初期仍需大量调参
