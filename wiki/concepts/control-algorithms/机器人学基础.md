# 机器人学基础

机器人学是研究如何让机器人**感知环境、规划行动、执行控制**的综合工程学科，涵盖运动学、感知、状态估计、路径规划和运动控制五大模块。

## 核心要点

机器人完成一个任务的完整闭环：

```
传感器感知 → 状态估计 → 运动规划 → 控制执行 → 机械执行
     ↑                                              │
     └──────────── 反馈（里程计/视觉）───────────────┘
```

各模块职责：

| 模块 | 问题 | 典型方法 |
|---|---|---|
| 传感器感知 | 我看到了什么？ | 摄像头、激光雷达、IMU、里程计 |
| 状态估计 | 我在哪里？ | 卡尔曼滤波、粒子滤波、SLAM |
| 运动规划 | 我该怎么走？ | A*、RRT、势场法 |
| 控制执行 | 如何精确到达？ | PID、轨迹跟踪、模型预测控制 |

## 运动学基础

- **坐标变换**：机器人位姿由旋转矩阵 R 和平移向量 t 描述（SE(3) 群）
- **正运动学**：已知关节角 → 求末端位姿
- **逆运动学**：已知目标位姿 → 求关节角（通常多解或无解）
- **里程计**：通过轮速/IMU 积分估计位移（误差随时间累积）

## 感知与状态估计

- **贝叶斯滤波**：以概率分布表示状态不确定性，融合运动模型（预测）和观测模型（更新）
- **卡尔曼滤波（KF）**：线性系统最优估计，扩展/无迹版本适用非线性
- **SLAM**（同步定位与地图构建）：在未知环境中同时构建地图和定位

## 控制执行层与控制算法的关系

控制算法是机器人底层执行层的核心：

- **轨迹跟踪**：给定参考轨迹，PID 控制各关节/轮速跟随
- **姿态控制**：无人机/机器人姿态稳定，通常用级联 PID（外环位置 + 内环角速度）
- **力控**：柔顺控制、阻抗控制（机械臂与环境接触时）
- **模型预测控制（MPC）**：根据未来轨迹优化当前控制量，适合有约束的运动规划

## 典型应用

- 移动机器人自主导航（SLAM + 路径规划 + PID）
- 工业机械臂（运动学 + 轨迹规划 + 关节 PID）
- 无人机飞控（IMU + 卡尔曼滤波 + 级联 PID）
- 自动驾驶车辆（感知融合 + 预测 + MPC 控制）
