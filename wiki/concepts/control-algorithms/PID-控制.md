# PID 控制

一句话定义：PID 控制是比例（Proportional）、积分（Integral）、微分（Derivative）三种控制规律的组合，核心思想是"既看当前误差，也看历史累计，还看变化趋势"。

## 核心要点

### PID 的核心思想

连续形式：

`$$u(t) = K_{p}e(t) + K_{i}\int e(t)dt + K_{d}\frac{de(t)}{dt}$$`

离散形式（数字控制器常用）：

`$$u(k)=K_{p}e(k)+K_{i}\sum_{n=0}^{k}e(n)+K_{d}\big(e(k)-e(k-1)\big)$$`

三项分工：
- **P 管现在**：看当前误差有多大，偏差大就立刻加大动作
- **I 管过去**：看历史累计偏差，只要长期没调到位就继续补偿
- **D 管未来趋势**：看误差变化有多快，冲得太快就提前刹车

### 直觉理解

不要一上来就盯着公式，建议按以下顺序理解：

1. 先看"误差"是什么
2. 再看控制器面对误差会做什么
3. 最后看 P/I/D 三项各自解决什么问题

**三个类比**：

| 类比 | P | I | D |
|------|---|---|---|
| 追目标 | 差得远就多推 | 偏了很久就继续补 | 冲太快就提前压 |
| 开车跟车 | 距离远就多给油 | 长期跟不上就持续多给 | 接近太快就提前减速 |
| 水缸加水 | 水位低就多加 | 漏水就持续补偿 | 水位涨太快就减缓 |

### 三项详解

#### 比例控制 P

`$$u = K_{p}e$$`

- **优点**：响应快、实现简单
- **问题**：单独使用通常存在稳态误差；比例系数过大易引起振荡
- **直觉**："看到差多少，就立刻补多少"

#### 积分控制 I

`$$u_I(t)=K_{i}\int e(t)dt$$`

- **作用**：消除稳态误差
- **问题**：响应变慢、超调增大、积分饱和
- **直觉**："记账"——只要误差一直存在就继续记，直到把长期偏差补回来

#### 微分控制 D

`$$u_D(t)=K_{d}\frac{de(t)}{dt}$$`

- **作用**：抑制超调、减少振荡、改善动态响应
- **问题**：对噪声敏感，通常需配合低通滤波
- **直觉**："趋势判断"——不是看现在偏了多少，而是看偏差变化多快

### 调参经验

调参顺序：**先 P，再 I，后 D**

1. 先增大 `$K_p$`，让系统有足够响应速度
2. 再加入 `$K_i$`，消除稳态误差
3. 最后增加 `$K_d$`，抑制超调和振荡

| 现象 | 调整建议 |
|------|----------|
| 响应太慢 | 增大 `$K_p$` |
| 稳态误差明显 | 增大 `$K_i$` |
| 超调大、振荡强 | 增大 `$K_d$` 或减小 `$K_p$` |
| 积分饱和严重 | 限制积分项或引入抗饱和机制 |

### 优缺点

**优点**：
- 原理简单，易于工程实现
- 不依赖高精度数学模型
- 对大多数单输入单输出对象有效
- 调参经验成熟，工业应用最广

**局限**：
- 对强非线性、时变系统效果有限
- 参数整定依赖经验
- 对大滞后、多变量耦合对象不一定理想
- 微分项易受测量噪声影响

## Python 实现要点

使用 `simple-pid` 库（`pip install simple-pid`）可快速实现工程级 PID：

```python
from simple_pid import PID

pid = PID(Kp=1.0, Ki=0.1, Kd=0.05,
          setpoint=100,
          output_limits=(-100, 100))   # 防积分饱和

while True:
    measurement = read_sensor()
    control = pid(measurement)          # 传入测量值，返回控制量
    apply_control(control)
```

**关键工程参数**：

| 参数 | 作用 | 建议 |
|---|---|---|
| `output_limits=(lo, hi)` | 限制输出范围，**同时防积分饱和（windup）** | 总是设置，避免积分项无限增长 |
| `proportional_on_measurement=True` | 比例项作用于测量值而非误差 | 设定值跳变时可减少超调 |
| `differential_on_measurement=True` | 微分项作用于测量值（默认开启） | 避免"微分尖峰"（setpoint 阶跃导致的 D 项突变） |
| `sample_time=0.01` | 固定采样间隔（秒） | 避免因循环速度不均匀导致积分/微分计算误差 |
| `reset()` | 清空积分项和历史状态 | 切换设定值前或模式切换时调用 |
| `pid.components` | 返回 (P, I, D) 三项分量 | 调试时用于查看各项贡献 |

**手动/自动无扰切换**：

```python
# 从手动切换到自动时，传入当前手动输出值
pid.set_auto_mode(True, last_output=manual_output)
```
