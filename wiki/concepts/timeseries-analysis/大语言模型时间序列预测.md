# 大语言模型时间序列预测

> 利用大语言模型（LLM）进行时间序列预测的新兴研究方向。

## 概述

大语言模型时间序列预测探索将LLM的强大序列建模能力应用于时间序列数据，通过将时间序列表示为 token 序列或自然语言描述，利用LLM的少样本/零样本学习能力进行预测。

## 核心方法

1. **序列 tokenization** - 将时间序列数值离散化为 token
2. **文本化描述** - 将时间序列特征转化为自然语言提示
3. **微调与适配** - 在时间序列数据上微调预训练LLM
4. **提示工程** - 设计专门的时间序列预测提示模板

## 优势与挑战

**优势**：
- 零样本/少样本预测能力
- 强大的序列建模和上下文理解
- 可处理多模态时间序列（文本+数值）

**挑战**：
- 数值精度与 tokenization 误差
- 计算成本高
- 可解释性较低
