# 图像分类

## 定义

图像分类（Image Classification）是为整张图像分配一个或多个类别标签的任务，是计算机视觉的基础任务。

## 经典架构

### CNN 时代

| 架构 | 年份 | 关键创新 |
|------|------|----------|
| **AlexNet** | 2012 | ReLU、Dropout、数据增强 |
| **VGG** | 2014 | 小卷积核（3×3）、深网络 |
| **GoogLeNet** | 2014 | Inception 模块 |
| **ResNet** | 2015 | 残差连接 |
| **EfficientNet** | 2019 | 复合缩放 |

### Transformer 时代

| 架构 | 年份 | 关键创新 |
|------|------|----------|
| **ViT** | 2020 | 纯 Transformer，图像切分 |
| **Swin Transformer** | 2021 | 滑动窗口，层次特征 |
| **ConvNeXt** | 2022 | 现代化 CNN，媲美 ViT |

## 评估指标

| 指标 | 说明 |
|------|------|
| **Top-1 Accuracy** | 预测最可能类别正确的比例 |
| **Top-5 Accuracy** | 前 5 个预测中包含正确答案的比例 |
| **ImageNet** | 标准基准数据集（1000 类） |

## 在 VLM 中的应用

图像分类是视觉语言模型的基础能力：
- ViT 作为图像编码器
- CLIP 进行图像-文本对齐
- 零样本分类能力
