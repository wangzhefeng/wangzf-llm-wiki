# 句法分析

## 一句话定义

句法分析（Syntactic Parsing）是构建句子的语法结构树，揭示词汇间依存或成分关系的任务。

## 在知识体系中的位置

句法分析是从浅层词序列（分词、标注、NER）向深层语义理解的桥梁。它一方面依赖 [[分词]] 和 [[词性标注]] 的准确性，另一方面为 [[文本分类]]、知识抽取等高级任务提供句子结构信息。现代深度学习时代，句法分析的重要性有所下降（BERT 隐式学到语法），但在解释性和特定领域仍不可或缺。

### 知识关联
- **前置步骤**：[[分词]]、[[词性标注]]
- **后续步骤**：语义角色标注（SRL）、关系抽取、机器翻译
- **同级任务**：[[命名实体识别]]、情感分析

## 核心原理与方法

### 两种主要范式

**1. 依存分析（Dependency Parsing）**
- 核心思想：所有词都依附于一个**中心词**（通常是谓语）
- 结果：有向树结构，边表示依存关系类型（主语、宾语、修饰等）

```
例：The boy saw a girl in the park
      saw(谓语)
      ├── The(定冠词) → boy(主语)
      ├── boy(主语)
      ├── a(定冠词) → girl(宾语)
      ├── girl(宾语)
      └── in(介词) → park(地点状语)
```

**2. 成分分析（Constituent Parsing）**
- 核心思想：句子由从大到小的短语递归组成
- 结果：树形结构，内部节点表示短语，叶子是词

### 三代方法论

**1. 规则与文法（1960s-1980s）**
- 上下文无关文法（CFG），手工编写规则
- 歧义问题难以解决

**2. 统计与转移系统（1990s-2010s）**
- **转移系统（Transition-based）**：通过一系列转移操作构造树
- **图算法（Graph-based）**：最大生成树解码
- 精度 92-95%

**3. 神经解析（2010s-至今）**
- **BiLSTM**：上下文感知的词表示
- **Transformer**：无需手工特征，end-to-end 学习
- 精度 96%+ UAS（Unlabeled Attachment Score）

## 实战应用（3 个案例）

### 案例 1：依存分析（spaCy）

```python
import spacy
nlp = spacy.load("en_core_web_sm")
text = "The quick brown fox jumps"
doc = nlp(text)
for token in doc:
    print(f"{token.text} ← {token.head.text} ({token.dep_})")
# 输出：
# The ← brown (det)
# quick ← brown (amod)
# brown ← fox (amod)
# fox ← jumps (nsubj)
# jumps ← jumps (ROOT)
```

### 案例 2：成分分析示例

```
      S (句子)
      ├── NP (名词短语)
      │   ├── The
      │   └── cat
      ├── VP (动词短语)
      │   ├── chased
      │   └── NP (名词短语)
      │       ├── the
      │       └── dog
      └── .
```

### 案例 3：句法信息在机器翻译中的应用

英文"I give a book to John"的依存结构帮助翻译器识别：
- give 为中心动词
- I 是施事者（agent）
- book 是受事者（theme）
- John 是接收者（recipient）

翻译到汉语"我把书给约翰"时，依存信息指导语序调整。

## 常见问题

**Q: 依存分析 vs 成分分析，选哪个？**
A: 依存分析计算更高效、标注更细粒度，成分分析更符合语言学直观但计算复杂。现代系统主要用依存分析。

**Q: 句法分析的精度需要多高？**
A: 通用文本 95% UAS 可用，但精确 UAS（包括关系类型）可能只有 90-92%。关系类型标注更难。

**Q: BERT 是否能替代显式句法分析？**
A: BERT 隐式学到语法信息，在下游任务中不显式需要句法树。但需要可解释性（如机器翻译）时，显式分析仍有价值。

**Q: 长句子分析的困难？**
A: 随着句长增加，歧义指数增长。16 词以上的句子精度急剧下降（94%→85%）。多分句系统可缓解。

**Q: 跨语言句法分析如何做？**
A: 多语言模型（mBERT）或通用依存树库（Universal Dependencies）规范化，允许跨语言迁移学习。
