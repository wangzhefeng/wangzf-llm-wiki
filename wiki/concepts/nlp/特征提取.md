# 特征提取

## 一句话定义

特征提取（Feature Extraction）是从原始文本中自动抽取数值特征，用于机器学习模型的输入的过程。

## 在知识体系中的位置

特征提取是传统机器学习时代 NLP 系统的核心。它处于文本预处理（分词等）和分类器之间，手工设计特征直接影响模型精度。虽然深度学习时代已大幅弱化特征工程的重要性，但理解特征提取的方法和局限仍对掌握 NLP 整个演进历程至关重要。

### 知识关联
- **前置步骤**：[[分词]]、[[词性标注]]
- **后继演进**：[[词嵌入]]（自动学习特征）
- **应用**：文本分类、聚类、相似度计算

## 核心原理与方法

### 三类特征方法

**1. 词频特征（Bag of Words, BoW）**
核心思想：**文本 = 词的多重集合**，不考虑顺序和语法

```
文本："I love NLP"
特征：{I: 1, love: 1, NLP: 1}  （3维向量）
局限：丢失顺序信息、语义稀疏
```

实现：CountVectorizer 统计词频，HashingVectorizer 用哈希降维

**2. TF-IDF（Term Frequency-Inverse Document Frequency）**
核心思想：**词的重要性 = 在文档中的频率 × 在语料库中的稀有度**

$$\text{TF-IDF}(t,d) = \frac{freq(t,d)}{total\_words(d)} \times \log \frac{N}{df(t)}$$

其中：
- $freq(t,d)$ 是词 $t$ 在文档 $d$ 中的频率
- $df(t)$ 是包含词 $t$ 的文档数
- $N$ 是总文档数

**效果**：
- 高频但通用词（"的"、"是"）权重低
- 低频但特征词（专有名词）权重高

**3. N-gram 特征**
核心思想：**捕捉局部上下文**，用相邻的 N 个词作为特征

```
文本："I love NLP"
unigram(N=1)：{I, love, NLP}
bigram(N=2)：{I love, love NLP}
trigram(N=3)：{I love NLP}
```

效果：比 BoW 保留部分顺序信息，但特征数量爆炸（词汇^N）

## 实战应用（3 个案例）

### 案例 1：TF-IDF + SVM 文本分类

```python
from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.svm import SVC
from sklearn.pipeline import Pipeline

# 建立管道
clf = Pipeline([
    ('tfidf', TfidfVectorizer(
        max_features=5000,       # 选择最频繁的 5000 词
        ngram_range=(1, 2),      # 使用 unigram 和 bigram
        min_df=5, max_df=0.8     # 过滤极少和极常见的词
    )),
    ('svm', SVC(kernel='linear', C=1.0))
])

# 训练与预测
texts = [
    "This movie is great",
    "I hated this film"
]
labels = [1, 0]
clf.fit(texts, labels)
pred = clf.predict(["Amazing movie!"])  # 输出 [1]
```

### 案例 2：特征稀疏性问题

原始 BoW 特征：
- 词汇表大小 10K，文本长度 100 词 → 特征中 99% 是 0（极度稀疏）
- 计算和存储低效

解决方案：
- 使用稀疏矩阵存储
- HashingVectorizer：固定维度（如 1024），用哈希函数映射词

## 常见问题

**Q: BoW 和 TF-IDF 的实际精度差异多大？**
A: 在文本分类中，TF-IDF 通常比 BoW 快 2-5%。但两者都不如词嵌入+深度学习（精度可快 10-15%）。

**Q: 为什么深度学习不需要特征工程？**
A: 深度学习模型自动学习特征（从词嵌入到隐层表示）。但手工特征在数据少时仍有帮助。

**Q: 特征的维度爆炸如何处理？**
A: 
- 特征选择：选择最重要的 K 个特征
- 特征降维：PCA、LSA 等
- 哈希技巧：固定维度，避免存储整个词汇表

**Q: 为什么 TF-IDF 对停用词无效？**
A: 停用词（"the"、"is"）在所有文档中高频，逆文档频率（IDF）低，权重自然降低。可显式移除停用词更彻底。

**Q: 特征提取与[[词嵌入]]的本质区别？**
A: 特征提取是人工定义的规则特征，词嵌入是从大规模语料自动学习的稠密向量。后者包含更丰富的语义信息。
