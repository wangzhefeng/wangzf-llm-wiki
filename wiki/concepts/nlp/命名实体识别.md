# 命名实体识别

## 一句话定义

命名实体识别（Named Entity Recognition，NER）是从非结构化文本中自动定位和分类专有名词（人名、地名、组织、日期、数字等）的任务。

## 在知识体系中的位置

NER 是信息抽取和知识图谱构建的基础，位于 [[分词]]、[[词性标注]] 之后。与词级标注不同，NER 的标签对象是"实体"（可跨多个词），因此需要特殊的标注方案（BIO/BIOES 标签体系）。NER 既是基础任务，也是 [[知识图谱]] 构建的第一步。

### 知识关联
- **前置步骤**：[[分词]]、[[词性标注]]
- **后续步骤**：[[知识图谱]]、信息抽取、关系抽取
- **应用**：搜索、推荐、舆情分析、知识库构建

## 核心原理与方法

### 标注方案：BIO/BIOES

NER 使用标签序列标记实体边界和类型：

```
文本：     北    京    大    学    成    立    于    1898
标签：  B-LOC I-LOC B-ORG I-ORG O     O     O     O
实体识别：北京(LOC)   北京大学(ORG)
```

**常见实体类型**：
- **PER**（Person）：人物、人名
- **LOC**（Location）：地点、地名
- **ORG**（Organization）：组织、机构
- **DATE/TIME**：日期、时间
- **MONEY/PERCENT**：金额、百分比

### 三代方法论

**1. 规则与词典（1990s）**
- 基于模式匹配和命名实体字典
- 精度与覆盖度的权衡难以解决

**2. 统计序列标注（2000s-2010s）**
- **CRF（条件随机场）**：标准工业方法，精度 85-90%
- 特征工程关键（字符、词典、上下文）

**3. 神经深度学习（2010s-至今）**
- **BiLSTM-CRF**：使用双向 LSTM 学习上下文表示，CRF 解码
- **Transformer/BERT**：预训练模型，fine-tune 后精度 92%+
- 端到端学习，无需手工特征

## 实战应用（3 个案例）

### 案例 1：通用 NER（spaCy）

```python
import spacy
nlp = spacy.load("en_core_web_sm")
text = "Apple CEO Tim Cook announced new products in San Francisco."
doc = nlp(text)
for ent in doc.ents:
    print(f"{ent.text} → {ent.label_}")
# 输出：
# Apple → ORG
# Tim Cook → PERSON
# San Francisco → GPE
```

### 案例 2：中文 NER（fastHan）

```python
from fastHan import FastHan
model = FastHan()
text = "张三在北京大学读书"
ner_result = model(text, task='ner')
# 输出：张三(PER), 北京大学(ORG)
```

### 案例 3：医学领域 NER

通用模型在医学领域 NER 精度低（30-50%），因为需要识别"症状"、"药物"、"检查项目"等医学特有实体。解决方案：
1. 使用医学语料库微调预训练模型
2. 构建医学词典增强
3. 多任务学习（NER + 属性分类）
实现精度可达 85%+。

## 常见问题

**Q: 嵌套实体问题如何处理？**
A: 例如"美国总统拜登"中，"拜登"是 PER，"美国"是 LOC，但"美国总统"可能被标为 TITLE。标准 BIO 方案处理不了嵌套。解决方案：分别进行多个 NER 系统或使用 sequence-to-set 方法。

**Q: NER 与 [[知识图谱]] 的关系？**
A: NER 是知识图谱构建的第一步（识别实体），随后进行关系抽取（识别实体间关系）。两者的错误会级联放大。

**Q: 如何评估 NER 质量？**
A: 使用精确率、召回率、F1 分数，计算范围内（exact match）或宽松匹配（partial/relaxed）两种。

**Q: 跨域 NER 如何做？**
A: 医学、法律、金融等领域有不同的实体类型。通解：领域自适应（domain adaptation）通过微调、数据增强或多任务学习实现。

**Q: 长文本 NER 如何处理？**
A: BERT 最大输入长度 512 词。长文本可分段处理，注意边界处理避免实体被截断。
