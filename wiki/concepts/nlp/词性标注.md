# 词性标注

## 一句话定义

词性标注（Part-of-Speech tagging，POS tagging）是为文本中的每个词分配其语法属性（名词、动词、形容词、介词等）的任务。

## 在知识体系中的位置

词性标注是 [[分词]] 之后的第二步基础任务，是理解句子语法结构的关键。与分词不同，词性标注本质上是一个**分类问题**——给定词及其上下文，预测其语法属性。现代系统中，词性标注通常与分词结合（如 spaCy 的 pipeline）。

### 知识关联
- **前置步骤**：[[分词]]
- **后续步骤**：[[句法分析]]、特征工程、语义理解
- **平行任务**：[[命名实体识别]]（同为序列标注框架）

## 核心原理与方法

### 标注集定义

词性集合因语言而异：
- **英文**：Penn Treebank（45 个标签）、通用依存树库（17 个主标签）
- **中文**：北大标注集（24 个）、宾州标注集中文版
- **常见标签**：NN(名词)、VB(动词)、JJ(形容词)、IN(介词)、PRP(代词)...

### 三代方法论

**1. 规则与词典（1970s-1980s）**
- 使用预定义规则和词典标注
- 精度低（80-90%）且难以移植

**2. 统计序列标注（1990s-2010s）**
- **HMM 模型**：P(TAG|word) × P(word|TAG)
- **CRF 模型**：考虑标签间依赖，P(sequence of tags | sequence of words)
- 精度提升至 96-97%

### 3. 神经序列标注（2010s-至今）
- **BiLSTM-CRF**：双向 LSTM + CRF 损失
- **Transformer**（BERT）：动态词表示 + fine-tuning
- 精度达 97%+ 在通用文本上

## 实战应用（3 个案例）

### 案例 1：歧义处理

"书" 在不同语境的词性不同：
```
他买了本书      →  书(NN)   名词
这房间书太多了  →  书(VB)   动词
```

### 案例 2：工业级实现（spaCy）

```python
import spacy
nlp = spacy.load("en_core_web_sm")
doc = nlp("The quick brown fox")
for token in doc:
    print(f"{token.text} → {token.pos_} ({token.tag_})")
# 输出：
# The → DET (DT)
# quick → ADJ (JJ)
# brown → ADJ (JJ)
# fox → NOUN (NN)
```

### 案例 3：中文词性标注的特殊性

```python
import jieba.posseg as pseg
words = pseg.cut("我爱自然语言处理")
for word, flag in words:
    print(f"{word} ({flag})")
# 输出：
# 我 (r)     代词
# 爱 (v)     动词
# 自然语言 (n)  名词
# 处理 (v)    动词
```

## 常见问题

**Q: 为什么需要词性标注？可以直接用词向量吗？**
A: 词向量捕捉语义相似性，但无法表达语法属性（如"树"可是名词或动词）。词性标注显式提供语法信息，便于规则提取、语法检查、句法分析等任务。

**Q: 词性标注精度与下游任务的关系？**
A: 词性标注错误直接影响 [[句法分析]] 和语义理解。但在预训练模型（BERT）时代，隐式学到的语法特征往往比显式标注更强。

**Q: 如何处理"歧义词"？**
A: 使用上下文信息。现代方法基于双向 LSTM 或 Transformer，能自动学习上下文依赖，无需手工规则。

**Q: 不同标注集之间能转换吗？**
A: 可以，但信息会损失。如 Penn Treebank 的 45 个标签能映射到通用 17 个标签，但反向转换会失真。

**Q: 零资源语言如何做词性标注？**
A: 跨语言迁移学习。使用多语言模型（mBERT）或通用 UPenn Treebank 标注体系进行迁移。
