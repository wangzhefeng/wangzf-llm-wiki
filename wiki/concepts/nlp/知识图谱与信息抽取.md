# 知识图谱与信息抽取

## 一句话定义

知识图谱（Knowledge Graph）是将非结构化文本中的实体、属性和关系自动抽取出来，构建结构化的实体-关系网络，用于知识表示和推理的系统。

## 在知识体系中的位置

知识图谱是 NLP 从信息处理向知识工程转变的重要应用。它整合了 [[命名实体识别]]（识别实体）、关系抽取（识别关系）、句法分析（辅助理解）等多个基础任务，并与知识库、推荐系统、语义搜索等下游应用紧密相连。知识图谱代表了 NLP 的系统化应用方向。

### 知识关联
- **前置步骤**：[[分词]]、[[命名实体识别]]、[[句法分析]]
- **核心流程**：实体识别 → 关系抽取 → 图谱补全 → 应用
- **应用**：搜索、推荐、问答系统、舆情分析

## 核心原理与方法

### 知识图谱的构成

```
实体（Entity）
    ├── 属性（Attribute）：name, type, description...
    └── 关系（Relation）→ 其他实体

示例：
    ├─ 北京大学
    │  ├── 类型：大学
    │  ├── 成立年份：1898
    │  └── 位置：北京
    │
    ├─ 张三 → 学生 → 北京大学（关系）
```

### 知识图谱构建的三大步骤

**1. 实体识别（[[命名实体识别]]）**
- 任务：从文本中识别实体及其类型（人、地、机构等）
- 技术：BiLSTM-CRF、BERT fine-tune
- 挑战：OOV、实体边界不清、嵌套实体

**2. 关系抽取（Relation Extraction）**
- 任务：识别实体对间的关系类型（成立于、任职于等）
- 方法：
  - 监督关系分类：给定实体对，分类其关系
  - 开放关系抽取：无预定义关系，自动发现
- 技术：句法树、依存路径、神经网络、远程监督

**3. 知识融合与补全**
- 去重：同一实体的多个表达（"北京大学"vs"北大"）
- 消歧：同名不同人（"张三"）
- 补全：预测缺失的实体关系
- 更新：处理过时信息

### 知识图谱存储与查询

使用图数据库（如 Neo4j）存储和查询：

```
Cypher 查询：
MATCH (person:Person)-[:worksAt]->(company:Company)
WHERE company.name = "Google"
RETURN person.name, person.title
```

## 实战应用（3 个案例）

### 案例 1：基于规则的关系抽取

使用句法依存路径识别"任职于"关系：

```
输入：张三在Google任职
句法树：任职 ← 张三（主语）, Google（地点）
规则：NER(PER) +[主语]→ 动词 +[地点]→ NER(ORG) ⟹ 关系"任职于"
```

### 案例 2：远程监督关系抽取

无需大量标注数据：
1. 获取已知实体关系（维基百科、现有知识库）
2. 自动为含有这些实体对的文本标注
3. 用弱监督学习（处理噪声标签）
4. 扩展到新实体和关系

### 案例 3：Neo4j 知识图谱应用

```python
from neo4j import GraphDatabase

driver = GraphDatabase.driver("bolt://localhost:7687")
session = driver.session()

# 创建实体和关系
session.run("CREATE (p:Person {name: '张三'}) RETURN p")
session.run("CREATE (c:Company {name: 'Google'}) RETURN c")
session.run("""
    MATCH (p:Person {name: '张三'}), (c:Company {name: 'Google'})
    CREATE (p)-[:WORKS_AT]->(c)
""")

# 查询
result = session.run("""
    MATCH (p:Person)-[:WORKS_AT]->(c:Company)
    RETURN p.name, c.name
""")
for record in result:
    print(record)
```

## 常见问题

**Q: 知识图谱与数据库的区别？**
A: 数据库存储结构化数据，关系预定义。知识图谱涵盖非结构化文本中提取的信息，关系可动态发现，具有歧义性和冗余性。

**Q: 如何评估知识图谱的质量？**
A: 精确率（抽取的关系中正确的比例）、召回率（正确关系被抽取的比例）、F1 分数。人工评估是黄金标准。

**Q: 关系抽取与 [[句法分析]] 的关系？**
A: 句法依存路径是关系抽取的强力特征。例如"CEO"通常是主语，"公司"是地点状语。

**Q: 实体消歧如何做？**
A: 同名实体（"苹果"公司 vs 苹果水果）。可用上下文相似度、维基百科消歧，或编码额外属性区分。

**Q: 知识图谱补全（Link Prediction）的方法？**
A: 基于路径的方法、张量分解、图神经网络、三元组分类等。常见是TransE（优化向量）、图神经网络。
