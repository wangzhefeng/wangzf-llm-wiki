# 文本分类

## 一句话定义

文本分类（Text Classification）是将文本文档自动分配到预定义的类别集合中的任务，是有监督学习的经典应用。

## 在知识体系中的位置

文本分类既是基础的 NLP 任务，也是最常见的应用。它处于从特征提取（低级）到[[知识图谱]]等高级任务的中间层。文本分类的方法论（特征工程、分类器选择、评估指标）是整个 NLP 系统设计的缩影。

### 知识关联
- **前置步骤**：[[分词]]、[[特征提取]]
- **并行任务**：[[情感分析]]（文本分类的特例）、[[文本聚类]]
- **应用**：垃圾邮件检测、新闻分类、意图识别、情感分析

## 核心原理与方法

### 问题定义
给定文本 $x$ 和类别集合 $\{c_1, c_2, ..., c_k\}$，学习函数 $f: x \to c$ 预测正确类别。

**特点**：
- 有标注的训练数据可用
- 类别数通常 2-100 个
- 任务可从二分类到多分类

### 三代方法论

**1. 特征工程 + 传统分类器（1990s-2010s）**
- 特征：Bag of Words、TF-IDF、N-gram
- 分类器：朴素贝叶斯、SVM、逻辑回归
- 特点：可解释性强，但特征工程耗时

**2. 浅层神经网络（2010s-2015）**
- 单层或两层全连接网络 + 词向量
- 卷积神经网络（CNN）处理序列：$\max(CNN(word\_embeddings))$
- 精度提升到 90%+

**3. 深度序列模型（2015s-至今）**
- **LSTM/GRU**：处理长依赖，序列编码到向量
- **Transformer/BERT**：预训练 + fine-tune，精度 95%+
- 特点：无需人工特征，端到端学习

## 实战应用（3 个案例）

### 案例 1：传统 TF-IDF + SVM

```python
from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.svm import SVC
from sklearn.pipeline import Pipeline

# 建立分类管道
clf = Pipeline([
    ('tfidf', TfidfVectorizer(max_features=1000, ngram_range=(1,2))),
    ('svm', SVC(kernel='linear'))
])

# 训练与预测
texts = ["I love this movie", "Terrible film, waste of time"]
labels = [1, 0]  # 1: positive, 0: negative
clf.fit(texts, labels)
print(clf.predict(["Great movie!"]))  # 输出 [1]
```

### 案例 2：BERT 微调（情感分类）

```python
from transformers import pipeline
classifier = pipeline("sentiment-analysis", 
                      model="bert-base-multilingual-uncased-sentiment")
result = classifier("I love this product!")
print(result)  # 输出 [{'label': 'positive', 'score': 0.9999}]
```

### 案例 3：多标签分类（新闻标签）

某新闻可能同时属于"体育"和"国际"。与传统多分类（互斥类别）不同：
- 使用多个二分类器（one-vs-rest）
- 或使用 sigmoid loss 替代 softmax
- 评估指标：Hamming loss、Jaccard 相似度、F1/macro

## 常见问题

**Q: 有多少训练数据才能做好文本分类？**
A: 少样本（<100）使用 TF-IDF+SVM；中等样本（100-10K）用浅层神经网络；大样本（>50K）用 BERT。但预训练模型可大幅减少需求。

**Q: 类别不平衡如何处理？**
A: 修改损失权重、过采样少数类、欠采样多数类，或使用 focal loss。不推荐仅用准确率，改用 F1/AUC。

**Q: 文本分类与 [[情感分析]] 的关系？**
A: 情感分析是文本分类的特例（二分类：正面/负面）。但情感分析通常涉及情感词、修饰词等特殊处理。

**Q: 如何处理开放集（未见类别）？**
A: 检测到"未知类"较困难。可用距离度量（样本与已知类的距离）或异常检测方法。

**Q: 分类模型的可解释性？**
A: 神经网络黑盒，但可用注意力权重、特征重要性排序、或 LIME 等解释工具。传统方法（SVM 系数）可解释性更强。
